# DSH 0.1.5 and earlier

`@openviking/dsh-memory-plugin` 1.0 and later supports DSH 0.1.7-rc.2 and later. Loaded by DSH 0.1.5 or an earlier build (including the 0.1.0 release candidates), it logs one line saying so and stays off.

- Last line that supports those builds: the 0.x releases of `@openviking/dsh-memory-plugin` on npm (`@openviking/dsh-memory-plugin@0`).
- Its source is in this repository's history, under `examples/dsh-memory-plugin` before the commit that added this file: `git log --diff-filter=A --format=%H -- examples/unmaintained/dsh-0.1.5.md` names that commit, and its parent has the code.
- The 0.x line gets no fixes.
