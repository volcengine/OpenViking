# OpenCode 1.x

`@openviking/opencode-plugin` supports OpenCode 2 only (the `setup()` plugin API). Loaded by OpenCode 1.x through `server()`, it logs one line saying so and does nothing.

- The package's releases are versioned by date. The last one that supports OpenCode 1.x (1.15.7 and later) is `@openviking/opencode-plugin@2026.11.26`.
- Its source is in this repository's history, under `examples/opencode-plugin` before the commit that added this file: `git log --diff-filter=A --format=%H -- examples/unmaintained/opencode-1.x.md` names that commit, and its parent has the code.
- That release gets no fixes.
