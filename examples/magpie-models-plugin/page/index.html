OpenViking

在 Agents → OpenViking 选择模型，在这里设置管理范围。

模型用途 / Model roles

独立配置时可填写完整的 provider/model 或 group/name。Embedding、Query Planner、Rerank 保持现有设置。

OpenViking 连接 / Connection

文件路径位于运行 Magpie 的电脑上。远程服务使用 HTTPS；OV 必须能访问 Magpie 网关。

生成参数 / Generation parameters

JSON 对象；支持 max_tokens、temperature、thinking、timeout。省略字段保留原设置；max_tokens: null 使用模型默认值，Bot 跟随模式则沿用 OV 限制。已知输出上限会限制 max_tokens；未知时请自行核对。Bot 生成参数可覆盖继承值。

适用于支持重启 API 的 OV；--with-bot 启动的 Bot 会随 OV 一起重启。独立 Bot 仍需单独重启。

保存后检查同步状态：OV VLM 改动需要重启 OV；Bot 模型或参数改动需要重启 Bot（跟随 OV 时也需要）。这里只显示设置保存结果，不代表服务已生效。

卸载前先在 Agents 中断开，并保持两个应用运行，等待恢复完成。
