# 个人研究助理前端原型
<!-- impeccable:product-schema 1 -->
## Platform
web
## Purpose
按用户已确认的页面草图，用模拟数据体验活的研究文档与记忆纠错台。研究委托、差异审阅、发布、记忆纠正与重算形成完整闭环。
## Constraints
不接后端、不访问真实文档、不运行模型。状态本地保存，可重置。桌面、平板和手机均可操作。
## Evidence
本会话飞书文档内图 8–10 为视觉与交互依据，沿用浅色、紫色交互、对照审阅和抽屉编辑。
## Stack
React + Vite；继承研究方案中的 React 选择。独立示例目录，不改 Web Studio。
