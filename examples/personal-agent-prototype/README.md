# 知续 · 个人研究助理（前端原型）

React + Vite，模拟“活的研究文档”和“记忆纠错台”。不连接后端、不调用模型、不访问飞书/GitHub；发布只更新浏览器中的模拟文档。

## 启动

```bash
npm install
npm run dev
```

打开 http://127.0.0.1:4178 。当前工作区已复用 `../../web-studio/node_modules`；独立复制后运行 `npm install` 即可安装自身依赖。

```bash
npm run build
npm test
```

`dist/` 可由任意静态服务器提供。无需环境变量和账户。

## 体验路径

1. 首页 → 去审阅 → 查看来源、勾选/编辑/暂缓建议 → 审阅并应用 → 确认 → 研究文档查看结果，可下载 Markdown。
2. 返回本次更新 → 选择时间范围建议 → 纠正偏好；或直接打开知识与记忆 → 产品时间范围 → 纠正这条记忆。
3. 使用示例新规则（近两个月活跃）或编辑规则 → 保存并重算 → 回到草稿 → 查看新差异 → 勾选后重新发布。
4. 研究文档底部“演示场景”可模拟版本冲突、撤销授权；旧草稿或撤权状态禁止发布。授权设置可重新授权。
5. 首页创建新主题；知识与记忆中可停用/启用、删除记忆，原始文档保留；左下“重置演示”恢复初始状态。

本地状态保存在 `localStorage` 的 `personal-agent-prototype-v1`。刷新保留数据；运行与同步延迟由本地定时器模拟。关闭页面后不执行任务，重新打开恢复尚未完成的模拟状态。日期、预算与来源均为演示配置，不产生费用。新主题的研究正文使用相同的固定演示模板，不是模型生成。

## 文件

- `src/main.jsx`：四个页面、抽屉、发布确认与响应式交互。
- `src/model.js`：可测试的状态转换、版本校验、记忆作用域、重算和删除抑制记录。
- `src/styles.css`：桌面/平板/手机布局。
- `src/model.test.js`：选中项发布、旧批准失效、记忆纠正、冲突/撤权、删除与取消测试。

浏览器验证包含主流程、刷新恢复、新建委托、冲突阻断和 1440 / 768 / 390 宽布局。正式产品仍需后端事务、真实权限、存储清理与实际模型集成。
