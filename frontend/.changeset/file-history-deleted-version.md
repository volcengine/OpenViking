## en-US

Keep the Deleted badge on confirmed deletions in the file history and comparison picker. Compare with an earlier version to see the removed content. Missing snapshot content for a tracked file appears as a read error.

## zh-CN

确认删除的版本会在文件历史和对比下拉框中保留「已删除」标记，与更早的版本对比可查看删除的内容。仍在快照中跟踪的文件如果缺失存储内容，则显示读取错误。
