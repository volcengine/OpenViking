## en-US

Keep the Deleted badge on confirmed file deletions in the history and comparison picker. The file must exist in the first parent. Older servers can confirm deletion through snapshot diff. Compare with an earlier version to see the removed content. Missing snapshot content for a tracked file appears as a read error.

## zh-CN

确认文件删除的版本会在文件历史和对比下拉框中保留「已删除」标记。该路径在首父提交中必须是文件，旧版服务端也可以通过快照差异确认删除。与更早的版本对比可查看删除的内容。仍在快照中跟踪的文件如果缺失存储内容，则显示读取错误。
