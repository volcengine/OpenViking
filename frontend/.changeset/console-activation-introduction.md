## en-US

Add `slots.activationIntro` to replace or hide the activation introduction while preserving Console's Enable, Retry and status controls. Add `labels.activationTitle` and `labels.activationDescription` for custom text, with empty strings hiding the respective text. Existing media and default presentation remain compatible, and presentation changes do not restart activation checks or reset the draft.

## zh-CN

新增 `slots.activationIntro`，可替换或隐藏启用页介绍，保留 Console 管理的启用、重试和状态。通过 `labels.activationTitle` 和 `labels.activationDescription` 覆盖文案，空字符串隐藏相应文案。现有媒体和默认展示保持兼容，展示配置变化不会重新查询启用状态或重置草稿。
