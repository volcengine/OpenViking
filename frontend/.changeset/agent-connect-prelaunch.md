## en-US

Add `AgentConnect.isPrelaunch` to use the prelaunch service endpoint across all displayed and copied integration instructions. When enabled it overrides `baseUrl`; existing endpoints remain unchanged by default.

## zh-CN

新增 `AgentConnect.isPrelaunch`，统一切换所有接入说明展示和复制内容中的预发布服务地址。开启时优先于 `baseUrl`，默认保持现有地址行为。
