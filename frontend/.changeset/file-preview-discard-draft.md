## en-US

Ask before discarding a modified file when cancelling an edit or navigating in FilePreview and FileBrowser. Hosts can use `confirmLeave()` before changing a controlled selection or leaving the page.

## zh-CN

FilePreview 和 FileBrowser 在取消编辑或切换内容前确认是否放弃未保存的文件改动。宿主可在切换受控选项或离开页面前调用 `confirmLeave()`。
