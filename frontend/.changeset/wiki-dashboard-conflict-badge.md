## en-US

Show a conflict count badge on Wiki dashboard tabs while viewing content or the dashboard. File badges count unresolved conflict records; directory badges count conflicting files. Hide unavailable and zero counts, cap the display at 99+, and refresh badges with the existing dashboard data.

## zh-CN

Wiki 看板页签在内容和看板视图中均展示冲突数量角标。文件按待解决冲突条数计数，目录按冲突文件数计数；未知及零值不显示，超过 99 显示 99+，并随已有看板数据刷新。
