## en-US

Add the optional `FileBrowser.hideDeniedEntries` setting to hide inaccessible tree entries while keeping traversal-only directories, pagination and permission checks. The default continues to show denied entries as disabled.

## zh-CN

新增可选的 `FileBrowser.hideDeniedEntries` 配置，隐藏目录树中无权访问的节点，同时保留可穿透目录、分页和权限检查。默认仍显示禁用的无权限节点。
