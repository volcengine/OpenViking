## en-US

Add optional FileBrowser props for hosts to save and restore expanded folders independently of the selected resource.

Hosts can also persist explicit collapses across mounts when home alias resolution is temporarily unavailable.

## zh-CN

FileBrowser 增加可选属性，支持宿主独立保存和恢复目录展开状态与选中资源。

主目录别名暂时无法解析时，宿主也可通过完整快照跨挂载保存手动折叠记录。
