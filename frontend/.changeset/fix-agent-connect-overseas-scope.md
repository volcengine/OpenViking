## en-US

Limit the AgentConnect Overseas tag to Codex, Claude Code and Cursor when `showOverseasTag` is `true`. Omitting the prop still tags only Codex and Claude Code, and `false` hides the tag for all agents.

## zh-CN

将 AgentConnect 在 `showOverseasTag` 为 `true` 时的「境外」标签范围限定为 Codex、Claude Code 和 Cursor。省略参数时仍仅标记 Codex 和 Claude Code，传入 `false` 时全部隐藏。
