## en-US

Track asynchronous tasks submitted from Console commands and VikingBot tool results through an instance-scoped scheduler. Share task queries across both modes, expose task snapshots on command records and tool parts, and show top-right notifications without blocking subsequent input. Add optional task query adapters for custom backends; keep query errors separate from task failures and cancel stale queries on identity changes.

## zh-CN

通过实例内调度器跟踪 Console 命令和 VikingBot 工具结果提交的异步任务。两种模式共用任务查询，在命令记录和工具项上展示任务快照，并通过右上角通知反馈进度，不阻塞后续输入。自定义后端可提供可选的任务查询适配器；查询错误与任务失败分别处理，身份变化时取消过期查询。
