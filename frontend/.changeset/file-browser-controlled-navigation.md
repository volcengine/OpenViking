## en-US

Updating a mounted `FileBrowser`'s controlled `uri` opens the preview and reveals the resource in the directory tree. Hosts that need a preview-only update can call `openResource(uri, { reveal: false })`. Use `defaultExpandedUri` to set the initial tree expansion.

## zh-CN

更新已挂载的 `FileBrowser` 的受控 `uri` 时，区块会打开预览并在目录树中定位资源。需要仅更新预览的宿主可调用 `openResource(uri, { reveal: false })`。用 `defaultExpandedUri` 设置初始展开位置。
