## en-US

Unify FileTree scrollbars across Chromium platforms with native macOS light and dark colors. Overflow reserves 12px for an 8px rounded thumb; the track and border appear only when hovering the scrollbar. macOS now uses a space-reserving scrollbar instead of following the system's automatic overlay visibility setting.

## zh-CN

统一 Chromium 各平台的 FileTree 滚动条样式，采用 macOS 原生浅色和暗色配色。内容溢出时占用 12px 空间，滑块宽 8px，轨道和边线仅在悬停滚动条时显示。macOS 也改用占位滚动条，不再跟随系统自动显示和隐藏悬浮滚动条的设置。
