## en-US

Export ContextPicker for controlled file and directory selection, with search, single or independent multiple selection, asynchronous selection restoration, automatic reveal and customizable footer actions. HITL custom answers can delegate selection to the host through onOpen. Reuse the same picker in built-in directory interactions and let hosts supply permission state.

## zh-CN
