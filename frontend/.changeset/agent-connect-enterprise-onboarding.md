## en-US

AgentConnect accepts `isEnterprise` to show English or Chinese team onboarding instructions for agents supported by the official installer, preserving API key masking and copying. Existing instructions remain the default.

## zh-CN

AgentConnect 新增 `isEnterprise`，为支持官方安装器的 Agent 展示中英文团队接入文案，复用 API Key 脱敏和复制逻辑。默认继续使用原有文案。
