## en-US

Support session auto-creation, memory policies, context token budgets, and retained message counts in Console. Send structured message parts, creation timestamps, and batch JSON. Session write commands accept boolean or JSON object telemetry options and display the telemetry summary returned by the server.

## zh-CN

Console 支持自动创建会话、配置记忆策略、设置上下文 Token 预算和保留消息数，并支持发送结构化消息片段、指定创建时间和批量写入 JSON 消息。会话写入命令接受布尔值或 JSON 对象类型的遥测参数，并展示服务端返回的遥测摘要。
