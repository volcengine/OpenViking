## en-US

Add optional, strongly typed analytics through OpenVikingProvider, disabled by default. Built-in interaction, outcome, and viewport exposure events use distinct targets. Hosts select events and provide delivery without analytics props on components. Add bilingual integration guidance, a runnable example, and an event catalogue generated from the type definitions.
