## en-US

Make VikingBot message dates keyboard-accessible copy actions for diagnostic JSON. Assistant dates copy message metadata; user dates copy metadata for the currently loaded messages. Add optional typed diagnostic identifiers to VikingBot and VikingBotMessageList, automatically include the current Console session ID, and report clipboard success or failure without fetching or exporting additional data.

## zh-CN

支持单击消息日期或使用键盘复制 VikingBot 排查 JSON：助手日期复制消息元数据，用户日期复制当前已加载消息的元数据。VikingBot 和 VikingBotMessageList 可接收明确类型的可选排查标识，Console 自动带入当前会话 ID，并反馈剪贴板复制成功或失败，不新增取数或后台导出。
