## en-US

Add FileTree.rowTrailingPosition with a default of 'viewport-end', keeping trailing content visible during horizontal scrolling. Set 'row-end' to retain the previous behavior of scrolling with the full row. FileBrowser uses this default so Wiki and experience dashboard actions remain visible. Pinned content follows the row's hover and selected colors in light and dark themes.

## zh-CN

新增 FileTree.rowTrailingPosition，默认值为 'viewport-end'，横向滚动时行尾内容保持在可视区域右侧。设置为 'row-end' 可保留原先随完整行横向滚动的行为。FileBrowser 使用此默认行为，让 Wiki 与经验看板入口保持可见。固定区域在浅色和暗色主题下跟随行的悬停与选中颜色。
