## en-US

Allow empty additional instructions in the built-in VikingBot clarification flow, including when a prefilled instruction is cleared. Keep names and source, target and skill selections required, and submit the optional instruction as an empty string.

## zh-CN

VikingBot 内置澄清流程的补充要求可留空，清空预填指令后也能提交，并以空字符串传递答案；名称、来源、输出目录和 Skill 的必填校验保持不变。
