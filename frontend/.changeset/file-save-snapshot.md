## en-US

After saving an editable ordinary file in FileBrowser, choose whether to keep a snapshot, then enter a description and save it. Snapshot failures retain the description for retry and do not undo the file save. Wiki compile files retain their automatic version history.

## zh-CN

FileBrowser 保存普通可编辑文件后，可选择是否保留快照，再填写描述并保存。快照失败会保留描述以供重试，不影响已保存的文件；Wiki 编译文件沿用自动版本历史。
