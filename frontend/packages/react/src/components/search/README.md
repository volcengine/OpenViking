# 搜索

检索入口、检索方式切换与高级筛选的视图与交互。查询条件、选项与结果由上层传入；提交、切换和筛选变更等意图通过事件回调上报，组件不发起检索请求，也不持有查询结果与分页状态。

`search.tsx` 对应 `@openviking/react/components/search`。当前是占位组件：只渲染固定尺寸的空壳，不消费 props，用于先行发布包供宿主对照 API。props 契约仍在定稿中，本模块暂不导出任何公开类型；真实实现随视图迁入，按本文重写。

## 职责边界

- **检索方式不进组件枚举**。宿主声明提供哪些检索方式及其文案，组件不内置方式清单，也不内置任一方式的参数面板。
- 筛选条件由宿主声明：可筛项、控件形态与取值都由上层给出，组件只渲染并上报变更。
- 提交只上报意图，请求组装、鉴权、结果排序与分页都在宿主侧。
- 结果由宿主传入，组件不请求、不缓存、不推断「无结果」的业务含义。

## 可选能力

部分字段表达的是宿主能力，不传即降级为对应表现：

| 字段     | 不传时         | 传值时的表现                 |
| -------- | -------------- | ---------------------------- |
| 检索方式 | 不显示方式切换 | 展示方式切换与当前方式说明   |
| 高级筛选 | 不显示筛选入口 | 展开后渲染宿主声明的筛选项   |
| 当前条件 | 不显示条件回显 | 以标签形式展示并可逐项移除   |
| 结果区   | 不渲染结果     | 按宿主给出的状态渲染结果列表 |
