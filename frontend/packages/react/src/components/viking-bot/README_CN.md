# VikingBot

[English](README.md) / 中文

展示宿主提供的会话消息，并提供输入区和待确认交互区：发送、停止、打开资源等操作通过回调交给宿主，组件不发起请求。

- 公开入口：`@openviking/react/components/viking-bot` 和 `@openviking/react/components/viking-bot/interaction`，样式 `@openviking/react/components/viking-bot/style.css`
- 文档：[组件文档](../../../../../docs/docs/zh/components/viking-bot.mdx)
