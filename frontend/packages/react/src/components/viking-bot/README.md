# VikingBot

预留对话、会话、流式回复和附件的视图与交互。
消息、会话、附件及回复状态由上层传入；发送、停止和上传等意图通过事件回调上报，组件不创建会话、上传附件或建立流式连接。

`viking-bot.ts` 对应 `@openviking/react/components/viking-bot`，当前为空模块，尚未提供组件或类型。

开发与构建入口见 [前端工作区 README](../../../../../README.md)，模块约定见[包说明](../../../README.md)。

独立样式入口为 `@openviking/react/components/viking-bot/style.css`，迁入实现前为空样式。
