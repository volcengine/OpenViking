# VikingBot

对话、会话、流式回复和附件的视图与交互。消息、会话、附件及回复状态由上层传入；发送、停止和上传等意图通过事件回调上报，组件不创建会话、上传附件或建立流式连接。

`viking-bot.tsx` 对应 `@openviking/react/components/viking-bot`。当前是占位组件：只渲染固定尺寸的空壳，不消费 props，用于先行发布包供宿主对照 API。真实实现按本文与类型声明重写，接口以源码为准，本文不重复列举。

## 职责边界

- 消息是宿主适配后的结构，组件不依赖任何上游消息协议。流式回复以增量片段的形式传入，连接与事件归宿主。
- 片段用联合类型表达，覆盖文本、推理、迭代、上下文引用、工具调用、工具结果、图片与附件；新增类型属于接口变更，需同步声明。
- 附件上传在宿主：组件只上报用户选择或拖入的文件，并按宿主给出的上传状态渲染。
- 消息列表与输入区可单独使用，也可由完整对话视图组合；命令式入口用于宿主快捷操作预填文本或追加文件。
- 消息上的额外动作（例如提交记忆）由宿主声明，组件只负责渲染入口。

## 可选能力

部分字段表达的是宿主能力，不传即降级为对应表现：

| 字段       | 不传时           | 传值时的表现               |
| ---------- | ---------------- | -------------------------- |
| 草稿       | 不展示输入区     | 展示受控输入区             |
| 流式片段   | 只渲染已完成消息 | 在指定位置追加生成中的片段 |
| 可用性     | 始终可输入       | 不可用时禁用输入并展示原因 |
| 虚拟列表   | 直接渲染全部消息 | 长历史启用虚拟滚动         |
| 头部与底部 | 不渲染           | 渲染宿主插槽内容           |
