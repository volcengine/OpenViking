# 资源导入

导入方式选择、文件选择、进度及结果展示。导入选项和任务状态由上层传入；选择、提交、取消和重试等意图通过事件回调上报，组件不上传文件、启动任务或轮询状态。

`resource-import.tsx` 对应 `@openviking/react/components/resource-import`。当前是占位组件：只渲染固定尺寸的空壳，不消费 props，用于先行发布包供宿主对照 API。真实实现按本文与类型声明重写，接口以源码为准，本文不重复列举。

## 职责边界

- **来源不进组件枚举**。宿主声明提供哪些来源、各自的图标与专属字段，组件不内置来源清单，也不内置任何来源的业务表单。
- 表单字段由宿主描述：控件类型决定使用哪种内置控件，无法归类的用自定义渲染交给宿主。
- 文件选择只上报用户选择的文件，上传、轮询与结果都由宿主负责；任务列表消费宿主整理好的任务状态。
- 目标目录通过目录选择回调交给宿主的目录选择器，组件不取目录树。
- 提交只上报意图，请求组装、鉴权与任务创建都在宿主侧。

## 可选能力

部分字段表达的是宿主能力，不传即降级为对应表现：

| 字段     | 不传时             | 传值时的表现                 |
| -------- | ------------------ | ---------------------------- |
| 文件列表 | 不展示已选文件     | 展示文件与各自的进度、错误   |
| 目标目录 | 不显示目标目录字段 | 展示当前目录与更换入口       |
| 额外动作 | 不显示             | 在提交按钮旁渲染宿主动作     |
| 任务列表 | 不渲染             | 按任务状态展示进度与重试入口 |
