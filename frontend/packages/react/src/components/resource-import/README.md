# 资源导入

预留导入方式选择、文件选择、进度及结果展示。导入选项和任务状态由上层传入；选择、提交、取消和重试等意图通过事件回调上报，组件不上传文件、启动任务或轮询状态。

`resource-import.ts` 对应 `@openviking/react/components/resource-import`，当前为空模块，尚未提供组件或类型。
`@openviking/react/components/resource-import/style.css` 为独立样式入口，迁入实现前为空样式。

开发与构建入口见 [Frontend workspace README](../../../../../README.md)，模块约定见[包说明](../../../README.md)。
