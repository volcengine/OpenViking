# FileBrowserActionBar

[English](README.md) / 中文

文件浏览区顶部的操作栏，固定两个操作：连接 Agent 和导入资源，由宿主决定显示哪几个以及点击后做什么。

- 公开入口：`@openviking/react/components/file-browser-action-bar`，样式 `@openviking/react/components/file-browser-action-bar/style.css`
- 文档：[组件文档](../../../../../docs/docs/zh/components/file-browser-action-bar.mdx)
