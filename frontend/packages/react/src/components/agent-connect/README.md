# Agent 接入

预留 Agent 选择、接入步骤、配置说明及连接状态视图。配置内容、凭证展示状态及连接结果由上层传入；组件通过事件回调上报用户意图，不创建凭证、执行鉴权或建立连接。

`agent-connect.ts` 对应 `@openviking/react/components/agent-connect`，当前为空模块，尚未提供组件或类型。
`@openviking/react/components/agent-connect/style.css` 为独立样式入口，迁入实现前为空样式。

开发与构建入口见 [Frontend workspace README](../../../../../README.md)，模块约定见[包说明](../../../README.md)。
