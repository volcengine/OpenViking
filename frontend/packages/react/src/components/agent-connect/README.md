# AgentConnect

English / [中文](README_CN.md)

A connection panel that lists mainstream agents and four developer options (MCP, CLI, API and SDK), with setup instructions and copyable code blocks in which the API key is masked by default with eight asterisks (`********`); revealing or copying retains the original value.
