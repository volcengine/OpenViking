# AgentConnect

[English](README.md) / 中文

Agent 接入面板，列出主流 Agent 和 MCP、CLI、API、SDK 四种开发方式，展示接入说明和可复制的代码块，其中的 API Key 默认脱敏。

说明卡片、代码块和表格统一使用 8px 圆角与主题面板背景，浅色模式下为白色，深色模式跟随主题。表格保留单层外框和单元格分隔线，边框随圆角裁切。

- 公开入口：`@openviking/react/components/agent-connect`，样式 `@openviking/react/components/agent-connect/style.css`
- 文档：[组件文档](../../../../../docs/docs/zh/components/agent-connect.mdx)
