# 目录树

接收节点、展开和选中状态，负责树行渲染与事件回传。目录加载、搜索定位和预览联动由宿主或资源浏览器管理。

`file-tree.ts` 对应 `@openviking/react/components/file-tree`，当前导出 props 类型，组件实现待迁入。接口以源码与类型声明为准，本文不重复列举。

## 职责边界

- 树结构由宿主持有。组件不拉取目录、不做分页、不保存展开状态；行的展开态、是否有子节点都由宿主算好后传入。
- 组件按宿主展平后的有序行列表渲染，不感知父子关系。分页、加载中、失败、空目录都是行的一种，由宿主插在正确位置。
- 选中与展开通过回调上报，组件不依赖回调返回值获取业务数据。
- 点击目录与点击文件共用同一个选中回调，由宿主按节点类型决定是切换目录还是打开文件；组件不区分「选中」与「打开」两段手势。
- 树整体加载失败与某个目录的子节点加载失败是两种状态，前者用整树级的错误插槽，后者是行。
- 工具栏、搜索、导入来源、权限流程都属于页面层，通过 `slots.toolbar` 注入。组件不知道有哪些来源，也不承担路由与鉴权。
- 三种整树级状态用 `loadingFallback`、`errorFallback`、`emptyFallback` 表达，与子节点区域的行状态互不干扰。

## 行的公共字段

行类型分两层继承，公共字段只声明一次：

- `FileTreeRowBase`：所有行都有 `id`（React key 与选中依据）和 `depth`（缩进层级）。
- `FileTreeChildRow`：子节点区域的行（加载中、加载更多、失败、空目录）在基类之上加 `parentId`。
- `FileTreeEntryRow` 继承基类而非 `FileTreeChildRow`，因为它本身就是树节点，不属于某个父节点的子节点区域。

## 可选能力

部分字段表达的是宿主能力，不传即降级为对应表现：

| 字段       | 不传时                 | 传值时的表现               |
| ---------- | ---------------------- | -------------------------- |
| 子节点信息 | 目录按「可以展开」处理 | 明确无子节点时不显示展开项 |
| 层级标记   | 不显示层级标记         | 在行尾显示摘要或上下文层级 |
| 过期时间   | 不显示过期提示         | 按过期时间给出提示         |
| 写入中     | 不显示写入进度         | 在行内显示进行中的写入     |

过期提示配合保留策略设置入口使用：传了过期时间但不传该回调时，提示里不出现设置按钮。

## 行内的宿主内容

两类内容由宿主渲染，组件只负责位置与交互：

- `renderDashboard`：行尾的看板指示器，例如经验看板或 wiki 看板入口。返回 `null` 即该行不显示；点击行为与折叠时的数量角标都由宿主在返回值里自行处理。
- `renderRowTooltip`：行的悬停浮层内容。返回 `null` 即不展示；延迟、定位与悬停抑制由组件处理。

看板判定属于产品语义，组件不内置路径规则，由宿主按自身路径推导后返回节点。

## 行级的一次性效果

高亮、闪烁、临时描边这类效果属于 UI 表现而非树的属性，由页面层实现。组件提供三种可选手段，可任选其一或组合使用：

1. **DOM 属性**：组件给每条行元素设置 `data-file-tree-row-id`，值等于行的 `id`；属性名以 `FILE_TREE_ROW_ATTRIBUTE` 常量导出。页面层可直接查询该元素后加类名或绘制覆盖层。
2. **`getRowAttributes` 回调**：需要按行数据决定属性时使用，返回的 `className` 与组件自身类名合并，其余属性覆盖到行元素上。
3. **`ref` 句柄**：需要滚动定位或反复取元素时使用，提供 `getRowElement(id)` 与 `scrollToRow(id, options)`。

三种方式都只作用于渲染结果，不改变组件状态，也不要求把效果写成 props。

`ref` 按 `forwardRef` 契约定义（类型 `FileTreeComponent`），ref 经第二个参数进入组件，React 18 与 19 都能拿到句柄；React 19 里写成普通 `ref` prop 同样可用。不要把它声明成 `FileTreeProps` 的字段——React 18 会把 `ref` 从 props 中剥离，那样声明在 18 下永远拿不到值。
