# Directory tour artwork

Source: user-provided OpenViking Console Figma file `ecpd1ZGHKRYibm1ODKEpM6`.
The six images correspond, in order, to nodes `10809:106850`, `10809:106871`,
`10809:106892`, `10809:106913`, `10809:125753`, and `10809:125774`.

Original raster artwork is resized for the displayed illustration slots at 2×
resolution and losslessly encoded as WebP. The build inlines the small files so
Node/SSR and consumers need no asset hosting or temporary Figma URLs.

Display sizes are 212×70, 216×72, 223×72, 216×72, 216×72, and 252×84.
The 72px illustration viewport clips the peers artwork as in the design.
