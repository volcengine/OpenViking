# DirectoryTour

A non-modal, step-by-step tour of the directories in your app: it highlights each directory row you locate and shows an explanation card beside it, without changing the selected file.

- Public entry: `@openviking/react/components/directory-tour`, styles `@openviking/react/components/directory-tour/style.css`
- Docs: [Component docs](../../../../../docs/docs/en/components/directory-tour.mdx)
