# TUI

[English](README.md) / 中文

必填 `locale: 'zh-CN' | 'en-US'` 选择内置中英文文案；已有 `labels` 可逐项覆盖，未覆盖项跟随当前语言。业务内容仍由宿主提供。

当前命令记录、结果与输入区的视图和交互。记录区、空态、输入、命令建议与参数帮助组成 TUI 主体。命令描述和执行记录由宿主传入；组件通过 `onSubmit` 上报提交意图，通过 `onCopy` 通知复制完成。

`tui.tsx` 对应 `@openviking/react/components/tui`。视图已按本文契约实现：渲染命令记录与结果、空态，以及带补全和参数提示的受控输入。字段清单以类型声明为准，本文不重复列举。

## 职责边界

- TUI 只包含命令记录与结果区、输入区及其建议和帮助。新建会话、历史记录面板、视图与用户切换、外层工具栏由宿主通过独立组件组合，不放进 TUI，也不提供对应插槽。
- 宿主处理新建会话、历史选择与清空，再更新 `records` 和 `value`；TUI 仅渲染当前传入的记录，不维护历史列表或专门的历史预览状态。
- 命令执行完全在宿主。组件使用宿主命令描述提供输入交互，执行结果按宿主给出的内容变体渲染。
- 结果内容用联合类型表达，包含通用文本与六种结构化结果；未归类结果通过通用文本展示。
- 输入是受控的。组件内部接受命令或示例后，通过 `onValueChange` 更新输入，不提交命令。
- 输入区是整宽的无边框编辑区域，带顶部分隔线，编辑区域最小高度 80px，底部快捷键引导高 40px。聚焦时分隔线保持原色。内容最多自适应增高至三行，超出后滚动；底部依次显示 `/ 全部指令`、`↑ 历史指令`、`↵ 发送`。↑/↓ 可回填当前记录中的命令，Enter 提交，Shift+Enter 换行，不单独渲染发送按钮。
- 输入 `o` 时会以灰字提示 `v`，按 Tab 接受前缀；也可直接按空格补成 `ov `。在 `ov ` 后按 Tab 打开全部命令，继续输入字母可筛选候选并预览剩余文字，再按 Tab 接受行内提示或已选中的命令。普通输入只显示行内提示，`/` 和显式 Tab 才展开列表；补全根据宿主的 `inputText` 推导。普通 Tab 始终保留输入区焦点：无补全、输入参数或光标位于中间时保持原值和页面位置；Shift+Tab 可移出输入区。灰字不会进入提交值。
- 输入 `/`，或在 `ov ` 后按 Tab，都会展开未选中任何命令的候选列表；筛选或重新打开时也清除选中状态。未选择时，↓ 从第一项开始，↑ 从最后一项开始。悬停或使用方向键选择后，侧边才显示示例与参数表。没有关键字也未选择候选时，Tab 不填入命令。横向空间不足时，详情与列表上下排列。Esc 或点击区域外可关闭浮层；不支持原生 Popover 的浏览器回退为内联面板。
- 输入区与命令记录统一使用灰色 CLI 前缀、正文色加重的命令名、链接色资源 URI；链接仅在 hover 时显示下划线。命令记录按同一份 `inputText` 显示，参数原样保留；时间单独位于下一行并右对齐。复制和历史回填使用相同前缀，未匹配目录的命令按原文显示。
- 宿主可传入 `createdAtMs`（Unix 毫秒）：组件显示“刚刚”、1 小时内的整分钟数、24 小时内的整小时数，之后显示本地时区的 `YYYY-MM-DD HH:mm`。无有效时间戳时回退到可选的 `createdAt` 展示字符串，不解析该字符串。SSR/hydration 先使用兜底文案，客户端接管后再格式化；时间随渲染重新计算，不设置独立定时刷新。`labels.justNow`、`labels.formatMinutesAgo` 和 `labels.formatHoursAgo` 可覆盖本地化时间文案。
- 接受命令后，输入区使用宿主提供的 `inputText` 前缀（默认 `name`）并按上述层级显示，后面直接显示位置参数提示；没有位置参数时显示必填选项。开始输入参数后占位收起，不写入受控值。完整详情仅在命令候选列表展开时展示。
- `locale` 选择英文（`en-US`）或中文（`zh-CN`）界面文案，`labels` 可逐项覆盖；命令和结果文案由宿主本地化。示例跟随文档站语言。
- `onSubmit` 上报显式提交意图。宿主负责请求、权限和执行，并通过 `records` 更新等待、成功或失败的记录；已有等待记录不阻止后续提交。
- `onOpenUri` 在输入区、命令气泡或结果中的 URI 链接激活时收到原始地址，由宿主负责打开。未传回调时，纯文本链接使用原生 `href`。
- 复制由组件完成，成功后通过 `onCopy` 通知宿主，参数为已复制的文本；失败时不触发该回调。省略回调不影响复制。
- 命令筛选、高亮、键盘选择、填入和参数帮助由组件处理。宿主提供 `commands` 和可选 `commandGroups`，包含本地化的说明、参数、选项及示例。组件不取数，不读写本地存储。
- `quickCommands` 列出内置空态展示的命令名称，按数组顺序从 `commands` 解析，未命中的名称跳过。标题、说明与列表由组件渲染，点击后填入并聚焦输入框，不提交命令。`emptyState` 会完全替换内置空态；传 `null` 不显示，两者都不传也不显示。
- 组件界面文案与引导提示统一通过 `labels` 配置。`disabled` 独立控制命令输入与提交的可用性，`labels.unavailableMessage` 提供禁用时的提示；仅设置文案不会禁用组件。

命令描述和分组由宿主提供，沿用现有描述和结果类型的新增命令无需发布组件。示例目录位于 `docs/docs/_demos/tui-commands/`，组件不再内置业务目录。省略 `commands` 时仍可输入和提交文本，但不展示候选或参数帮助。

结果卡片共用命令标题与带无障碍名称的状态图标。匹配到宿主命令时，标题使用其 `inputText`，不带参数，正文中的同名命令标题不重复显示。写入结果逐行使用独立底色，状态结果使用带底色的键值行；资源预览保留独立的正文布局，JSON 与 Markdown 代码块共用可复制的代码视图。命令成功不代表返回任务已经结束。空结果与帮助文案由 `labels.noResult`、`labels.availableCommands`、`labels.helpHint` 配置。

结果按七种 `TuiRecordContent` 变体分别渲染：`text`（纯文本或 Markdown，JSON 自动缩进）、`search-list`、`resource-preview`、`resource-tree`、`status`、`write-result` 与 `command-help`。输入区、命令气泡、Markdown 和结构化结果字符串中的资源 URI 链接共用 `onOpenUri`。自定义 ReactNode 内部的链接由宿主处理。点击输入区链接不会改变或提交命令；Shift+Tab 可聚焦链接，再按 Enter 激活。`resource-tree` 在有 `detailRows` 时按列对齐成表格，否则逐行展示并每 20 条分页。

## 结果内容

`TuiRecordContent` 包含 `text`、`search-list`、`resource-preview`、`resource-tree`、`status`、`write-result` 和 `command-help` 七种变体。

- `text` 通过 `format` 区分 `plain` 与 `markdown`，缺省为 `plain`。JSON 格式化后作为文本展示。
- 失败通过 `TuiRecord.status: 'error'` 表达，错误正文使用通用文本，不单独定义错误内容变体。
- 命令帮助内容与其他执行结果均由宿主使用现有结果类型提供。

从 CLI 输出到这些变体的转换仍由宿主负责，组件不解析命令输出。

## 可选能力

部分字段表达的是宿主能力，不传即降级为对应表现：

| 字段           | 不传时         | 传值时的表现                                                     |
| -------------- | -------------- | ---------------------------------------------------------------- |
| 空态           | 不显示         | `quickCommands` 渲染内置空态；`emptyState` 替换它，`null` 不显示 |
| 检索层级与类型 | 不显示对应标签 | 分别在标题旁和分数旁展示标签                                     |
| 分数详情       | 分数仅显示文本 | 提供分数文案时，悬停或聚焦显示宿主详情内容                       |

记录为 `pending` 时，组件按命令名或别名匹配宿主目录，使用描述的可选 `skeleton`；未提供或未识别时使用通用骨架。等待时可省略 `content`。

`disabled` 缺省为 `false`。设为 `true` 时禁用命令输入与提交，并展示 `labels.unavailableMessage`；未覆盖该文案时使用当前 `locale` 的默认提示。

## 开发入口

开发与构建入口见 [前端工作区 README](../../../../../README.md)，模块约定见[包说明](../../../README.md)。

独立样式入口为 `@openviking/react/components/tui/style.css`。类名使用 `ov-tui__<元素>`，颜色取自 `--ov-ui-*` 主题变量并带主题中性的回退值，浅色与暗色宿主下都可直接使用。
