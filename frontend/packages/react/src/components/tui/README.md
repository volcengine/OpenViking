# TUI

当前命令记录、结果与输入区的视图和交互。记录区、空态、输入、命令建议与参数帮助组成 TUI 主体。执行结果由上层传入；命令发送、资源打开和复制成功后通过回调通知宿主，失败时不触发对应回调。

`tui.tsx` 对应 `@openviking/react/components/tui`。当前是占位组件：只渲染固定尺寸的空壳，不消费 props，用于先行发布包供宿主对照 API。真实实现按本文与类型声明重写，接口以源码为准，本文不重复列举。

## 职责边界

- TUI 只包含命令记录与结果区、输入区及其建议和帮助。新建会话、历史记录面板、视图与用户切换、外层工具栏和底部快捷键说明由宿主通过独立组件组合，不放进 TUI，也不提供对应插槽。
- 宿主处理新建会话、历史选择与清空，再更新 `records` 和 `value`；TUI 仅渲染当前传入的记录，不维护历史列表或专门的历史预览状态。
- 命令执行完全在宿主。组件复用共享命令元数据提供输入交互，执行结果按宿主给出的内容变体渲染。
- 结果内容用联合类型表达，包含通用文本与六种结构化结果；未归类结果通过通用文本展示。
- 输入是受控的。组件内部接受补全或参数提示后，通过 `onValueChange` 更新输入，不提交命令。
- `onSubmit` 仅在命令成功发送后通知命令文本，发送失败时不触发。该通知不承担发送，也不表示后台命令已执行完成；发送过程不依赖通知的返回值。宿主通过 `records` 更新后续结果与错误；后台任务记录仍为 `pending` 时，不阻止后续提交。
- `onOpenUri` 在资源成功打开后通知已打开的 URI，失败时不触发；导航执行能力由接入层负责。
- 复制由组件完成，成功后通过 `onCopy` 通知宿主，参数为已复制的文本；失败时不触发该回调。省略回调不影响复制。
- 命令匹配、候选列表、高亮与键盘选择、参数提示及帮助面板由组件内部统一处理。命令名称、参数、说明和示例必须复用 CLI 的同一份命令元数据，宿主不逐条维护或渲染命令帮助；组件不自行取数或读写本地存储。
- `emptyState` 是完整空态的唯一配置入口，可组合标题、说明和快捷入口，相关交互由宿主在节点内处理。无记录时展示该节点；省略时使用 `labels.empty`，传 `null` 时隐藏空态内容。
- 组件界面文案与引导提示统一通过 `labels` 配置。`disabled` 独立控制命令输入与提交的可用性，`labels.unavailableMessage` 提供禁用时的提示；仅设置文案不会禁用组件。

当前仅定义接口边界，尚未实现补全、帮助面板或接入 CLI 共享命令元数据；新增 CLI 命令的自动同步需在真实实现中打通该链路。元数据加载与传输应通过共享适配层接入，不把请求或逐命令适配放入各宿主。

## 结果内容

`TuiRecordContent` 包含 `text`、`search-list`、`resource-preview`、`resource-tree`、`status`、`write-result` 和 `command-help` 七种变体。

- `text` 通过 `format` 区分 `plain` 与 `markdown`，缺省为 `plain`。JSON 格式化后作为文本展示。
- 失败通过 `TuiRecord.status: 'error'` 表达，错误正文使用通用文本，不单独定义错误内容变体。
- 命令帮助由共享命令定义生成，其他结果由共享适配层统一转换；宿主复用转换结果，不逐条适配命令。

这些变体定义统一展示的目标契约；共享结果转换和实际视图仍待实现。

## 可选能力

部分字段表达的是宿主能力，不传即降级为对应表现：

| 字段           | 不传时              | 传值时的表现                               |
| -------------- | ------------------- | ------------------------------------------ |
| 空态节点       | 展示 `labels.empty` | 无记录时展示完整节点，传 `null` 时隐藏     |
| 检索层级与类型 | 不显示对应标签      | 分别在标题旁和分数旁展示标签               |
| 分数详情       | 分数仅显示文本      | 提供分数文案时，悬停或聚焦显示宿主详情内容 |

记录为 `pending` 时，组件根据 `command` 匹配共享命令定义并选择对应骨架，无法匹配时使用通用骨架。等待期间可省略 `content`，宿主无需指定骨架形态。

`disabled` 缺省为 `false`。设为 `true` 时禁用命令输入与提交，并展示 `labels.unavailableMessage`；未覆盖该文案时使用内置英文提示。
