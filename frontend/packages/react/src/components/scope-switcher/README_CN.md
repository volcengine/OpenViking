# ScopeSwitcher

[English](README.md) / 中文

由多级独立选择器组成的作用域面包屑：`ScopeSwitcher` 负责排列，每一级（例如库、数据空间、用户）用一个 `ScopeSelector` 展示当前值并切换。

- 公开入口：`@openviking/react/components/scope-switcher`，样式 `@openviking/react/components/scope-switcher/style.css`
- 文档：[组件文档](../../../../../docs/docs/zh/components/scope-switcher.mdx)
