# 作用域选择

预留作用域选项、搜索、选中状态及切换交互。选项、加载状态和可操作状态由上层传入；组件通过事件回调上报搜索和切换意图，不查询或持久化账号、数据库、数据空间或 User。

`scope-switcher.ts` 对应 `@openviking/react/components/scope-switcher`，当前为空模块，尚未提供组件或类型。
`@openviking/react/components/scope-switcher/style.css` 为独立样式入口，迁入实现前为空样式。

开发与构建入口见 [Frontend workspace README](../../../../../README.md)，模块约定见[包说明](../../../README.md)。
