# 作用域选择

作用域选项、搜索、选中状态及切换交互。选项、加载状态和可操作状态由上层传入；组件通过事件回调上报搜索和切换意图，不查询或持久化账号、数据库、数据空间或用户。

`scope-switcher.tsx` 对应 `@openviking/react/components/scope-switcher`。当前是占位组件：只渲染固定尺寸的空壳，不消费 props，用于先行发布包供宿主对照 API。真实实现按本文与类型声明重写，接口以源码为准，本文不重复列举。

## 职责边界

- 组件不认识「工作空间 / 账号 / 用户」的语义。宿主用层级数组声明有几个层级、各自叫什么、选项从哪来。
- 层级数量与语义由宿主决定：可以只声明一层，也可以声明数据空间 → 账号 → 用户三层；差异只体现在层级的数量与顺序，组件本身不变。
- 搜索关键字、分页、加载与错误全部受控；切换只上报选中项，持久化与路由同步由宿主完成。
- 层级内的附加动作（新建、编辑、删除）由宿主声明，组件只负责渲染入口与禁用态。

## 可选能力

部分字段表达的是宿主能力，不传即降级为对应表现：

| 字段     | 不传时         | 传值时的表现           |
| -------- | -------------- | ---------------------- |
| 搜索     | 不显示搜索框   | 下拉内提供搜索与筛选   |
| 分页     | 只展示当前选项 | 滚动到底部时请求下一页 |
| 只读     | 渲染下拉       | 固定作用域，直接展示值 |
| 层级动作 | 不显示动作区   | 下拉底部展示动作入口   |
