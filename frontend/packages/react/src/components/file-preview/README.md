# 文件预览

接收宿主已读取的内容与预览状态，渲染文本、Markdown、JSON 或媒体。文件读取、编辑、保存和权限由宿主或功能模块管理。

`file-preview.ts` 对应 `@openviking/react/components/file-preview`，当前导出 props 类型，组件实现待迁入。接口以源码与类型声明为准，本文不重复列举。

## 职责边界

- 预览不读取文件。内容由宿主按内容种类组装后传入，包括文本、媒体地址、截断信息与失败原因。
- 读取被截断时通过回调请宿主继续加载；读取失败用内容上的错误字段表达，不用抛错。
- 编辑是可选能力：不传编辑态即为只读。保存、放弃都由宿主执行，组件只上报意图并展示保存中与失败状态。
- 目录摘要页签与业务扩展页签通过插槽注入，通用预览不硬编码任何业务。
- 标题栏动作、权限标记、关闭与下载入口由宿主提供或声明，组件不判断权限。

## 可选能力

部分字段表达的是宿主能力，不传即降级为对应表现：

| 字段     | 不传时         | 传值时的表现             |
| -------- | -------------- | ------------------------ |
| 编辑态   | 只读           | 提供编辑、保存与放弃入口 |
| 摘要页签 | 不显示摘要页签 | 目录预览上方出现对应页签 |
| 扩展页签 | 不显示扩展页签 | 在内置页签之后追加       |
| 下载动作 | 不显示下载入口 | 展示下载按钮             |
