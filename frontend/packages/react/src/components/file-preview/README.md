# 只读文件预览

接收宿主已读取的内容与预览状态，渲染文本、Markdown、JSON 或媒体。文件读取、编辑、保存和权限由宿主或功能模块管理。

`file-preview.ts` 对应 `@openviking/react/components/file-preview`，当前为空模块，尚未提供组件或类型。

开发与构建入口见 [前端工作区 README](../../../../../README.md)，模块约定见[包说明](../../../README.md)。

经验看板通过扩展页签接入，视图可在模块内拆分；经验取数和统计处理由页面层负责，通用预览不硬编码经验业务。

独立样式入口为 `@openviking/react/components/file-preview/style.css`，迁入实现前为空样式。
