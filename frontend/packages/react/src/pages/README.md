# 页面组合层

`pages/` 组织可嵌入的完整页面，组合 `components/` 中的纯视图组件，负责获取数据、处理响应与业务状态，再将视图数据和事件回调传给组件。

## 职责

- 连接数据源，管理加载、空态、错误、分页、刷新和重试等页面状态。
- 将接口响应转换为组件需要的数据，通过组件事件发起后续数据操作。
- 协调多个组件的选中资源、查询条件和操作结果；组件自身仍保持纯视图职责。
- 具体路由、宿主导航及必要的服务配置由 Studio 等消费应用接入。

依赖方向为 `pages → components`。通用的展示与交互放在 `components/`，页面私有的数据处理、Hook 和类型留在对应页面目录。

## 当前状态与开发入口

当前仅预留目录和约定，尚无页面实现、公开导出或独立构建入口。后续每个页面使用独立的 kebab-case 目录，入口文件与目录同名。

开发命令和构建入口见 [UI workspace README](../../../../README.md)，包结构见[包说明](../../README.md)，实施约束见本目录 [AGENTS.md](./AGENTS.md)。
