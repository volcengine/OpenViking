# SVG sources

The five icons in `svg/` are original artwork created for this workspace. They follow the repository license. React imports these SVG files directly during its build.

The `svg/scope-switcher/` chevron and check assets are unmodified exports from the user-provided [OpenViking Console design](https://www.figma.com/design/ecpd1ZGHKRYibm1ODKEpM6/OpenViking-Console?node-id=10325-138037). Chevron: `I10325:138037;9343:425920` (14 × 14); check: `10325:138844` (16 × 16). They follow this repository's license and are bundled by ScopeSwitcher; no private IconBox dependency is used.
