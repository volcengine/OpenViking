# File-type icons

Source: @pierre/trees 1.0.0-beta.4 — https://github.com/pierrecomputer/pierre
Copyright 2025 Pierre Computer Company. Apache-2.0; see LICENSE.md in this directory.

Each file holds one icon, extracted from the upstream `builtInIcons` map and
converted from an inline body string into a standalone SVG. Artwork is unchanged:
16 × 16 viewBox, `currentColor` fills. Brand colours per icon live in
`packages/icons/file-type-rules.json` alongside the name and extension rules.
