# File browser icons

- `search-filter.svg` comes from the supplied `Frame.svg`. The 28 × 28
  viewBox and paths are unchanged. Its stroke inherits the button's theme color.
  The artwork follows the repository license.
- `file-04.svg` and `search-close.svg` are exported from the OpenViking Console
  search dialog. Their original dimensions and paths are unchanged; their
  strokes inherit the theme color. The artwork follows the repository license.
- `search-advanced-close.svg`, `search-folder-open.svg` and
  `search-chevron-down.svg` are exported from the advanced search panel. Their
  original dimensions and paths are unchanged; their colors follow the theme.
