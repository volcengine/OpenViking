## 前端请求

| 事件                     | source.component | region         | params 字段组  | 触发口径                                                                                                                          |
| ------------------------ | ---------------- | -------------- | -------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `client_request_success` | `ComponentName`  | `所属组件区域` | `RequestReady` | Provider 管理的单次非流式 Client 请求完成响应体读取和现有业务错误判定；JSON/envelope/blob 共用一次尝试，不在 fetch 返回时提前报。 |
| `client_request_fail`    | `ComponentName`  | `所属组件区域` | `RequestFault` | 同次请求在配置解析、传输、读体或既有业务错误判定失败；HTTP 200 错误外壳也失败。调用中止不报，合法非 JSON 响应不额外改判。         |
