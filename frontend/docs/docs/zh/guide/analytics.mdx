# 埋点

通过 `OpenVikingProvider.analytics` 接收业务组件和区块的操作、结果及曝光事件，由宿主对接自己的埋点平台。

## 接入

根 Provider 省略 `analytics` 时关闭采集，不创建埋点事件、曝光观察器或操作计时。配置 `onEvent` 后开启；组件和区块无需增加埋点 Props。

```tsx
import { OpenVikingProvider } from '@openviking/react/client';
import type { OpenVikingAnalyticsOptions } from '@openviking/react/client';

const analytics = {
  onEvent(event) {
    // 在宿主接入层调用自己的 SDK，并补充页面、来源和用户身份。
    hostAnalytics.track(event.name, {
      ...event.params,
      instanceId: event.instanceId,
    });
  },
} satisfies OpenVikingAnalyticsOptions;

<OpenVikingProvider analytics={analytics}>{children}</OpenVikingProvider>;
```

`hostAnalytics` 和 `children` 由宿主提供。组件库不包含埋点 SDK，不主动向埋点平台发请求。

### 选择事件

省略 `events` 时接收全部内置事件，传 `[]` 时不接收任何事件。每个名称都受到类型约束，按名称判断后，`params` 收窄为该事件的参数类型。

```tsx
const analytics = {
  events: [
    'openviking_file_preview_copy_path_click',
    'openviking_file_browser_search_success',
  ],
  onEvent(event) {
    if (event.name === 'openviking_file_browser_search_success') {
      console.log(event.params.result_count, event.params.duration_ms);
    }
  },
} satisfies OpenVikingAnalyticsOptions;
```

### Provider 作用域

嵌套 Provider 省略 `analytics` 时继承外层，传 `false` 时关闭当前子树，传配置对象时替换外层配置。一个采集点只投递给最近的有效配置，不同时上报内外两层。切换配置不重新请求业务数据，也不回放关闭期间的操作。

`onEvent` 可以返回 `Promise<void>`。上报不阻塞业务操作；同步抛错或 Promise 拒绝均被隔离，库不自动重试或缓存事件。需要重试、采样或批量发送时，在宿主接入层处理。

## 事件约定

- 事件名固定为 `openviking_<目标>_<事件>`。复制路径与复制正文、接入指南与代码块分别定义，不用一个事件兼指多个目标。
- 业务组件的提交或点击只表达用户意图；实际执行所在的区块或内部执行器报告成功、失败。宿主接管执行时，库不推断宿主的业务结果。
- `console_command_accepted` 表示关联异步任务已受理；关联任务全部成功后才发 `console_command_success`。任务查询失败不作为任务执行失败。
- `file_preview_download_start` 表示浏览器下载已发起，不能据此判断文件已保存到本地。
- `file_preview_save_success` 的 `version_status: 'not-created'` 表示正文保存成功但版本未创建；`'unknown'` 表示保存接口未明确版本状态。
- 取消与失败分开。请求因组件卸载、作用域切换而失效时，不补发旧请求的成功或失败。

### 曝光

`*_show` 和 `directory_tour_start` 在目标进入可视区域且页面处于前台后触发，要求相交区域宽高均大于零；隐藏、加载中的正文和后台预览层不计曝光。同一目标在同一次展示周期内只报一次，重渲染、滚出后滚入、标签页切回不会重复。弹窗关闭后重新打开、引导切换步骤或切换预览目标会开始新周期。

曝光使用 `IntersectionObserver`，不判断目标是否被其他元素遮挡。不支持该 API 的环境跳过自动曝光。关闭配置后再次开启不会补发历史操作；尚未曝光且此时可见的目标可以首次上报。

### 公共字段与数据范围

| 字段         | 说明                                     | 类型                                       |
| ------------ | ---------------------------------------- | ------------------------------------------ |
| `name`       | 固定事件名，用于收窄 `params`            | `OpenVikingAnalyticsEventName`             |
| `params`     | 该事件的参数；无参数的事件为 `{}`        | `OpenVikingAnalyticsEventMap[typeof name]` |
| `instanceId` | 采集点实例标识，不是用户、账号或资源标识 | `string`                                   |

`operation_id` 关联同一次操作的提交与结果；`duration_ms` 是从操作开始到当前阶段的毫秒数，`step_index` 从零开始。`error_kind` 只提供固定分类，不包含错误原文。

`has_filters` 表示当前检索方式是否启用了实际支持的显式筛选。默认根目录不计入筛选，仅选择时间字段而未设置日期也不计入。

内置事件不采集完整 URI、文件路径、文件名、查询词、命令原文、消息和文件正文、邮箱、密码或 API Key。页面、来源、用户身份及平台自定义字段由宿主在 `onEvent` 中补充。

## API

类型均从 `@openviking/react/client` 导出。

### OpenVikingAnalyticsOptions

| 参数      | 说明                                 | 类型                                                         | 默认值       |
| --------- | ------------------------------------ | ------------------------------------------------------------ | ------------ |
| `onEvent` | 接收筛选后的事件，上报异常不影响业务 | `(event: OpenVikingAnalyticsEvent) => void \| Promise<void>` | 必填         |
| `events`  | 选择要接收的内置事件                 | `readonly OpenVikingAnalyticsEventName[]`                    | 全部内置事件 |

`OpenVikingProviderProps.analytics` 的类型是 `OpenVikingAnalyticsOptions | false`，根 Provider 默认关闭。`OpenVikingAnalyticsEventMap` 提供逐事件参数映射，`OpenVikingAnalyticsEvent` 是可以按 `name` 收窄的联合类型。
