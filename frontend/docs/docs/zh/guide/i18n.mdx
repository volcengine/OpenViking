# 国际化

业务组件和区块内置简体中文和英文两套文案，通过 `locale` 切换，不依赖 i18next 等翻译库。

## 设置语言

`locale` 的取值是 `'zh-CN' | 'en-US'`，按下面的顺序取第一个有值的：

1. 组件自己的 `locale`
2. 组件所在区块的 `locale`
3. 最近的 `OpenVikingProvider` 的 `locale`，嵌套的 Provider 省略时继承外层
4. 默认值 `'en-US'`

在应用根部的 `OpenVikingProvider` 上设置一次，其余业务组件和区块都可以省略 `locale`。区块的语言同时作用于区块内置视图和你传入的插槽。

## 覆盖文案

每个业务组件和区块的 `labels` 用来修改单条文案：

- 传入的字段优先于当前语言的默认文案。
- 省略或为 `undefined` 的字段使用当前语言的默认文案，切换语言后随之更新。
- 空字符串保留为显式覆盖，对应文案显示为空。
- 嵌套对象逐键合并，覆盖一个字段不会丢掉其他默认项。

业务内容、插槽和回调里的文案由你提供，不随 `locale` 翻译。

## 切换语言

切换语言只更新界面文案，不会重新发起请求，也不会清空记录、会话或输入草稿。服务端返回的内容、错误原文、AI 回复和用户输入保持原样，不做翻译。
