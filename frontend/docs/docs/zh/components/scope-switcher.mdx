# ScopeSwitcher 作用域选择

作用域面包屑。宿主声明有几个层级、各自叫什么；组件负责渲染并上报搜索与切换意图。

当前是占位组件：只渲染一个固定尺寸的空壳，不消费 props，宿主可先对着已发布的包开发，真实视图后续迁入。下方的 props 契约是最终形态，占位实现会被替换。

## 基础用法


占位尺寸为 640 × 40，对齐头部作用域条。

## 属性

公开的 props 从同一子路径以类型导出，以源码为准：

```tsx
import type { ScopeSwitcherProps } from '@openviking/react/components/scope-switcher';
```

| 属性     | 类型 | 默认值 | 说明                       |
| -------- | ---- | ------ | -------------------------- |
| 其余属性 | —    | —      | 占位组件不消费任何 props。 |

```tsx
import { ScopeSwitcher } from '@openviking/react/components/scope-switcher';
import '@openviking/react/components/scope-switcher/style.css';
```

## 实现范围

组件只渲染视图并上报意图。取数、持久化、权限与任何网络连接都由宿主负责。
