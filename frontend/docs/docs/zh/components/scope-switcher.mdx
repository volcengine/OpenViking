# ScopeSwitcher 作用域选择

由独立选择器组合的作用域面包屑。`ScopeSwitcher` 只负责布局；每一级宿主独立维护请求、选项、加载/错误和搜索状态，并渲染一个 `ScopeSelector`。

业务侧只传三个接口即可接入的用法见 [ScopeCascade 级联选择](../modules/scope-cascade)。下方保留纯视图层的自定义接入示例。

## 基础用法

```tsx file="../../_demos/scope-switcher-basic.tsx" preview

```

```tsx
<ScopeSwitcher>
  <LibrarySelector />
  <SpaceSelector />
  <UserSelector />
</ScopeSwitcher>
```

各级宿主直接返回 `ScopeSelector`，不额外包裹 DOM。CSS 在相邻选择器间添加分隔符。固定层级与可切换层级可混用，不需要的层级直接省略。窄屏自动换行，手机使用底部面板。

## 更新边界

原来的 `levels` 数组接口已替换成 `children`。根组件没有共享状态、数据订阅或变化的 Context 值。各级选择器默认独立维护展开状态，选中后关闭面板；传入 `visible` 时可由本级宿主控制。搜索、选项和请求也各归本级宿主，不使用 `memo`。

静态示例为每个实例创建独立的身份数据源，各级通过 `useSyncExternalStore` 订阅自己的通道。只有本级选中身份或祖先身份变化才替换快照：换库更新库并清空空间、用户；换空间更新空间并清空用户；换用户只更新用户。先更新全部受影响快照，再通知订阅者，避免读到混合身份。重复选择同一身份不更新。请求、搜索和展开状态不进入共享数据源。

该数据源只是**宿主接入示例**，不是库强制要求的 Store，也不是全局单例。已有数据层可提供相同的定向订阅能力。祖先身份作为下游宿主子树的 `key`，变化时重置旧选项、搜索、错误、展开状态，并取消旧请求。本级选中值变化不会重新请求本级列表。边界外的祖先更新仍可能触发普通 React 渲染，这个接口不承诺隔绝任意祖先更新。

## 属性

`ScopeSwitcherProps` 为标准 `HTMLAttributes<HTMLDivElement>`，包含 `children`、`className`、`style` 等，不再接收 `levels` 或共享文案。

`ScopeSelectorProps` 包含必填 `level: ScopeSwitcherLevel` 和可选 `labels: ScopeSwitcherLabels`。

层级公共字段：`kind`、`key`、`selectedLabel`，可选 `ariaLabel`、`icon`、`tag`。`kind: 'fixed'` 只显示不可交互的标签；`kind: 'selectable'` 还接收：

| 字段                                     | 行为                                                               |
| ---------------------------------------- | ------------------------------------------------------------------ |
| `options`、`selectedId`                  | 必填，宿主持有选项和选择，未选择时 id 传 `''`。                    |
| `disabled`、`busy`                       | 分别禁用触发器、全部选项行。                                       |
| `loading`、`error`                       | 用加载态或错误态替换列表。                                         |
| `visible`、`onVisibleChange`             | 可选受控展开状态及通知；不传 `visible` 时独立维护。                |
| `onSelect(option)`                       | 关闭面板并上报选择意图，宿主更新身份。                             |
| `searchKeyword`、`onSearchKeywordChange` | 本级宿主控制搜索，不传回调则不显示搜索框。                         |
| `total`                                  | 已加载数或总数超过 10，或搜索词非空时显示搜索框。                  |
| `onScroll(metrics)`                      | 传出 `scrollTop`、`scrollHeight`、`clientHeight`，分页由宿主处理。 |
| `renderPanel({ search, list })`          | 组合标题、操作及底部入口。                                         |
| `renderOption(content, option)`          | 扩展或替换行内容，内嵌按钮/链接不触发行选择。                      |
| `emptyFallback`、`errorFallback`         | 自定义空态、错误态和重试入口。                                     |

选项必填 `id`、`label`，可选 `icon`、`description`、`disabled`。文案包含 `loading`、`searchPlaceholder`、`empty`、`noMatch`、`error`，默认英文，本地化文案传给各级选择器。

方向键及 Home/End 移动焦点，Enter/空格选择，Escape 关闭并返回触发器。点击外部或焦点离开时关闭面板。触发器尺寸、图标及选项间 4px 间距保持不变。

```tsx
import {
  ScopeSwitcher,
  ScopeSelector,
} from '@openviking/react/components/scope-switcher';
import '@openviking/react/components/scope-switcher/style.css';
```
