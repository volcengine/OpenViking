# ScopeSwitcher 作用域选择

由多级独立选择器组成的作用域面包屑：`ScopeSwitcher` 负责排列，每一级（例如库、数据空间、用户）用一个 `ScopeSelector` 展示当前值并切换。

## 何时使用

- 在页面头部用面包屑展示并切换库、数据空间、用户等多级作用域。
- 需要自己控制每一级的请求、选项、搜索和分页时：组件只负责展示，不发起请求，也不需要 `OpenVikingProvider`。
- 只想传入三个加载函数完成「库 → 数据空间 → 用户」级联时，使用 [ScopeCascade](../modules/scope-cascade)，它已内置 ScopeSwitcher。

## 引入

```tsx
import {
  ScopeSwitcher,
  ScopeSelector,
} from '@openviking/react/components/scope-switcher';
import '@openviking/react/components/scope-switcher/style.css';
```

## API

### ScopeSwitcher

| 参数             | 说明                                                                                        | 类型                 | 默认值                   |
| ---------------- | ------------------------------------------------------------------------------------------- | -------------------- | ------------------------ |
| children         | 各级的 `ScopeSelector`，从左到右排列，相邻两级之间自动绘制分隔符 `/`                        | `ReactNode`          | -                        |
| locale           | 其中所有 `ScopeSelector` 的界面语言，规则见[国际化](../guide/i18n)；同时写入根节点的 `lang` | `'zh-CN' \| 'en-US'` | 继承上级，默认 `'en-US'` |
| className、style | 外观与布局，其余 HTML 属性透传到根元素                                                      | HTML 属性            | -                        |

### ScopeSelector

| 参数     | 说明                                                                                    | 类型                      | 默认值                   |
| -------- | --------------------------------------------------------------------------------------- | ------------------------- | ------------------------ |
| kind     | 层级形态：`'fixed'` 只显示当前值，不可点击；`'selectable'` 显示可展开的触发器和下拉面板 | `'fixed' \| 'selectable'` | 必填                     |
| identity | 层级的标识、无障碍名称和末尾标记                                                        | `ScopeSwitcherIdentity`   | 必填                     |
| trigger  | 触发器上显示的文本和图标；`fixed` 层级没有 `data`，需要在这里提供 `label`               | `ScopeSwitcherTrigger`    | -                        |
| data     | 选项和当前选中项，`fixed` 层级不接收                                                    | `ScopeSwitcherData`       | `selectable` 时必填      |
| state    | 加载、错误、禁用、展开和搜索词等交互状态，仅 `selectable` 接收                          | `ScopeSwitcherState`      | -                        |
| actions  | 选择、展开、搜索和滚动的回调，仅 `selectable` 接收                                      | `ScopeSwitcherActions`    | -                        |
| slots    | 替换面板、选项行、空态和错误态的内容，仅 `selectable` 接收                              | `ScopeSwitcherSlots`      | -                        |
| labels   | 覆盖界面文案                                                                            | `ScopeSwitcherLabels`     | -                        |
| locale   | 界面语言，规则见[国际化](../guide/i18n)                                                 | `'zh-CN' \| 'en-US'`      | 继承上级，默认 `'en-US'` |

`ScopeSelectorProps` 是 `ScopeSelectorFixedProps` 与 `ScopeSelectorSelectableProps` 的联合类型，两者共有的属性定义在 `ScopeSelectorBaseProps` 中。

### ScopeSwitcherIdentity

| 参数      | 说明                                                                                              | 类型        | 默认值 |
| --------- | ------------------------------------------------------------------------------------------------- | ----------- | ------ |
| key       | 层级的稳定标识，例如 `'library'`、`'space'`、`'user'`，供宿主区分层级，组件不读取它               | `string`    | 必填   |
| ariaLabel | 触发器和面板的无障碍名称，例如「切换库」；不传时触发器没有 `aria-label`，面板以触发器上的文本命名 | `string`    | -      |
| tag       | 触发器末尾的标记，例如套餐名                                                                      | `ReactNode` | -      |

### ScopeSwitcherTrigger

| 参数  | 说明                                                                                                                                 | 类型        | 默认值 |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------ | ----------- | ------ |
| label | 触发器上显示的当前值；不传时取 `data.options` 里 `selectedId` 对应项的 `label`，都没有时为空。当前值不在已加载的选项里时，由宿主提供 | `string`    | -      |
| icon  | 触发器上的图标或头像；不传时使用选中项的 `icon`                                                                                      | `ReactNode` | -      |

### ScopeSwitcherData

| 参数           | 说明                                                                                       | 类型                             | 默认值           |
| -------------- | ------------------------------------------------------------------------------------------ | -------------------------------- | ---------------- |
| options        | 该层级的完整选项，按给定顺序渲染；用来判断当前选中值是否仍然有效，因此不要只放当前搜索结果 | `readonly ScopeSwitcherOption[]` | 必填             |
| visibleOptions | 面板里实际显示的选项；搜索过滤和分页追加走这里，不影响选中值的有效性判断                   | `readonly ScopeSwitcherOption[]` | `options`        |
| selectedId     | 当前选中项的 `id`，未选择时传 `''`                                                         | `string`                         | 必填             |
| total          | 该层级的总条数，用于判断是否显示搜索框                                                     | `number`                         | `options` 的条数 |

### ScopeSwitcherOption

| 参数        | 说明                                       | 类型        | 默认值  |
| ----------- | ------------------------------------------ | ----------- | ------- |
| id          | 选项的唯一标识                             | `string`    | 必填    |
| label       | 选项文本，搜索命中的片段会高亮             | `string`    | 必填    |
| icon        | 行首图标，例如库、数据空间或用户的头像     | `ReactNode` | -       |
| description | 显示在文本下方的次要说明，例如套餐或地址   | `string`    | -       |
| disabled    | 禁用该选项：置灰显示，不响应点击和键盘选择 | `boolean`   | `false` |

### ScopeSwitcherState

| 参数          | 说明                                                                                          | 类型      | 默认值  |
| ------------- | --------------------------------------------------------------------------------------------- | --------- | ------- |
| loading       | 选项正在首次加载：面板显示加载文案，不显示列表                                                | `boolean` | `false` |
| error         | 选项加载失败：面板显示 `slots.errorFallback`，没有时显示 `labels.error`                       | `boolean` | `false` |
| busy          | 该层级有变更正在进行，例如正在切换数据空间：禁用整个列表，避免并发选择                        | `boolean` | `false` |
| disabled      | 该层级暂时不可切换：触发器不响应点击，面板不展开                                              | `boolean` | `false` |
| visible       | 面板是否展开；提供后为受控模式，需要在 `actions.onVisibleChange` 里写回，不传时由本级自行维护 | `boolean` | -       |
| searchKeyword | 当前搜索词，由宿主保存；选项文本中命中的片段高亮，非空时即使选项不超过 10 条也会显示搜索框    | `string`  | `''`    |

### ScopeSwitcherActions

| 参数                  | 说明                                               | 类型                                            | 默认值 |
| --------------------- | -------------------------------------------------- | ----------------------------------------------- | ------ |
| onSelect              | 选中某一项时触发；组件先关闭面板，选中值由宿主更新 | `(option: ScopeSwitcherOption) => void`         | -      |
| onVisibleChange       | 面板展开或关闭时触发，参数为变化后的状态           | `(visible: boolean) => void`                    | -      |
| onSearchKeywordChange | 搜索词变化时触发；提供后才会显示搜索框             | `(keyword: string) => void`                     | -      |
| onScroll              | 选项列表滚动时触发，宿主据此加载下一页             | `(metrics: ScopeSwitcherScrollMetrics) => void` | -      |

### ScopeSwitcherSlots

| 参数          | 说明                                                                                         | 类型                                                             | 默认值                                        |
| ------------- | -------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | --------------------------------------------- |
| renderPanel   | 接管面板内容：`search` 和 `list` 是组件渲染好的搜索框和列表，标题、操作和底部入口由宿主排布  | `(panel: ScopeSwitcherPanelContent) => ReactNode`                | 只渲染 `search` 和 `list`                     |
| renderOption  | 在默认行内容的基础上追加或替换，例如行尾的「更多」菜单；行的点击、选中和键盘交互仍由组件处理 | `(content: ReactNode, option: ScopeSwitcherOption) => ReactNode` | 默认行内容                                    |
| emptyFallback | 没有选项时替代列表显示的内容                                                                 | `ReactNode`                                                      | `labels.empty`，有搜索词时为 `labels.noMatch` |
| errorFallback | 加载失败时替代列表显示的内容，例如带重试入口                                                 | `ReactNode`                                                      | `labels.error`                                |

### ScopeSwitcherPanelContent

`renderPanel` 的参数。

| 参数   | 说明                                 | 类型        | 默认值 |
| ------ | ------------------------------------ | ----------- | ------ |
| search | 搜索框；搜索框不显示时为空节点       | `ReactNode` | -      |
| list   | 选项列表，以及加载、空、失败三种状态 | `ReactNode` | -      |

### ScopeSwitcherScrollMetrics

`onScroll` 的参数。

| 参数         | 说明             | 类型     | 默认值 |
| ------------ | ---------------- | -------- | ------ |
| scrollTop    | 列表已滚动的距离 | `number` | -      |
| scrollHeight | 列表内容的总高度 | `number` | -      |
| clientHeight | 列表的可视高度   | `number` | -      |

### ScopeSwitcherLabels

默认值依次为 `zh-CN`、`en-US` 的内置文案。

| 参数              | 说明                                                        | 类型     | 默认值                                        |
| ----------------- | ----------------------------------------------------------- | -------- | --------------------------------------------- |
| loading           | 加载提示                                                    | `string` | `'加载中…'` / `'Loading…'`                    |
| searchPlaceholder | 搜索框内的提示文字，同时是它的无障碍名称                    | `string` | `'搜索'` / `'Search'`                         |
| empty             | 没有选项时的提示                                            | `string` | `'暂无选项'` / `'No options'`                 |
| noMatch           | 有搜索词但没有命中时的提示；只设置了 `empty` 时沿用 `empty` | `string` | `'没有匹配项'` / `'No matches'`               |
| error             | 加载失败时的提示                                            | `string` | `'选项加载失败'` / `'Unable to load options'` |

## 注意

- `ScopeSwitcher` 只负责布局和语言，不保存选中值。每一级的选项、选中值、搜索词和请求由宿主传给对应的 `ScopeSelector`。
- 相邻层级之间的分隔符 `/` 由样式绘制，因此 `ScopeSelector` 要直接作为 `ScopeSwitcher` 的子节点；自定义的层级组件直接返回 `ScopeSelector`，不要再包一层 DOM。
- 固定层级和可切换层级可以混用，不需要的层级直接省略。
- 选中值由宿主归一化：`ScopeSelector` 严格按 `data.selectedId` 渲染。`selectedId` 为空或不在 `options` 里时没有任何一行显示为选中，命中禁用项时仍显示为选中；组件不会改写选中值，也不会调用 `onSelect`。
- 数据到达后，宿主检查 `selectedId` 是否仍在 `options` 里（只被搜索过滤出 `visibleOptions` 不算失效），无效则改选第一个可选项，并把结果写回 URL 和请求参数。[ScopeCascade](../modules/scope-cascade) 已内置这一步。
- 上级的选中项变化后，给下级层级的宿主组件设置包含上级 id 的 `key`，下级重新挂载，旧的选项、搜索词、错误和展开状态随之清空。
- 展开状态默认由各级自己维护，选择后面板关闭。提供 `state.visible` 后改为受控，宿主在 `actions.onVisibleChange` 里写回；选择时组件先请求关闭再调用 `onSelect`，宿主可以等异步操作完成后再关闭面板。
- 搜索框在两个条件同时满足时显示：提供了 `actions.onSearchKeywordChange`，并且 `options`、`visibleOptions`、`total` 中最大的条数超过 10，或搜索词非空。选项的过滤由宿主完成，组件高亮命中的片段，不区分大小写。
- 搜索框的显示阈值 10 以常量 `SCOPE_SWITCHER_SEARCH_THRESHOLD` 导出，不能通过属性修改。
- 键盘：在触发器上按 ArrowDown 或 ArrowUp 展开面板；在选项行上，方向键循环移动焦点，Home、End 跳到首尾，Enter 或空格选择，Escape 关闭面板并把焦点还给触发器。点击面板外部或焦点离开选择器时，面板同样关闭。
- 面板展开后，焦点先落在搜索框，没有搜索框时落在选中项，没有选中项时落在第一个可选项。选择后焦点回到触发器，焦点已移到别处时不抢回。
- 禁用选项，以及 `busy` 时的全部选项，不能选择，方向键也会跳过它们。`renderOption` 里内嵌的按钮、链接和输入框不会触发行选择。
- 触发器带有 `aria-haspopup="dialog"` 和 `aria-expanded`，面板是 `dialog`，列表是 `listbox`，选项行是带 `aria-selected` 的 `option`。
- 图标由宿主通过 `trigger.icon` 和 `option.icon` 传入，组件不内置层级图标。默认图标可以从 `@openviking/react/icons` 取 `LibraryIcon`、`SpaceIcon`、`UserIcon`；ScopeCascade 会给适配函数没有返回 `icon` 的选项自动补上这三个。
- 每行至少 32px 高，空间不足时各层级换行；单级触发器最宽 260px，超出后文本省略。
- 视口宽度不超过 600px 时，面板改为贴底的整宽面板；更宽时，最后一级的面板右对齐展开。
- 包根入口导出 `ScopeSwitcher`、`ScopeSelector`、`ScopeSwitcherProps` 和 `ScopeSelectorProps`；其余类型和 `SCOPE_SWITCHER_SEARCH_THRESHOLD` 从 `@openviking/react/components/scope-switcher` 导入。

## 主题变量

变量声明在 `.ov-scope-switcher` 上，通过 `ScopeSwitcher` 的 `style` 或自己的 CSS 覆盖其中任意一条，设置在祖先节点上不会生效。共用的颜色取自 `--ov-ui-color-*`，规则见[快速开始](../guide/getting-started)，在祖先节点上设置即可覆盖。

| 变量                                        | 说明                                                               | 默认值                        |
| ------------------------------------------- | ------------------------------------------------------------------ | ----------------------------- |
| `--ov-ui-scope-switcher-icon`               | 触发器图标和展开箭头的颜色                                         | `--ov-ui-color-text-2`        |
| `--ov-ui-scope-switcher-option-icon`        | 选项行首图标的颜色                                                 | `--ov-ui-scope-switcher-icon` |
| `--ov-ui-scope-switcher-option-icon-size`   | 选项行首图标底槽的尺寸                                             | `24px`                        |
| `--ov-ui-scope-switcher-option-icon-radius` | 选项行首图标底槽的圆角，渲染圆形头像时设为 `50%`                   | `12px`                        |
| `--ov-ui-scope-switcher-row-hover`          | 选项行悬停时的底色                                                 | `--ov-ui-color-fill-hover`    |
| `--ov-ui-scope-switcher-tag-background`     | `identity.tag` 的底色                                              | `--ov-ui-color-bg-5`          |
| `--ov-ui-scope-switcher-tag-text`           | `identity.tag` 的文字色                                            | `--ov-ui-color-text-2`        |
| `--ov-ui-scope-switcher-panel-width`        | 下拉面板的宽度                                                     | `272px`                       |
| `--ov-ui-scope-switcher-option-height`      | 选项行的最小高度                                                   | `44px`                        |
| `--ov-ui-scope-switcher-option-gap`         | 相邻选项行的间距                                                   | `2px`                         |
| `--ov-ui-scope-switcher-list-max-height`    | 选项列表的最大高度，超出后在列表内滚动                             | `288px`                       |
| `--ov-ui-scope-switcher-panel-max-height`   | 面板的最大高度，另受视口高度限制；`renderPanel` 接管内容时同样适用 | 列表最大高度加 `54px`         |
