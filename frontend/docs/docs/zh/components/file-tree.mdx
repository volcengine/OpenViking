# FileTree 文件树

FileTree 把宿主提供的行渲染成可展开、可键盘操作的文件树。

## 何时使用

- 数据由宿主加载和管理（分页、懒加载、权限裁剪）时：把树状态展平成有序的行传入，展开、选中和加载更多由宿主执行，组件在操作成功后通知。
- 需要自己决定搜索界面、导入入口和行尾操作时：组件只渲染并触发回调，不发起请求，也不需要 `OpenVikingProvider`。
- 使用 [FileBrowser](../modules/file-browser) 时，文件树已经内置，不需要单独接入。

## 引入

```tsx
import { FileTree } from '@openviking/react/components/file-tree';
import '@openviking/react/components/file-tree/style.css';
```

### FileTreeRow

`rows` 里的每一行是下面五种类型之一，用 `kind` 区分。

| 取值          | 说明                                                                                | 类型                  |
| ------------- | ----------------------------------------------------------------------------------- | --------------------- |
| `'entry'`     | 目录或文件，每个节点一行                                                            | `FileTreeEntryRow`    |
| `'loading'`   | 目录的子节点加载中，插在父节点下方，也可以不产出，改用条目行的 `busy`               | `FileTreeLoadingRow`  |
| `'load-more'` | 子节点分页且还有下一页时的「加载更多」行，一次性返回全部子节点的数据源不需要        | `FileTreeLoadMoreRow` |
| `'error'`     | 子节点加载失败，带重试按钮；`rows` 里只有这一行且没有 `parentId` 时表示整树加载失败 | `FileTreeErrorRow`    |

## 注意

### 导出

- 行、文案、句柄等类型和辅助函数从 `@openviking/react/components/file-tree` 导出，包根入口只导出 `FileTree` 和 `FileTreeProps`。
- `FileTree` 的类型是 `FileTreeComponent`，通过 `ref` 取得 `FileTreeHandle`，React 18 和 19 都支持。

### 行

- 树状态由宿主持有：展开、选中和子节点加载都在宿主，组件只渲染 `rows`。展开或选中发生后，更新 `expanded` 和 `selectedId` 再传入。
- `rows` 是展平后的一维列表，按传入顺序渲染，缩进由 `depth` 决定，组件不检查行之间的层级关系。子节点行及其状态行紧跟在父节点之后，`depth` 为父节点加 1。
- 行是普通对象，传入前可以自行排序、过滤或按权限裁剪。
- `rootOrder="context"` 按 URI 首段把根目录排成 `user → session → agent → resources`，接受单复数写法（如 `users`、`agents`），其他目录排在后面并保持相对顺序。只有根层的目录行参与排序，连同子树一起移动，根层的文件行和状态行（如分页行）保持原位置。

### 操作与通知

- `operations` 的方法返回 `Promise<void>`，完成表示成功，被 reject 表示失败。成功后才触发对应的 `on…` 回调，失败时不触发。
- 省略某个方法，对应操作不可用：展开箭头、「加载更多」、「重试」、搜索和刷新按钮禁用，点击行不会选中。省略 `on…` 回调不影响操作执行。
- 同一操作（同一行的选中、展开、加载更多、重试，或搜索、刷新）尚未完成时，重复触发会被忽略。

### 选中、键盘与权限

- 点击目录和点击文件都调用 `operations.select`，宿主按 `row.type` 区分。点击展开箭头只调用 `operations.toggleExpand`，不会选中。
- `renderRowTrailing` 返回的内容在行内，点击会冒泡到行并触发选中。需要独立的点击行为时调用 `event.stopPropagation()`，示例中的看板图标就是这样处理的。
- 键盘：上下方向键移动焦点，右键展开目录，左键折叠目录，Enter 和空格选中。
- 树使用 `role="tree"`，行使用 `role="treeitem"` 并输出 `aria-level`（`depth` 加 1）、`aria-selected`、`aria-expanded` 和 `aria-disabled`，用 `aria-label` 给树命名。
- 权限状态由宿主提供，组件不发鉴权请求：`disabled` 的行不能选中和展开，`selectable: false` 的行不能选中但可以展开，`access` 只在行尾显示文字标记，不改变行为。

### 搜索与刷新

- 搜索入口和刷新按钮默认显示，`search`、`refresh` 传 `false` 分别隐藏。两者都隐藏时不渲染这一行，`slots.toolbar` 不受影响。
- 刷新等待期间（`loading`、`refresh.loading` 或 `operations.refresh` 返回的 Promise 任一在进行），按钮显示加载态并禁用，重复点击不会重复执行。`operations.refresh` 被 reject 后按钮恢复，且不触发 `onRefresh`。
- 刷新按钮悬停或聚焦时显示提示，按 Esc 关闭。`labels.refresh` 同时是提示文案和按钮的无障碍名称。
- 搜索入口的默认文案带有 `⌘+K` 提示，组件不注册这个快捷键，也不过滤行。搜索界面、快捷键和结果处理由宿主通过 `operations.search` 接入。

### 目录说明

- 组件按行 `uri` 的路径结构判断目录语义，内置对应的说明和触发行为文案，不需要宿主传入。匹配只看路径，忽略 `viking://` 前缀、大小写、查询串和末尾斜杠，与 `type` 无关。
- 内置说明只覆盖固定层级：`viking://resources` 匹配 `sharedResources`，`viking://resources/docs` 不匹配，更深的节点由宿主决定。
- 说明显示在名称后面。悬停行时在右侧弹出浮层，内容是标题、说明、触发行为和路径。长期记忆下的九个键（`profile` 到 `experiences`）只在浮层显示说明。
- 行上的 `description` 优先于内置说明，空字符串表示不显示。`labels.info` 按键覆盖内置文案，空字符串同样表示不显示，没有覆盖的键使用当前语言的内置文案。
- `uri` 没有匹配任何键时，不显示内置浮层。提供 `renderRowTooltip` 后，浮层内容完全由它决定。

```tsx
<FileTree
  rows={rows}
  labels={{
    info: {
      description: { userRoot: '当前用户' },
      triggerBehavior: { memories: '提交会话时自动沉淀' },
      field: { description: '说明', triggerBehavior: '触发行为', path: '路径' },
    },
  }}
/>
```

### 定位行

- 每个行元素都带有 `data-file-tree-row-id` 属性，值为行的 `id`，属性名以 `FILE_TREE_ROW_ATTRIBUTE` 导出。页面层可以据此实现一次性高亮或覆盖层。
- `getRowAttributes(row)` 为行追加类名和属性：`className`、`style` 与组件自身的合并，条目行的 `onClick`、`onKeyDown` 由组件接管。
- `ref` 提供 `getRowElement(id)` 和 `scrollToRow(id, options)`，例如在 [DirectoryTour](./directory-tour) 的 `locateTarget` 里返回要定位的行元素。

```tsx
const treeRef = useRef<FileTreeHandle>(null);

<FileTree ref={treeRef} rows={rows} />;

treeRef.current?.scrollToRow('resources', { block: 'center' });
```

### 布局

- 树的根元素高度为 `100%`，内容在树内部滚动，需要给外层容器设置高度。
- 行宽按内容撑开，名称完整显示，容器横向滚动。层级很深时缩进同样靠横向滚动获得空间。
- 说明文字最宽 200px，超出省略，避免长说明撑宽整行。
- Chromium 浏览器在各平台使用统一的滚动条样式：内容溢出时占用 12px 空间，滑块宽 8px，颜色采用 macOS 原生滚动条的浅色与暗色配色。悬停滚动条时显示轨道和边线，滑块在浅色下悬停加深、暗色下悬停变亮。
- `renderRowTrailing` 返回的内容显示在行右端；行内还有层级、权限等行尾标记时，它紧跟在这些标记之后。

## 主题变量

根元素的类名是 `ov-file-tree`，内部元素为 `ov-file-tree__<元素>`，例如 `ov-file-tree__row`。颜色优先读取你在祖先元素上设置的 `--ov-ui-color-*`，没有设置时使用库的内置值，设置方法见[快速开始](../guide/getting-started)的主题一节；只调整文件树时覆盖下面的变量。

| CSS 变量                          | 默认值                           | 用途                             |
| --------------------------------- | -------------------------------- | -------------------------------- |
| `--ov-ui-file-tree-text`          | 同 `--ov-ui-color-text-1`        | 行文字                           |
| `--ov-ui-file-tree-text-muted`    | 同 `--ov-ui-color-text-3`        | 说明、标记、展开箭头和状态行文字 |
| `--ov-ui-file-tree-icon`          | 同 `--ov-ui-color-text-3`        | 行首图标                         |
| `--ov-ui-file-tree-row-hover`     | 同 `--ov-ui-color-bg-5`          | 悬停背景                         |
| `--ov-ui-file-tree-row-selected`  | 同 `--ov-ui-color-primary-light` | 选中背景                         |
| `--ov-ui-file-tree-guide`         | 同 `--ov-ui-color-border-1`      | 层级竖线                         |
| `--ov-ui-file-tree-spinner`       | 同 `--ov-ui-color-primary`       | 转圈的弧线                       |
| `--ov-ui-file-tree-spinner-track` | 同 `--ov-ui-color-border-3`      | 转圈的底环                       |
