# DirectoryTour 目录引导

分步介绍目录的非模态引导：依次定位宿主指定的目录行，在旁边显示高亮和讲解卡片，不改变文件选中状态。

## 何时使用

- 用户首次进入文件浏览，需要依次介绍 memories、sessions、resources 等目录时。
- 新目录首次出现，需要用一张自定义卡片介绍它时。
- 目录如何加载、展开，以及何时算「已读」由宿主决定：组件只负责定位、高亮和卡片，不发起请求，不保存完成状态，也不需要 `OpenVikingProvider`。需要遮罩并阻止页面操作的模态引导不适用。

## 引入

```tsx
import {
  DirectoryTour,
  DirectoryTourIntro,
  openVikingDirectoryTourSteps,
} from '@openviking/react/components/directory-tour';
import '@openviking/react/components/directory-tour/style.css';
```

## API

### DirectoryTour

| 参数             | 说明                                                                                                                                                       | 类型                                                                            | 默认值                   |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | ------------------------ |
| open             | 是否显示引导                                                                                                                                               | `boolean`                                                                       | 必填                     |
| steps            | 步骤列表，为空数组时不渲染；只有一项时不显示进度                                                                                                           | `readonly DirectoryTourStep[]`                                                  | 必填                     |
| currentStep      | 当前步骤的下标，从 0 开始；提供后为受控模式，需要在 `onStepChange` 里更新                                                                                  | `number`                                                                        | -                        |
| defaultStep      | 非受控模式的起始下标；关闭后重新打开，从这里重新开始                                                                                                       | `number`                                                                        | `0`                      |
| placement        | 卡片优先出现在目录行的哪一侧；放不下时换到另一侧，两侧都放不下时放在上方或下方                                                                             | `'right' \| 'left'`                                                             | `'right'`                |
| locateTimeout    | 定位的等待时间（毫秒），超时后显示缺失提示卡片                                                                                                             | `number`                                                                        | `10000`                  |
| locateTarget     | 返回步骤对应的目录行元素：宿主加载并展开目录，等目录行渲染后再返回，`null` 表示找不到。`signal` 在切换步骤、卸载或超时时中止；不传时每步都显示缺失提示卡片 | `(target: string, signal: AbortSignal) => Promise<DirectoryTourAnchor \| null>` | -                        |
| onStepChange     | 用户继续到下一步时触发，参数为新的下标                                                                                                                     | `(index: number) => void`                                                       | -                        |
| onClose          | 点击关闭按钮或按 Escape 时触发；不传时不显示关闭按钮，也不处理 Escape                                                                                      | `() => void`                                                                    | -                        |
| onComplete       | 最后一步结束时触发（点击确认或调用 `context.complete()`），参数包含被跳过的步骤 id；之后不再渲染，宿主负责关闭与持久化                                     | `(result: DirectoryTourResult) => void`                                         | -                        |
| renderContent    | 替换定位成功后的卡片内容；此时 `title` 只作为对话框的无障碍名称，`description` 不显示                                                                      | `(context: DirectoryTourContentContext) => ReactNode`                           | -                        |
| labels           | 覆盖界面文案                                                                                                                                               | `DirectoryTourLabels`                                                           | -                        |
| locale           | 界面语言，规则见[国际化](../guide/i18n)                                                                                                                    | `'zh-CN' \| 'en-US'`                                                            | 继承上级，默认 `'en-US'` |
| className、style | 卡片根节点的类名和样式，可用来设置尺寸和主题变量                                                                                                           | `string`、`CSSProperties`                                                       | -                        |

### DirectoryTourStep

| 参数         | 说明                                                            | 类型        | 默认值                                  |
| ------------ | --------------------------------------------------------------- | ----------- | --------------------------------------- |
| id           | 步骤的唯一标识，`onComplete` 用它报告被跳过的步骤               | `string`    | 必填                                    |
| target       | 目录的语义名，原样传给 `locateTarget`；预设步骤的六个取值见下方 | `string`    | 必填                                    |
| title        | 卡片标题                                                        | `ReactNode` | 必填                                    |
| description  | 标题下方的说明                                                  | `ReactNode` | 必填                                    |
| illustration | 卡片顶部的插画；六个预设 `target` 有内置插画，传 `null` 隐藏    | `ReactNode` | 预设 `target` 的内置插画                |
| cardWidth    | 卡片宽度（CSS 像素），不会超出可视视口                          | `number`    | `270`                                   |
| nextLabel    | 本步主按钮的文案                                                | `string`    | `labels.next`，最后一步为 `labels.done` |

### DirectoryTourAnchor

`locateTarget` 返回的类型：一个 `HTMLElement`，或一组连续的目录行 `readonly HTMLElement[]`。数组的第一项决定卡片位置，其中仍在文档里的行共同组成高亮范围。

### DirectoryTourContentContext

`renderContent` 的参数。

| 参数     | 说明                                                  | 类型                | 默认值 |
| -------- | ----------------------------------------------------- | ------------------- | ------ |
| step     | 当前步骤                                              | `DirectoryTourStep` | -      |
| index    | 当前步骤的下标，从 0 开始                             | `number`            | -      |
| total    | 步骤总数                                              | `number`            | -      |
| complete | 确认当前步骤：进入下一步，最后一步时触发 `onComplete` | `() => void`        | -      |
| close    | 关闭引导，等同于点击关闭按钮，调用 `onClose`          | `() => void`        | -      |

### DirectoryTourResult

`onComplete` 的参数。

| 参数           | 说明                                                      | 类型                | 默认值 |
| -------------- | --------------------------------------------------------- | ------------------- | ------ |
| skippedStepIds | 用户已点按钮继续的缺失步骤 id，按先后排列，没有则为空数组 | `readonly string[]` | -      |

### DirectoryTourLabels

默认值依次为 `zh-CN`、`en-US` 的内置文案。

| 参数                  | 说明                                                             | 类型                                         | 默认值                         |
| --------------------- | ---------------------------------------------------------------- | -------------------------------------------- | ------------------------------ |
| close                 | 关闭按钮的无障碍名称                                             | `string`                                     | `'关闭引导'` / `'Close guide'` |
| next                  | 非最后一步的主按钮文案                                           | `string`                                     | `'下一步'` / `'Next'`          |
| done                  | 最后一步的主按钮文案，同时是 `DirectoryTourIntro` 确认按钮的文案 | `string`                                     | `'知道了'` / `'Got it'`        |
| progress              | 进度文案，`current` 从 1 开始；单步引导不显示                    | `(current: number, total: number) => string` | 「当前/总数」，如 `1/6`        |
| unavailable           | 无法定位目录行时的提示                                           | `string`                                     | `'当前暂未找到这个目录。'`     |
| locating、retry、skip | 不会显示                                                         | `string`                                     | -                              |

### DirectoryTourIntro

卡片内容的展示组件，通常在 `renderContent` 里使用。视频播放、编辑等操作放在 `media` 和 `features` 中，由宿主处理。

| 参数        | 说明                                                                                                                                             | 类型                                | 默认值                   |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------- | ------------------------ |
| title       | 标题                                                                                                                                             | `ReactNode`                         | 必填                     |
| description | 标题下方的说明                                                                                                                                   | `ReactNode`                         | 必填                     |
| features    | 说明下方的要点列表，每项一行                                                                                                                     | `readonly ReactNode[]`              | -                        |
| media       | 标题上方的媒体区域，例如封面图                                                                                                                   | `ReactNode`                         | -                        |
| onDone      | 点击确认按钮时触发，通常传入 `context.complete`                                                                                                  | `() => void`                        | -                        |
| labels      | 覆盖确认按钮的文案，只有 `done`                                                                                                                  | `Pick<DirectoryTourLabels, 'done'>` | -                        |
| locale      | 界面语言，规则见[国际化](../guide/i18n)；在 `renderContent` 里不继承 `DirectoryTour` 的 `locale`，需要在这里传入，或由 `OpenVikingProvider` 提供 | `'zh-CN' \| 'en-US'`                | 继承上级，默认 `'en-US'` |

### openVikingDirectoryTourSteps

六步预设，文案为英文，每步的 `target` 取下表的值。组件不内置任何账号的路径，由宿主在 `locateTarget` 里把 `target` 映射到目录行：`userResources` 是用户私有的 resources 目录，`sharedResources` 是团队共享的根级 resources 目录。

| 步骤 id              | `target`          | 介绍的目录                |
| -------------------- | ----------------- | ------------------------- |
| `memories`           | `userMemories`    | 用户记忆（memories）      |
| `sessions`           | `userSessions`    | 对话记录（sessions）      |
| `personal-resources` | `userResources`   | 个人资料（resources）     |
| `shared-resources`   | `sharedResources` | 团队公共资料（resources） |
| `experiences`        | `userExperiences` | Agent 经验（experiences） |
| `peers`              | `userPeers`       | 对象记忆（peers）         |

## 注意

- `locateTarget` 由宿主实现：加载并展开目录，等目录行渲染后返回它的元素，例如 [FileTree](./file-tree) 的 `getRowElement(id)`。组件随后把它滚动到可见区域，并在旁边显示高亮和卡片。
- 用 `useCallback` 保持 `locateTarget` 的引用稳定，引用变化会重新定位当前步骤；`signal` 中止后不要继续展开旧作用域的目录。
- 定位期间卡片保持隐藏。如果 `locateTarget` 返回 `null` 或抛出错误、定位超时，或目录行被移除，当前步骤会显示内置的缺失提示卡片，不高亮树节点。点击「下一步」继续，最后一步点击「知道了」结束。
- `onClose` 和 `onComplete` 触发后，由宿主把 `open` 设为 `false`；是否已读，以及按用户或空间持久化，也由宿主处理。账号或空间切换时，关闭引导或更换组件的 `key`。
- 受控模式下，宿主在 `onStepChange` 里更新 `currentStep`。找不到目录时仍显示当前步骤的进度编号，点击按钮后才继续。
- `locateTarget` 可以返回一组连续的目录行：第一行决定卡片位置，仍在文档里的行组成高亮范围。折叠后移除的行退出高亮，新加载的行需要宿主重新定位（更新 `locateTarget` 或重新打开引导）。
- 位置随滚动、窗口缩放和目录行尺寸变化更新，卡片限制在可视视口内，包括缩放和软键盘的影响；目录行滚出可见区域时，卡片和高亮一起隐藏。
- 卡片是非模态 `dialog`：显示后获得焦点，按 Escape 触发 `onClose`，关闭时焦点回到原来的元素（该元素仍在文档里时）。宿主控件已用 `preventDefault()` 处理的 Escape，卡片不再响应。
- 卡片通过浏览器的 Popover API 渲染在顶层，不需要设置 `z-index`，也不会创建全屏遮罩或 SVG，需要浏览器支持该 API。
- 服务端渲染时不创建浮层；初始 `open` 为 `true` 时，在 hydration 完成后才创建。
- 预设步骤的文案是英文，其他语言需要自己提供 `title` 和 `description`。六个预设 `target` 的插画随 JS 打包，不需要托管图片。
- 包根入口只导出 `DirectoryTour` 和 `DirectoryTourProps`；`DirectoryTourIntro`、`openVikingDirectoryTourSteps` 和其余类型从 `@openviking/react/components/directory-tour` 导入。

## 主题变量

卡片挂在 `document.body` 下，会继承目录行上生效的 `--ov-ui-*` 变量，祖先节点上 `class`、`style`、`data-theme` 的变化也会同步到卡片。下列变量可以通过 `className` 或 `style` 直接设置，优先级高于继承值。

| 变量                                | 说明                                     | 默认值                   |
| ----------------------------------- | ---------------------------------------- | ------------------------ |
| `--ov-ui-directory-tour-primary`    | 高亮描边、焦点环和主按钮的颜色           | `--ov-ui-color-primary`  |
| `--ov-ui-directory-tour-background` | 卡片背景色                               | `--ov-ui-color-bg-1`     |
| `--ov-ui-directory-tour-text`       | 卡片文字色                               | `--ov-ui-color-text-1`   |
| `--ov-ui-directory-tour-secondary`  | `description` 和 `features` 的文字色     | `--ov-ui-color-text-2`   |
| `--ov-ui-directory-tour-muted`      | 进度和 `DirectoryTourIntro` 说明的文字色 | `--ov-ui-color-text-3`   |
| `--ov-ui-directory-tour-border`     | 卡片描边色                               | `--ov-ui-color-border-3` |
