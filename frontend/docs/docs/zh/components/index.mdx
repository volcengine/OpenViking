# 组件

面向 OpenViking AI 应用的可复用视图与文件类型图标。组件通过 props 接收处理后的数据和状态，通过事件回调表达用户意图；数据获取、认证与业务流程由应用负责。

## 可用模块

### [FileTree 文件树](./file-tree)

展平后的文件树，支持行渲染、选中、展开、键盘交互与分页意图上报。宿主提供有序行数据并负责加载。当前视图为占位实现，范围与限制见组件详情。

### [FilePreview 文件预览](./file-preview)

带页签的文件预览视图，提供标题操作、页签切换及纯文本预览和编辑基础。当前视图为占位实现：正文尚未接入 FileViewer，先降级为纯文本。应用负责提供内容与保存行为。

### [Tui 命令控制台](./tui)

已确认的命令记录、结果与输入区 API。当前视图仍为占位实现；命令补全、CLI 共享元数据与结果渲染后续实现。

### [ScopeSwitcher 作用域选择](./scope-switcher)

无状态的头部面包屑容器，组合独立的 ScopeSelector 视图。各级宿主独立管理数据、搜索和请求，仅选中身份参与级联更新。

### [AgentConnect Agent 接入](./agent-connect)

Agent 接入视图。页签、当前页签的条目与详情正文都由宿主传入；组件渲染列表与详情，并上报切换与复制意图。

### [VikingBot 对话](./viking-bot)

对话视图：消息列表、输入区与待确认交互区。按归一化消息模型渲染可用视图，当前为待设计评审的占位实现。

### [图标](./icons)

提供音频、PDF、演示文稿、视频与文字文档五种文件类型图标，支持自定义图片尺寸与无障碍描述。

公开包入口、样式选择与应用接入边界见[快速开始](../guide/getting-started)。

### [登录与认证表单](./auth-forms)

无接口、路由、存储和布局耦合的认证视图。文案默认为英文，可通过 `labels` 和标题等属性覆盖。
