# 组件

面向 OpenViking AI 应用的可复用视图与文件类型图标。组件均为纯 UI，通过 props 接收处理后的数据与状态，通过回调表达交互意图，不感知接口；取数与业务联动由模块或宿主负责。

## 可用模块

### [FileBrowserEntries 文件浏览入口](./file-browser-entries)

文件浏览区域顶部的入口条：连接 Agent 与导入资源。固定两个入口，宿主只决定显示哪几个与点击后做什么，图标、文案与分隔线由组件负责。

### [FileTree 文件树](./file-tree)

展平后的文件树，支持行渲染、选中、展开、键盘交互与分页意图上报。宿主提供有序行数据并负责加载。当前视图为占位实现，范围与限制见组件详情。

### [DirectoryTour 目录引导](./directory-tour)

基于目录行 DOM 锚点的六步定位引导，支持异步定位、独立高亮、避让、重试与跳过；宿主负责目录加载和完成状态。

### [FilePreview 文件预览](./file-preview)

带页签的文件预览视图，提供标题操作、页签切换及纯文本预览和编辑基础。当前视图为占位实现：正文尚未接入 FileViewer，先降级为纯文本。应用负责提供内容与保存行为。

### [Tui 命令控制台](./tui)

命令记录、结果与输入区视图，补全、参数提示与分组命令帮助由内置 CLI 元数据驱动。

### [ScopeSwitcher 作用域选择](./scope-switcher)

无状态的头部面包屑容器，组合独立的 ScopeSelector 视图。各级宿主独立管理数据、搜索和请求，仅选中身份参与级联更新。

### [AgentConnect Agent 接入](./agent-connect)

Figma 接入视图，内置主流 Agent 与 MCP、CLI、API、SDK 开发接入列表、中英文详情和原始图标。调用方提供密钥与语言，支持实例内或受控选择与复制反馈。

### [VikingBot 对话](./viking-bot)

对话视图：消息列表、输入区与待确认交互区。按归一化消息模型渲染可用视图，当前为待设计评审的占位实现。

### [图标](./icons)

提供音频、PDF、演示文稿、视频与文字文档五种文件类型图标，支持自定义图片尺寸与无障碍描述。

### [WikiDashboard Wiki 看板](./wiki-dashboard)

独立展示 Wiki 生成效果、待确认冲突及修复记录，通过状态和回调展示加载及重试。

### [ExperienceDashboard 经验看板](./experience-dashboard)

独立展示 Agent 经验列表、应用效果与来源追溯，通过 props 接收展示数据和状态。

公开包入口、样式选择与应用接入边界见[快速开始](../guide/getting-started)。

### [登录与认证表单](./auth-forms)

无接口、路由、存储和布局耦合的认证视图。内置文案继承当前语言，可通过 `labels` 和标题等属性覆盖。
