# 业务组件总览

这里的业务组件都是纯视图：数据由你传入，组件不发起请求，也不需要 `OpenVikingProvider`。自带取数的功能见[区块](../modules/)。

### [Icons 图标](./icons)

组件库内置的图标：箭头、文件类型、作用域层级和看板图标以 React 组件提供，渲染为内联 SVG；另有按文件名选择文件类型图标的函数。

## 文件与目录

### [FileTree 文件树](./file-tree)

FileTree 把宿主提供的行渲染成可展开、可键盘操作的文件树。

### [FilePreview 文件预览](./file-preview)

带页签的文件预览：按格式渲染文件正文，提供路径面包屑、预览与源码切换、文本编辑和宿主自定义操作。

### [FileBrowserActionBar 文件浏览操作栏](./file-browser-action-bar)

文件浏览区顶部的操作栏，固定两个操作：连接 Agent 和导入资源，由宿主决定显示哪几个以及点击后做什么。

### [DirectoryTour 目录引导](./directory-tour)

分步介绍目录的非模态引导：依次定位宿主指定的目录行，在旁边显示高亮和讲解卡片，不改变文件选中状态。

## 对话与命令

### [VikingBot 对话](./viking-bot)

展示宿主提供的会话消息，并提供输入区和待确认交互区：发送、停止、打开资源等操作通过回调交给宿主，组件不发起请求。

### [CommandConsole 命令控制台](./command-console)

终端风格的命令记录与输入视图：展示命令记录及其结果，输入区提供命令补全和参数帮助。

## 账号与连接

### [ScopeSwitcher 作用域选择](./scope-switcher)

由多级独立选择器组成的作用域面包屑：`ScopeSwitcher` 负责排列，每一级（例如库、数据空间、用户）用一个 `ScopeSelector` 展示当前值并切换。

### [AgentConnect Agent 接入](./agent-connect)

Agent 接入面板，列出主流 Agent 和 MCP、CLI、API、SDK 四种开发方式，展示接入说明和可复制的代码块，其中的 API Key 默认脱敏。

### [登录与认证表单](./auth-forms)

六个组件，覆盖选择登录方式、邮箱或 API Key 登录、请求重置邮件、设置密码和确认邀请。

## 数据看板

### [WikiDashboard Wiki 看板](./wiki-dashboard)

展示 Wiki 目录或文件里的冲突：目录视图列出有冲突的文件，文件视图列出每条冲突的详情和修复记录。

### [ExperienceDashboard 经验看板](./experience-dashboard)

展示 Agent 经验的使用情况：目录视图列出经验文件，文件视图展示单个经验的应用效果、来源轨迹和测试材料。
