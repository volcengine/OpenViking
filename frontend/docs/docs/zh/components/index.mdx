# 组件

面向 OpenViking 应用的可复用 React UI 模块，包含基础组件和组合视图。组件通过 props 接收处理后的数据和状态，通过事件回调表达用户意图；数据获取和业务数据处理由上层负责。每个组件均提供使用说明、交互示例和 API 详情。

## 可用组件

### [图标](./icons)

五种文件类型图标，支持自定义图片尺寸与无障碍描述。

### [StatusBadge 状态徽标](./status-badge)

脚手架示例：通过文字标签和颜色指示器展示资源或操作的状态。

## 预留模块

`file-tree`、`file-preview`、`tui`、`viking-bot`、`scope-switcher`、`agent-connect`、`resource-import` 已从 JS 子路径公开 props 类型，组件实现与样式待迁入。同一套 props 由不同宿主接入，宿主之间的流程与取数不同，交互与 UI 保持一致。公开路径及样式选择见[快速开始](../guide/getting-started)。
