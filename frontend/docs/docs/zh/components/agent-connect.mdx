# AgentConnect Agent 接入

Agent 接入面板，列出主流 Agent 和 MCP、CLI、API、SDK 四种开发方式，展示接入说明和可复制的代码块，其中的 API Key 默认脱敏。

## 何时使用

- 需要引导用户把 OpenViking 接入 Codex、Claude Code、Cursor 等 Agent，或通过 MCP、CLI、API、SDK 自行开发时。
- 需要自己决定 API Key 和服务地址的来源时：组件只负责展示和复制，不发起请求，也不需要 `OpenVikingProvider`。
- 需要放在文件浏览区顶部时，使用 [FileBrowserActionBar](./file-browser-action-bar)，它通过 `agentConnect` 在右侧抽屉中展示本组件。

## 引入

```tsx
import { AgentConnect } from '@openviking/react/components/agent-connect';
import '@openviking/react/components/agent-connect/style.css';
```

## API

### AgentConnect

| 参数             | 说明                                                                                               | 类型                                        | 默认值                                                  |
| ---------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------- | ------------------------------------------------------- |
| apiKey           | 写入接入说明的 API Key，界面脱敏显示，复制时使用原值                                               | `string`                                    | 必填                                                    |
| baseUrl          | OpenViking 服务地址，替换接入说明里的默认地址                                                      | `string`                                    | `https://api.vikingdb.cn-beijing.volces.com/openviking` |
| agreementUrl     | 用户协议链接，提供后页脚显示协议链接，省略时只显示数据访问提示                                     | `string`                                    | -                                                       |
| showOverseasTag  | 「境外」标签的范围：省略时标记 Codex 和 Claude Code，`true` 标记全部适用的 Agent，`false` 隐藏标签 | `boolean`                                   | -                                                       |
| activeTabId      | 受控的当前页签，省略时由组件维护                                                                   | `'mainstream' \| 'custom'`                  | `'mainstream'`                                          |
| selectedId       | 受控的选中条目，取值为 `AgentConnectItem` 的 `id`，当前页签不含该条目时显示第一项                  | `string`                                    | 当前页签的第一项                                        |
| onTabChange      | 选择页签时触发，点击、方向键、Home、End 都会触发                                                   | `(tabId: 'mainstream' \| 'custom') => void` | -                                                       |
| onSelect         | 选择条目时触发                                                                                     | `(item: AgentConnectItem) => void`          | -                                                       |
| onCopy           | 复制成功后触发，参数是实际复制的代码块或整段说明，包含原始 API Key                                 | `(text: string) => void`                    | -                                                       |
| locale           | 界面语言，规则见[国际化](../guide/i18n)                                                            | `'zh-CN' \| 'en-US'`                        | 继承上级，默认 `'en-US'`                                |
| className、style | 外观与布局，其余 HTML 属性透传到根元素                                                             | HTML 属性                                   | -                                                       |

### AgentConnectItem

| 参数 | 说明                     | 类型     | 默认值 |
| ---- | ------------------------ | -------- | ------ |
| id   | 内置条目的标识，取值见下 | `string` | 必填   |
| name | 条目在当前语言下的名称   | `string` | 必填   |

内置条目的 `id`：

- `mainstream` 页签（接入主流 Agent）：`codex`、`claude-code`、`doubao`、`workbuddy`、`trae`、`cursor`、`openclaw`、`hermes`、`opencode`、`deepseek-harness`、`deerflow`、`pi`、`zcode`、`kimi-code`。
- `custom` 页签（开发自己的 Agent）：`mcp`、`cli`、`api`、`sdk`。

## 注意

- Agent 目录、接入说明和图标内置，不提供增删或替换的 prop。语言只能通过 `locale` 切换，组件没有语言选择界面。
- 接入内容和图标随组件打包，不需要配置资源地址，运行时不请求远端文档。组件不执行说明里的命令，只负责展示和复制。
- 默认宽 1000px、最小高度 949px，容器更窄时横向滚动。
- 代码块里的 API Key 默认显示为 `••••••••`，点击代码块上的「显示 API Key」查看原值，同一份说明里一次只显示一个代码块的密钥。复制始终使用原始密钥，与显示状态无关。
- 组件不持久化 `apiKey`，也不把它写进 DOM 属性。`onCopy` 收到的文本包含原始 API Key，宿主按凭据处理，不要写入日志。
- 复制使用 Clipboard API，需要安全上下文（如 HTTPS）和剪贴板权限。失败时显示「复制失败，请重试」，不会调用 `onCopy`。
- DeerFlow 和 CLI 的详情带有说明页签：DeerFlow 为 MemoryManager 与 MCP，CLI 为「手动终端安装」与「通过 AI Agent 安装」。默认选中第一个，复制的是当前选中的说明。
- 切换条目、说明页签、语言、`apiKey` 或 `baseUrl` 后，密钥显示和复制反馈恢复初始状态。此前发起的复制完成后不再更新界面，也不调用 `onCopy`。
- TRAE 的安装命令面向国际版。
- Hermes 使用自定义 `baseUrl`（不同于默认地址）时，说明改用 Custom 连接步骤。
- 「境外」标签显示在详情标签行的末尾，按 Agent 产品的归属标记，不根据它使用的模型推断部署地区。`showOverseasTag` 为 `true` 时，除 Codex 和 Claude Code 外，还标记 Cursor、OpenClaw、Hermes Agent、OpenCode 和 pi。
- 类型从 `@openviking/react/components/agent-connect` 导出，包根入口只导出组件和 `AgentConnectProps`。
