# WikiDashboard Wiki 看板

展示 Wiki 目录或文件里的冲突：目录视图列出有冲突的文件，文件视图列出每条冲突的详情和修复记录。

## 何时使用

- 需要在文件浏览中查看 Wiki 的冲突概览，并跳转到具体文件或冲突时。
- 需要自己决定数据来源、操作按钮和页面布局时：组件只负责展示，不发起请求，也不需要 `OpenVikingProvider`。
- 使用 [FileBrowser](../modules/file-browser) 时，看板已经内置，不需要单独接入。

## 引入

```tsx
import { WikiDashboard } from '@openviking/react/components/wiki-dashboard';
import '@openviking/react/components/wiki-dashboard/style.css';
```

宿主传入的内容渲染出错时，组件显示默认兜底：插画、提示和「重试显示」按钮。需要替换展示时传入 `slots.errorFallback`。

## API

### WikiDashboard

| 参数             | 说明                                                                              | 类型                                                                                                                            | 默认值                   |
| ---------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------------ |
| kind             | 展示模式，数据加载中也能确定                                                      | `'directory' \| 'file'`                                                                                                         | 必填                     |
| data             | 与 `kind` 对应的展示数据，未提供时显示加载或错误状态                              | `WikiDirectoryData`（目录）、`WikiFileData`（文件）                                                                             | -                        |
| loading          | 列表为空时显示加载状态                                                            | `boolean`                                                                                                                       | `false`                  |
| error            | 列表为空时显示错误状态                                                            | `Error \| null`                                                                                                                 | -                        |
| onRetry          | 点击重试时触发，组件不自行发起请求                                                | `() => void`                                                                                                                    | -                        |
| onOpenUri        | 目录视图：点击文件时触发，参数为该文件的 URI；文件视图：点击路径时触发            | `(uri: string) => void`（目录）、`() => void`（文件）                                                                           | -                        |
| onOpenDashboard  | 目录视图：打开该文件的看板时触发，未提供时回退到 `onOpenUri`                      | `(uri: string) => void`                                                                                                         | -                        |
| defineActions    | 为每一行定义操作按钮，省略或返回空数组时不显示操作区                              | `(uri: string) => readonly WikiDashboardAction[]`（目录）、`(conflict: WikiConflict) => readonly WikiDashboardAction[]`（文件） | -                        |
| slots            | 替换渲染异常的展示内容，见[错误展示插槽](../guide/getting-started#自定义错误展示) | `{ errorFallback?: ReactNode \| ((reset: () => void) => ReactNode) }`                                                           | -                        |
| labels           | 覆盖界面文案                                                                      | `Partial<WikiDashboardLabels>`                                                                                                  | -                        |
| locale           | 界面语言，规则见[国际化](../guide/i18n)                                           | `'zh-CN' \| 'en-US'`                                                                                                            | 继承上级，默认 `'en-US'` |
| className、style | 外观与布局，其余 HTML 属性透传到根元素                                            | HTML 属性                                                                                                                       | -                        |

### WikiDirectoryData

| 参数              | 说明                                                      | 类型                | 默认值 |
| ----------------- | --------------------------------------------------------- | ------------------- | ------ |
| files             | 有冲突的文件 URI                                          | `readonly string[]` | 必填   |
| conflictFileCount | 冲突文件数                                                | `number`            | -      |
| limited           | 文件列表是否被截断，为 `true` 时数量后显示 `+` 并提示上限 | `boolean`           | -      |

### WikiFileData

| 参数      | 说明                                   | 类型                      | 默认值 |
| --------- | -------------------------------------- | ------------------------- | ------ |
| conflicts | 文件里的冲突                           | `readonly WikiConflict[]` | 必填   |
| path      | 要展示的文档路径，省略时不显示路径区域 | `string`                  | -      |

### WikiConflict

| 参数             | 说明                                                         | 类型                                                                                                     | 默认值 |
| ---------------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------- | ------ |
| id               | 冲突的唯一标识                                               | `string`                                                                                                 | 必填   |
| matchText        | 冲突在正文中的原文片段                                       | `string`                                                                                                 | 必填   |
| description      | 冲突标题，点击后展开详情                                     | `string`                                                                                                 | 必填   |
| reason           | 冲突原因                                                     | `string`                                                                                                 | 必填   |
| severity         | 严重程度                                                     | `'high' \| 'medium' \| 'low'`                                                                            | 必填   |
| state            | 修复状态                                                     | `'unfixed' \| 'fixed'`                                                                                   | 必填   |
| beginTime        | 发现时间，Unix 秒级时间戳                                    | `number`                                                                                                 | 必填   |
| fixTime          | 修复时间，Unix 秒级时间戳，未修复为 `null`                   | `number \| null`                                                                                         | 必填   |
| fixPlan          | 修复方案                                                     | `string`                                                                                                 | 必填   |
| resolutionBasis  | 修复依据                                                     | `string`                                                                                                 | 必填   |
| resolutionSource | 修复方式                                                     | `'manual' \| 'automatic'`                                                                                | -      |
| location         | 原文片段在正文中的位置；`unique` 时带 `start`、`end`、`line` | `{ status: 'unique'; start: number; end: number; line: number } \| { status: 'missing' \| 'ambiguous' }` | 必填   |

| 参数     | 说明                                                                 | 类型         | 默认值  |
| -------- | -------------------------------------------------------------------- | ------------ | ------- |

| disabled | 禁止点击，仍可聚焦查看提示                                           | `boolean`    | `false` |
| onClick  | 点击、Enter 或空格激活时触发，省略时按钮不可操作                     | `() => void` | -       |

## 注意

- 组件没有默认操作。`defineActions` 在渲染时调用，只根据当前行返回配置，不要在里面发请求或更新状态；可以按冲突状态返回不同的操作。
- 组件没有顶层 `uri` 属性。请求和定位需要的 URI 通过 `onOpenUri`、`defineActions` 的闭包传入。
- 切换文档时要重置筛选和展开状态，在外层给组件设置 `key={documentId}`。
- 类型从 `@openviking/react/components/wiki-dashboard` 导出，包根入口只导出组件和 `WikiDashboardProps`。
