# ExperienceDashboard 经验看板

展示 Agent 经验的使用情况：目录视图列出经验文件，文件视图展示单个经验的应用效果、来源轨迹和测试材料。

## 何时使用

- 需要在文件浏览中查看经验的使用效果，并跳转到具体的经验或轨迹时。
- 需要自己决定数据来源、分页和页面布局时：组件只负责展示，不发起请求，也不需要 `OpenVikingProvider`。
- 使用 [FileBrowser](../modules/file-browser) 时，看板已经内置，不需要单独接入。

## 引入

```tsx
import { ExperienceDashboard } from '@openviking/react/components/experience-dashboard';
import '@openviking/react/components/experience-dashboard/style.css';
```

## 代码演示

### 基础用法

切换「经验目录」「经验文件」「宿主数据」「失败状态」查看四种状态，页签支持方向键和 Home/End。「宿主数据」补充了应用效果指标和测试材料：未提供 `effect` 时指标显示「—」，提供 `testMaterials` 后才出现「测试」页签。

## API

### ExperienceDashboard

| ---------------- | ---------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | ------------------------ |
| uri              | 当前资源的 URI，变化时重置页签、时间范围等内部状态                                                                           | `string`                                                                                                    | 必填                     |
| kind             | 展示模式，不根据 `uri` 推断：`directory` 列出经验文件，`file` 展示单个经验的看板                                             | `'directory' \| 'file'`                                                                                     | 必填                     |

| tab              | 文件视图的当前页签：`impact` 应用效果、`source` 来源追溯、`test` 测试。传入后受控，需要在 `onTabChange` 里更新               | `'impact' \| 'source' \| 'test'`                                                                            | `'impact'`               |
| days             | 文件视图「应用效果」页签的统计时间范围，单位为天，可选 `7`、`30`，`0` 表示全部时间。传入后受控，需要在 `onDaysChange` 里更新 | `number`                                                                                                    | `7`                      |
| page             | 当前页码，从 0 开始                                                                                                          | `number`                                                                                                    | `0`                      |

| states           | 各区域的加载与错误状态，键的含义见「注意」                                                                                   | `Partial<Record<'list' \| 'outcomes' \| 'trajectories' \| 'sources' \| 'tests', ExperienceDashboardState>>` | `{}`                     |

| onOpenUri        | 点击经验或轨迹名称、测试材料的「打开」按钮时触发，参数为对应的 URI；省略时这些按钮禁用                                       | `(uri: string) => void`                                                                                     | -                        |
| labels           | 覆盖界面文案                                                                                                                 | `Partial<ExperienceDashboardLabels>`                                                                        | -                        |
| locale           | 界面语言，规则见[国际化](../guide/i18n)                                                                                      | `'zh-CN' \| 'en-US'`                                                                                        | 继承上级，默认 `'en-US'` |
| className、style | 外观与布局，其余 HTML 属性透传到根元素                                                                                       | HTML 属性                                                                                                   | -                        |

| --------------- | ----------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ------ |

| testMaterials   | 测试材料，字段见下方 `data.testMaterials`；提供后（包括空数组）才显示「测试」页签                           | `readonly { id: string; title: string; content: string; taskQuery?: string; uri?: string }[]`             | -      |

| --------------- | ----------------------------------------------------------------------------------------------------- | -------- | ------ |

`data.testMaterials` 数组中每一项的字段。

| 参数      | 说明                                                                                      | 类型     | 默认值 |
| --------- | ----------------------------------------------------------------------------------------- | -------- | ------ |

| content   | 材料正文，按行显示：`User:`、`Assistant:` 开头的行突出角色，`# ` 开头的行加粗；可一键复制 | `string` | 必填   |

### ExperienceDashboardState

| 参数    | 说明                                                   | 类型            | 默认值  |
| ------- | ------------------------------------------------------ | --------------- | ------- |
| loading | 区域没有数据时显示加载状态，优先于错误状态             | `boolean`       | `false` |
| error   | 区域没有数据时显示错误状态和 `error.message`           | `Error \| null` | -       |
| onRetry | 点击「重试」时触发，组件不自行发起请求；省略时按钮禁用 | `() => void`    | -       |

## 注意

- `states` 按区域设置，仅在该区域没有数据时显示，各区域的错误和重试互相独立：`list` 对应目录视图的经验列表，`outcomes` 对应任务结果分布，`trajectories` 对应应用轨迹，`sources` 对应来源追溯，`tests` 对应测试材料。
- 分页控件在 `page > 0` 或 `hasMore` 为 `true` 时出现：目录视图翻的是经验列表，文件视图只在「应用效果」页签出现，翻的是应用轨迹。对应区域的 `loading` 为 `true` 时翻页按钮禁用。
- 测试材料更新时保留当前页签和时间范围；`testMaterials` 变为 `undefined` 时，已选中的「测试」页签回退到「应用效果」。
- 复制使用 `navigator.clipboard.writeText`，它只在 HTTPS 或 localhost 下可用；不可用或被浏览器拒绝时，按钮显示「复制失败」。
- 组件高度为 `100%`，内容超出时在组件内部滚动，请给父容器设置高度。目录视图的表格最小宽度为 560px，容器更窄时横向滚动。
- 类型从 `@openviking/react/components/experience-dashboard` 导出，包括 `ExperienceDashboardTab` 和 `ExperienceOutcome`；包根入口只导出组件和 `ExperienceDashboardProps`。
