# Icons 图标

组件库内置的图标：箭头、文件类型、作用域层级和看板图标以 React 组件提供，渲染为内联 SVG；另有按文件名选择文件类型图标的函数。

## 何时使用

- 需要与组件库界面一致的图标时，例如为 [ScopeSwitcher](./scope-switcher) 的选项或 [FileTree](./file-tree) 的行提供图标。
- 需要按文件名显示对应类型的图标时，使用 `getFileTypeIcon`。

## 引入

```tsx
import { PdfIcon, getFileTypeIcon } from '@openviking/react/icons';
```

图标以内联 SVG 打包进 JavaScript，没有单独的资源请求，不需要导入样式表。

## API

### 图标组件通用属性

清单中的图标组件（`LibraryIcon` 除外）渲染为内联 `svg`，接收 `IconProps`。

| 参数             | 说明                                                                                             | 类型                      | 默认值                     |
| ---------------- | ------------------------------------------------------------------------------------------------ | ------------------------- | -------------------------- |
| width            | 图标宽度                                                                                         | `number \| string`        | 图标自带的尺寸，见图标清单 |
| height           | 图标高度                                                                                         | `number \| string`        | 图标自带的尺寸，见图标清单 |
| aria-label       | 无障碍名称；省略时 SVG 带 `aria-hidden`，作为装饰；传入后图标保留在无障碍树中                    | `string`                  | -                          |
| className、style | 为 SVG 元素设置类名和内联样式；跟随文字颜色的图标用 `color` 改色                                 | `string`、`CSSProperties` | -                          |
| 其他属性         | 标准 SVG 属性，包括 `aria-*` 和 `role`，不接收 `children`；显式传入的 `aria-hidden` 优先于默认值 | SVG 属性                  | -                          |

### LibraryIcon

固定为 14 × 14 的圆形渐变色块，渲染为 `span`，不接收 SVG 属性，也不进入无障碍树。

| 参数 | 说明                                                                   | 类型     | 默认值 |
| ---- | ---------------------------------------------------------------------- | -------- | ------ |
| name | 决定使用五组渐变中的哪一组，同一个名称始终得到同一组；省略时使用第一组 | `string` | `''`   |

### VikingBotIcon

对话相关的图标，用 `name` 选择，其余属性同图标组件通用属性。

| 参数          | 说明                                                                                         | 类型                                                                                                                              | 默认值 |
| ------------- | -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------ |
| name          | 图标名称，依次为灯泡、书本、视频、报告、历史、新建会话、移除、工具、上下文文件夹、关闭上下文 | `'bulb' \| 'book' \| 'video' \| 'report' \| 'history' \| 'newSession' \| 'remove' \| 'tool' \| 'contextFolder' \| 'contextClose'` | 必填   |
| width、height | 图标尺寸                                                                                     | `number \| string`                                                                                                                | `16`   |

### 文件类型图标函数

| 函数                     | 说明                                                                           | 类型                                                  |
| ------------------------ | ------------------------------------------------------------------------------ | ----------------------------------------------------- |
| `getFileTypeIcon`        | 取得文件名对应的图标组件，没有匹配时返回通用文件图标                           | `(name: string) => FileTypeIconComponent`             |
| `resolveFileTypeIconKey` | 取得文件名对应的图标键，没有匹配时返回 `'default'`                             | `(name: string) => string`                            |
| `getFileTypeColor`       | 取得图标键的品牌色，`scheme` 默认为 `'light'`，未登记的键返回 `'currentColor'` | `(key: string, scheme?: 'light' \| 'dark') => string` |

`name` 可以是文件名或路径，只取最后一段并忽略大小写：先匹配完整文件名，再按扩展名从长到短匹配（`tar.gz` 先于 `gz`），都没有命中时使用通用文件图标。

返回的文件类型图标使用 `currentColor`，PDF、PPT、Word、音频和视频图标除外，它们自带固定配色。用 `getFileTypeColor` 取得品牌色后设置 `color`：

```tsx
import {
  getFileTypeColor,
  getFileTypeIcon,
  resolveFileTypeIconKey,
} from '@openviking/react/icons';

function FileTypeIcon({ name }: { name: string }) {
  const Icon = getFileTypeIcon(name);
  return (
    <Icon
      aria-hidden="true"
      width={16}
      height={16}
      style={{ color: getFileTypeColor(resolveFileTypeIconKey(name)) }}
    />
  );
}
```

## 主题变量

`LibraryIcon` 有五组渐变，亮色和暗色主题使用同一组。用 `--ov-ui-color-library-swatch-1` 到 `--ov-ui-color-library-swatch-5` 逐组覆盖；没有加载库样式表时，组件使用内置的同一组渐变。

```css
:root {
  --ov-ui-color-library-swatch-1: linear-gradient(145deg, #e0f7fa, #80deea);
}
```

## 注意

- 清单中的图标默认带 `aria-hidden`，作为装饰。图标单独传达信息时，传入应用语言的 `aria-label`；旁边的文字已经说明含义时省略，避免重复播报。
- `getFileTypeIcon` 返回的组件用于装饰时，请显式传入 `aria-hidden`。
- 图标没有交互行为：放进按钮时，按钮语义、键盘交互和焦点样式由宿主提供。
- 类型 `IconProps`、`IconComponent`、`FileTypeIconComponent` 和 `VikingBotIconName` 同样从 `@openviking/react/icons` 导出；包根入口不导出图标。
