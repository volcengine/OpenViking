# VikingBot 对话

对话视图：消息列表、输入区与待确认交互区。开源版与火山版的宿主协议不同，组件只接收已归一化的消息模型，并把两版渲染方式不同的区域交给宿主替换。

**当前是占位组件**：API 契约已确定，并按契约渲染出可用视图，但视图尚未经过设计评审，真实实现会被重写。请把 props 与交互模型当作交付物，视觉表现视为临时方案。

## 两版宿主怎么接

| 差异           | 处理方式                                                             |
| -------------- | -------------------------------------------------------------------- |
| 消息形态       | 统一为 `parts[]`，`role` 覆盖 user、assistant、system、tool          |
| 执行时间线折叠 | 片段用 `groupId` 归组，`startedAt`、`durationMs` 参与展示            |
| 文本格式       | `text.format` 区分 `plain` 与 `markdown`                             |
| 工具调用       | `server`、`endpoint`、`durationMs` 覆盖 MCP 语义                     |
| 消息级动作     | `message.action` 声明动作，`onMessageAction` 上报                    |
| 流式           | `{ parts, insertIndex, iteration }`；末尾追加时传消息数量            |
| 人工确认       | `components/viking-bot/interaction` 子路径，四种内置表单加自定义渲染 |
| 渲染底座       | `messageList`、`composer`、`interaction`、`children` 四层替换        |

协议适配留在各宿主仓库，组件不引入任何后端事件类型。

## 属性

### VikingBotProps

| 属性                 | 类型                                             | 默认值 | 说明                                   |
| -------------------- | ------------------------------------------------ | ------ | -------------------------------------- |
| `messages`           | `readonly VikingBotMessage[]`                    | 必填   | 当前会话的消息。                       |
| `className`          | `string`                                         | —      | 附加到根元素的类名。                   |
| `streaming`          | `VikingBotStreamingState`                        | —      | 助手仍在生成时追加的片段。             |
| `draft`              | `string`                                         | —      | 受控草稿；不传时不展示输入区。         |
| `attachments`        | `readonly VikingBotAttachment[]`                 | —      | 宿主已选中的附件。                     |
| `isSending`          | `boolean`                                        | —      | 是否正在回复；为真时停止动作替代发送。 |
| `isAvailable`        | `boolean`                                        | `true` | 是否可接受输入。                       |
| `unavailableMessage` | `string`                                         | —      | 不可用时的说明。                       |
| `emptyState`         | `ReactNode`                                      | —      | 首条消息之前替代消息列表显示的内容。   |
| `header`             | `ReactNode`                                      | —      | 头部插槽。                             |
| `footer`             | `ReactNode`                                      | —      | 输入区上方的插槽。                     |
| `children`           | `ReactNode`                                      | —      | 替换整个主体。                         |
| `messageList`        | `ReactNode`                                      | —      | 替换消息列表，用于宿主自带渲染底座。   |
| `composer`           | `ReactNode`                                      | —      | 替换输入区。                           |
| `interaction`        | `VikingBotInteractionProps`                      | —      | 待确认交互；存在时替代输入区。         |
| `listKey`            | `string`                                         | —      | 身份作用域标识；值变化时重置展示状态。 |
| `composerRef`        | `RefObject<VikingBotComposerRef \| null>`        | —      | 输入区的命令式入口。                   |
| `onDraftChange`      | `(value: string) => void`                        | —      | 草稿变化时触发。                       |
| `onFilesAdded`       | `(files: readonly File[]) => void`               | —      | 上报用户选择或拖入的文件。             |
| `onAttachmentRemove` | `(attachment: VikingBotAttachment) => void`      | —      | 移除一个附件。                         |
| `onSend`             | `(draft: VikingBotDraft) => void`                | —      | 上报发送意图；不传时不能发送。         |
| `onCancel`           | `() => void`                                     | —      | 停止正在进行的回复。                   |
| `onOpenUri`          | `(uri: string) => void`                          | —      | 打开消息中引用的资源。                 |
| `onCopy`             | `(text: string) => void`                         | —      | 复制成功后触发；复制由宿主执行。       |
| `onMessageAction`    | `(messageId: string, actionKey: string) => void` | —      | 触发一条消息声明的动作。               |
| `labels`             | `VikingBotLabels`                                | 英文   | 可替换文案。                           |

```tsx file="../../_demos/viking-bot-interaction.tsx" preview

```

交互不是后端暂停状态：宿主从自己的流里算出问题，答案发回后清除。组件内置 `choice`、`text`、`schedule`、`repair` 四种表单；需要树选择器、上传器等宿主能力时，用 `custom` 自行渲染。

### VikingBotInteractionProps

| 属性         | 类型                                | 默认值 | 说明                                 |
| ------------ | ----------------------------------- | ------ | ------------------------------------ |
| `request`    | `VikingBotInteractionRequest`       | 必填   | 当前问题。                           |
| `className`  | `string`                            | —      | 附加到根元素的类名。                 |
| `index`      | `number`                            | `0`    | 当前步骤序号，从 0 开始。            |
| `total`      | `number`                            | `1`    | 步骤总数；大于 1 时展示进度。        |
| `disabled`   | `boolean`                           | —      | 是否禁用。                           |
| `submitting` | `boolean`                           | —      | 是否正在提交。                       |
| `error`      | `ReactNode`                         | —      | 提交失败的原因。                     |
| `onSubmit`   | `(answer) => void \| Promise<void>` | —      | 上报答案。                           |
| `onCancel`   | `() => void`                        | —      | 放弃本次交互；不传时不渲染取消按钮。 |
| `labels`     | `VikingBotInteractionLabels`        | 英文   | 可替换文案。                         |
