# VikingBot 对话

展示宿主提供的会话消息，并提供输入区和待确认交互区：发送、停止、打开资源等操作通过回调交给宿主，组件不发起请求。

## 何时使用

- 需要在自己的页面里展示 AI 会话，包括回复、推理与工具调用过程、输入区和历史会话入口时。
- 需要自己决定会话服务、流式请求和文件上传的接入方式时：组件只负责展示，不需要 `OpenVikingProvider`。
- 使用 [Console](../modules/console) 时，对话视图已经内置，不需要单独接入。

## 引入

```tsx
import { VikingBot } from '@openviking/react/components/viking-bot';
import '@openviking/react/components/viking-bot/style.css';
```

样式入口已包含主题基线和视图用到的 `@ark-design/ui` 样式，可以单独引入。

消息列表、输入区和待确认交互区由 `@ark-design/ui` 渲染。它是可选 peer 依赖，不会随 `@openviking/react` 自动安装，使用前需要安装不低于 `0.0.0-beta.7` 的版本：

```bash
npm install @ark-design/ui@0.0.0-beta.7
```

只需要待确认交互区时，可以从 `interaction` 子路径导入 `VikingBotInteraction`，样式入口相同：

```tsx
import { VikingBotInteraction } from '@openviking/react/components/viking-bot/interaction';
import '@openviking/react/components/viking-bot/style.css';
```

| interactionSlot       | 替换内置的交互表单，仅在设置了 `interaction` 时显示                                                                            | `ReactNode`                                      | -                        |
| children              | 替换根元素内的全部内容，头部、消息区和输入区都不再渲染                                                                         | `ReactNode`                                      | -                        |

| locale                | 界面语言，规则见[国际化](../guide/i18n)                                                                                        | `'zh-CN' \| 'en-US'`                             | 继承上级，默认 `'en-US'` |
| className、style      | 外观与布局，其余 HTML 属性透传到根元素                                                                                         | HTML 属性                                        | -                        |

## 注意

- 组件不发起请求：会话的加载与保存、流式连接、判断一轮回复何时结束和文件上传都由宿主处理。宿主需要把自己的消息和流式事件转换成 `VikingBotMessage` 和 `VikingBotStreamingState`。
- 根元素高度为父元素的 100%，消息区在内部滚动，需要给父元素设置高度。
- 助手回复按 Markdown 渲染，`format` 为 `'plain'` 的文本逐字显示。正文、行内代码和 `bash`、`shell`、`sh`、`text`、`txt` 代码块里的 `viking://` 地址会变成链接，点击后传给 `onOpenUri`。
- 助手回复里的 Markdown 链接只保留 `http`、`https`、`mailto`、`tel` 协议，其他协议的链接显示为纯文本；`http` 和 `https` 链接在新标签页打开。
- 用户消息同样按 Markdown 渲染，但其中的 `viking://` 地址不会变成链接。
- 相邻且 `groupId` 相同的推理和工具调用片段合并为一个执行块：标题栏显示状态和耗时，默认展开，可点击折叠；每个工具调用可以展开查看输入和输出。没有 `groupId` 的片段各自成块。
- 快捷输入在草稿为空时直接填入，否则换行后追加；再选择另一项会替换上一次填入的文案，保留前后用户自己输入的内容。
- 用户修改了已填入的文案，或宿主整体替换草稿而无法确定修改位置时，这段文案视为用户自己的内容，下一个快捷输入改为追加。
- 在输入框里输入 `@` 与点击 `@` 按钮使用同一个选择器，选中后引用加入 `references.selected`，输入框里的 `@` 查询文字被删除。引用按 URI 去重。
- 引用标签显示图标和完整 URI，空间不足时省略并在标题中保留完整路径；只显示前 5 个，其余收进 `+N`，悬停、聚焦或点击 `+N` 展开。
- 引用只出现在 `VikingBotDraft.references`，不会写进草稿文本。切换账号或会话时，宿主需要同时重置 `references.selected` 和 `attachments`。
- 待确认交互是宿主状态，不是后端暂停：宿主根据自己的流生成问题，答案发回后清除 `interaction`。组件只渲染表单，并通过 `onSubmit` 上报答案。
- 消息列表、输入区和待确认交互区在首次渲染时才加载 `@ark-design/ui`，加载期间先显示空容器。导入 VikingBot 本身不会加载它，因此模块在没有 `window` 的环境中也能导入。
- `VikingBotComposer`、`VikingBotMessageList` 和 `VikingBotSessionActions` 可以单独使用，例如把 `VikingBotSessionActions` 放进自己的顶栏。
- `groupMessages`、`groupByActivity` 和 `messageText` 与内置消息列表使用同一套规则，自定义 `messageList` 时可以直接使用。
- `DEFAULT_LABELS` 和 `DEFAULT_INTERACTION_LABELS` 是内置的英文文案，列出了各自 `labels` 的全部键。
- 类型从 `@openviking/react/components/viking-bot` 导出，包根入口只导出 `VikingBot` 和 `VikingBotProps`。`VikingBotInputFeatures` 是 `VikingBot` 与 `VikingBotComposer` 共有的 `quickInputs`、`onQuickInputSelect` 和 `references`。

## 请求与会话

使用 [VikingBot 无头模块](../modules/viking-bot) 获取请求、会话和状态管理；组件本身只接收数据与回调。[Console](../modules/console) 已内置接入该模块。
