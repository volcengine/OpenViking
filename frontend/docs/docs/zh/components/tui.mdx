# Tui 命令控制台

命令控制台主体：当前命令记录、结果、空态，以及带建议和帮助的输入区域。宿主提供命令目录并负责请求、权限、执行和会话；组件通过 `onSubmit` 上报提交意图，通过 `onCopy` 通知复制完成。

视图已实现命令记录与七种结果变体、空态，以及带补全和参数提示的受控输入。业务命令目录由宿主提供。

## 基础用法

```tsx file="../../_demos/tui-basic.tsx" preview

```

示例自己维护记录与输入：发送后追加一条等待中的记录再更新为结果，与宿主的接入方式一致。输入 `/help` 可查看模拟的命令帮助结果。

输入区是整宽的无边框编辑区域，带顶部分隔线，编辑区域最小高度 80px，底部快捷键引导高 40px。聚焦时分隔线保持原色。内容最多自适应增高至三行，超出后滚动；底部依次显示 `/ 全部指令`、`↑ 历史指令`、`↵ 发送`。↑/↓ 可回填当前记录中的命令，Enter 提交，Shift+Enter 换行，不单独渲染发送按钮。

输入 `o` 时会以灰字提示 `v`，按 Tab 接受前缀；也可直接按空格补成 `ov `。在 `ov ` 后按 Tab 打开全部命令，继续输入字母可筛选候选并预览剩余文字，再按 Tab 接受行内提示或已选中的命令。普通输入只显示行内提示，`/` 和显式 Tab 才展开列表；补全根据宿主的 `inputText` 推导。普通 Tab 始终保留输入区焦点：无补全、输入参数或光标位于中间时保持原值和页面位置；Shift+Tab 可移出输入区。灰字不会进入提交值。

输入 `/`，或在 `ov ` 后按 Tab，都会展开未选中任何命令的候选列表；筛选或重新打开时也清除选中状态。未选择时，↓ 从第一项开始，↑ 从最后一项开始。悬停或使用方向键选择后，侧边才显示示例与参数表。没有关键字也未选择候选时，Tab 不填入命令。横向空间不足时，详情与列表上下排列。Esc 或点击区域外可关闭浮层；不支持原生 Popover 的浏览器回退为内联面板。

选中命令后，编辑区以主题色显示 `inputText` 前缀，在其后用浅色直接提示位置参数；没有位置参数时提示必填选项。开始填写参数后，占位提示收起，且不会写入 `value` 或提交文本。完整详情面板只在命令候选列表展开时展示。

命令记录按同一份 `inputText` 显示并着色前缀，参数原样保留；时间单独位于下一行并右对齐。复制和历史回填使用相同前缀，未匹配目录的命令按原文显示。

共用示例通过 `useLang()` 跟随文档站语言，同时提供对应语言的命令描述、分组和结果。`locale="zh"` 选择中文界面文案，默认 `locale="en"`；`labels` 可单独覆盖界面文案。命令和结果文案由宿主本地化。

## 组件边界

Tui 只包含当前命令记录与结果、空态，以及带建议和帮助的命令输入区。新建会话、历史记录面板、视图与用户切换、外层工具栏，由宿主通过独立组件组合。

宿主处理会话和历史操作后，更新 `records` 与 `value`。历史结果复用同一套记录视图；Tui 不维护历史列表、专门的历史预览状态，也不提供外层工具栏或动作插槽。

宿主通过 `commands` 和可选的 `commandGroups` 提供目录；Tui 负责筛选、高亮、键盘选择、填入及参数帮助。接受补全通过 `onValueChange` 更新输入；显式提交触发 `onSubmit`，由宿主执行并通过 `records` 回填状态和结果。

命令名称、别名、分组、说明、参数、选项和示例都是描述数据。新增命令沿用现有描述和结果类型时，只需更新宿主数据，无需发布组件。宿主可以自行加载或更新服务端目录，Tui 不取数。示例目录位于 `docs/docs/_demos/tui-commands/`。

## 属性

公开的 props 从同一子路径以类型导出，以源码为准：

```tsx
import type {
  TuiCommandDefinition,
  TuiCommandGroup,
  TuiLabels,
  TuiProps,
  TuiRecord,
  TuiRecordContent,
  TuiSearchResultItem,
} from '@openviking/react/components/tui';
```

下表说明已实现的行为。

| 属性          | 类型                            | 默认值       | 说明                                                                                   |
| ------------- | ------------------------------- | ------------ | -------------------------------------------------------------------------------------- |
| records       | readonly TuiRecord[]            | 必填         | 当前展示的执行记录，按提交顺序排列；会话与历史切换后由宿主更新。                       |
| value         | string                          | 必填         | 受控输入值。                                                                           |
| disabled      | boolean                         | false        | 禁用命令输入与提交，提示文案由 `labels.unavailableMessage` 提供。                      |
| emptyState    | ReactNode                       | labels.empty | 无记录时展示的完整空态，可包含标题、说明与快捷入口；传 `null` 时隐藏。                 |
| locale        | `"en" \| "zh"`                  | `"en"`       | 内置界面文案的语言；labels 可单独覆盖界面文案。                                        |
| commands      | readonly TuiCommandDefinition[] | `[]`         | 宿主命令目录，用于补全、帮助及等待骨架。                                               |
| commandGroups | readonly TuiCommandGroup[]      | `[]`         | 宿主分组名称和顺序；未声明的组按目录顺序追加。                                         |
| labels        | TuiLabels                       | —            | 统一的界面文案与引导提示。                                                             |
| onValueChange | (value: string) => void         | —            | 上报输入变化，包含接受的命令和示例；行内占位不改变输入值，也不提交。省略时输入框只读。 |
| onSubmit      | (command: string) => void       | —            | 显式提交时上报意图，由宿主执行；省略时不能提交。                                       |
| onOpenUri     | (uri: string) => void           | —            | 资源成功打开后触发，参数为已打开的 URI；失败时不触发。                                 |
| onCopy        | (text: string) => void          | —            | 复制成功后触发，参数为已复制的文本；失败时不触发。省略回调不影响复制。                 |

`onSubmit` 上报提交的文本，不等待执行结果。宿主负责发送、权限和执行，并更新等待、成功或失败的记录；已有 `pending` 记录不阻止后续提交。

`emptyState` 是完整自定义空态的唯一入口。标题、说明、快捷入口及其交互由宿主在节点内组合。省略时展示 `labels.empty`，传 `null` 时隐藏空态内容。

### 命令描述

`TuiCommandDefinition` 包含 `name`、`description`、`usage`，以及可选的 `inputText`、`summary`、`aliases`、`group`、`params`、`options`、`examples` 和 `skeleton`。参数使用 `label`，选项使用 `token`，两者均支持 `description`、`required` 和 `defaultValue`。`inputText` 指定接受命令时填入的前缀，默认 `name`；demo 提供 `ov read` 等 CLI 前缀。`required` 默认 `false`，省略 `defaultValue` 时展示破折号。分组包含 `key` 和 `label`。示例接受字符串或 `{ value, label? }`，选择后仅填入 `value`；宿主可展示带 CLI 前缀的示例，同时填入斜杠命令。

省略 `commands` 时仍可输入和提交文本，但不展示命令候选或参数帮助。组件不翻译宿主描述，也不校验命令权限。

### 结果内容

`TuiRecordContent` 包含一种通用文本与六种结构化结果：

| variant          | 数据            | 说明                         |
| ---------------- | --------------- | ---------------------------- |
| text             | text, format?   | 通用输出，格式缺省为 plain。 |
| search-list      | items, summary? | 检索结果与汇总。             |
| resource-preview | title, content  | 资源正文预览。               |
| resource-tree    | items, title?   | 资源条目与明细。             |
| status           | rows, title?    | 键值状态行。                 |
| write-result     | lines, title?   | 写入操作结果。               |
| command-help     | sections        | 按分组展示可用命令。         |

`text.format` 支持 `plain` 和 `markdown`，缺省为 `plain`。JSON 格式化为字符串后通过 `text` 展示。失败通过 `TuiRecord.status: 'error'` 表达，错误正文使用文本结果，不单独定义错误内容变体。

每种变体都有对应视图：纯文本或 Markdown（JSON 自动缩进）、带分数详情的检索行、资源预览、可按列对齐并分页的资源表、状态行、写入结果行与分组命令帮助。文本结果中的 URI 可打开。CLI 输出到这些变体的转换仍由宿主负责。

### 文案与引导提示

通用界面文案跟随 `locale`，可通过 `labels` 逐项覆盖。命令名称、分组、说明和参数帮助来自宿主描述。

| 属性                      | 类型   | 说明                                                          |
| ------------------------- | ------ | ------------------------------------------------------------- |
| labels.unavailableMessage | string | `disabled` 为 `true` 时的不可用提示；仅修改文案不会禁用组件。 |
| labels.pending            | string | 等待中的状态文本。                                            |
| labels.empty              | string | 无记录且未提供 `emptyState` 时展示的默认提示。                |
| labels.allCommands        | string | `/` 全部指令的快捷键说明。                                    |
| labels.historyCommands    | string | `↑` 历史指令的快捷键说明，回填范围为当前 records。            |
| labels.send               | string | `↵` 发送的快捷键说明。                                        |

`disabled` 缺省为 `false`。设为 `true` 时禁用命令输入与提交，提示内容由 `labels.unavailableMessage` 定制。

参数帮助标题、表头、必填文案和分页提示也可通过 `labels.parameters`、`examples`、`noParameters`、`parameter`、`required`、`description`、`defaultValue`、`yes`、`no` 和 `loadMore` 覆盖。

### 检索结果详情

`TuiSearchResultItem` 支持以下可选展示字段：

| 属性         | 类型      | 说明                                                                   |
| ------------ | --------- | ---------------------------------------------------------------------- |
| levelLabel   | string    | 标题旁的内容层级标签。                                                 |
| typeLabel    | string    | 分数旁的结果类型标签。                                                 |
| scoreLabel   | string    | 宿主格式化后的分数文案。                                               |
| scoreDetails | ReactNode | 悬停或键盘聚焦分数时展示的宿主详情内容，仅在提供 `scoreLabel` 时显示。 |

### 等待中的记录

`TuiRecord` 为 `pending` 时，组件按命令名或别名匹配宿主目录，使用描述的可选 `skeleton`；未提供或未识别时使用通用骨架。等待时可省略 `content`。

组件和样式的导入方式：

```tsx
import { Tui } from '@openviking/react/components/tui';
import '@openviking/react/components/tui/style.css';
```

## 实现范围

组件渲染宿主数据并处理本地输入交互。请求、响应转换、执行、持久化、权限和网络连接由宿主负责。
