# Tui 命令控制台

命令输入、执行记录与结果展示。执行由宿主负责；组件渲染记录，并上报提交、取消与历史预览意图。

当前是占位组件：只渲染一个固定尺寸的空壳，不消费 props，宿主可先对着已发布的包开发，真实视图后续迁入。下方的 props 契约是最终形态，占位实现会被替换。

## 基础用法


占位尺寸为 360 × 560，对齐右侧命令面板。

## 属性

公开的 props 从同一子路径以类型导出，以源码为准：

```tsx
import type { TuiProps } from '@openviking/react/components/tui';
```

| 属性     | 类型 | 默认值 | 说明                       |
| -------- | ---- | ------ | -------------------------- |
| 其余属性 | —    | —      | 占位组件不消费任何 props。 |

```tsx
import { Tui } from '@openviking/react/components/tui';
import '@openviking/react/components/tui/style.css';
```

## 实现范围

组件只渲染视图并上报意图。取数、持久化、权限与任何网络连接都由宿主负责。
