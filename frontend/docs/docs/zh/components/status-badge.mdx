## 自定义标签

通过 children 提供业务相关或翻译后的标签。以下共享示例使用英文文案；组件默认文案仍为英文，切换文档语言不会改变组件行为。


例如，传入 `<StatusBadge status="ready">已连接</StatusBadge>` 即可显示中文标签。

## 属性

| 属性        | 类型                                 | 默认值   | 说明                                                    |
| ----------- | ------------------------------------ | -------- | ------------------------------------------------------- |
| `status`    | `'ready' \| 'processing' \| 'error'` | 必填     | 选择指示器颜色和默认文案。                              |
| `children`  | `ReactNode`                          | 状态文案 | 替换默认英文标签。                                      |
| `className` | `string`                             | —        | 为外层 span 添加类名。                                  |
| 其他属性    | `HTMLAttributes<HTMLSpanElement>`    | —        | 标准 span 属性，包括 `aria-*`、`title` 和事件处理函数。 |

```tsx
import { StatusBadge, type StatusBadgeStatus } from '@openviking/react';
import '@openviking/react/style.css';
```

## 无障碍

状态通过可见文字表达，不只依赖颜色。徽标本身不具有交互行为。需要播报状态变化时，由应用将其放入 live region 中，具体见交互示例。

## 主题变量

| CSS 变量                    | 默认值    | 用途                                 |
| --------------------------- | --------- | ------------------------------------ |
| `--ov-ui-status-ready`      | `#187347` | 就绪状态的文字、边框与指示器颜色。   |
| `--ov-ui-status-processing` | `#2563c5` | 处理中状态的文字、边框与指示器颜色。 |
| `--ov-ui-status-error`      | `#c43838` | 错误状态的文字、边框与指示器颜色。   |
| `--ov-ui-radius`            | `6px`     | 徽标圆角。                           |

## 实现边界

`StatusBadge` 只展示调用方传入的状态。请求、重试、权限和状态切换由应用负责。
