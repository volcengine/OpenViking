# Search 搜索

检索入口、检索方式切换与高级筛选。检索方式与筛选项由宿主声明，请求、排序与分页由宿主负责；组件负责渲染并上报意图。

当前是占位组件：只渲染一个固定尺寸的空壳，不消费 props，宿主可先对着已发布的包开发，真实视图后续迁入。

## 基础用法

```tsx file="../../_demos/search-basic.tsx" preview

```

占位尺寸为 960 × 640，对齐整页视图。

## 属性

组件当前不消费任何 props：

| 属性     | 类型 | 默认值 | 说明                       |
| -------- | ---- | ------ | -------------------------- |
| 其余属性 | —    | —      | 占位组件不消费任何 props。 |

```tsx
import { Search } from '@openviking/react/components/search';
import '@openviking/react/components/search/style.css';
```

## 实现范围

组件只渲染视图并上报意图。取数、持久化、权限与任何网络连接都由宿主负责。
