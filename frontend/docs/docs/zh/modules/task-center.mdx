# TaskCenter 任务中心

两个任务列表合成一个模块：数据源导入与知识编译。每个页签有自己的数据源、列与定时语义。模块自己取数，宿主提供配置、受控状态、列配置、插槽与文案。

组件当前是占位实现：展示模块名称与占位文案。下面的 props 已定型，接入方可以先完成容器与状态接入；组合视图与 `useTaskCenter` 随后补充。

## 两个页签

| 页签       | 数据源           | 定时的含义                         |
| ---------- | ---------------- | ---------------------------------- |
| 数据源导入 | 定时同步的 watch | 固定间隔（分钟），到点重新导入资源 |
| 知识编译   | 编译目标         | 每日或每周的固定时刻，到点重新编译 |

两者不是同一个字段的两种展示。watch 按间隔重新导入；编译目标按墙钟时刻重跑。

## 模块负责什么

- 每个页签的列表、加载/空态/失败状态，以及页签内的表头筛选。
- 定时列，含编辑控件。
- 从当前身份判断「其他成员任务」范围是否可用。

## 宿主负责什么

- 通过 Provider 提供请求配置，模块可用 `requestOptions` 逐字段覆盖。
- 登录、账号作用域与权限。
- 任务详情：由模块内部以抽屉展示，宿主不参与打开任务。
- 写入定时变更。`onSaveScheduleInterval` 与 `onSaveCompileSchedule` 返回 Promise：写入成功后 resolve，模块重新取数；失败则 reject，模块保留编辑内容并展示 `labels.saveFailed`。两者分开是因为导入任务按间隔同步，编译目标按每日或每周的固定时刻更新。
- 工具栏，通过 `slots.toolbar` 注入。行末操作内置：详情入口与定时编辑。

## 列

省略 `columns` 时，每个页签使用自己的内置列与默认顺序：

| 页签       | 内置列                                                                       |
| ---------- | ---------------------------------------------------------------------------- |
| 数据源导入 | 资源名称、定时同步、数据来源、最近更新时间、任务创建时间、路径               |
| 知识编译   | 目录、状态、冲突文件数、任务类型、定时更新、最近更新时间、任务创建时间、路径 |

传 `columns.import` 或 `columns.compile` 可以调整顺序、隐藏或覆盖某一列，也可以新增列：

```tsx
<TaskCenter
  columns={{
    compile: [
      { key: 'name', width: 280 },
      { key: 'schedule' },
      { key: 'conflicts', title: '冲突数' },
      {
        key: 'artifacts',
        title: '产物',
        render: (row) => <Artifacts uri={row.toUri} />,
      },
    ],
  }}
/>
```

自定义 key 必须提供 `render`；内置 key 省略时使用默认单元格。

## 属性

模块从子路径和根入口导出 `TaskCenterProps`。`TaskCenterTab`、`TaskCenterScope`、`TaskCenterLabels`、`TaskCenterSlots`、行类型与列类型只从子路径导出。

| 属性                     | 类型                                              | 默认值   | 说明                                                                                                                                                                                        |
| ------------------------ | ------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tab`                    | `'import' \| 'compile'`                           | —        | 受控的当前页签。传入时由宿主决定，模块只上报切换意图。                                                                                                                                      |
| `defaultTab`             | `'import' \| 'compile'`                           | `import` | 非受控时的初始页签。                                                                                                                                                                        |
| `scope`                  | `'mine' \| 'others'`                              | —        | 受控的可见范围。传入时由宿主决定。                                                                                                                                                          |
| `defaultScope`           | `'mine' \| 'others'`                              | `mine`   | 非受控时的初始范围。                                                                                                                                                                        |
| `columns`                | `TaskCenterColumns`                               | —        | 各页签的列配置。省略时使用各自的内置列与默认顺序。                                                                                                                                          |
| `onTabChange`            | `(tab: TaskCenterTab) => void`                    | —        | 页签变化后触发。                                                                                                                                                                            |
| `onScopeChange`          | `(scope: TaskCenterScope) => void`                | —        | 可见范围变化后触发。                                                                                                                                                                        |
| `onSaveScheduleInterval` | `(row, intervalMinutes: number) => Promise<void>` | —        | 保存导入任务的同步间隔。写入成功后 resolve，模块重新取数；reject 时保留编辑内容并展示 `labels.saveFailed`。                                                                                 |
| `onSaveCompileSchedule`  | `(row, schedule \| null) => Promise<void>`        | —        | 保存编译目标的定时规则。参数与原生 `update_schedule` 同形——`{ frequency: 'daily', hour, minute }` 或 `{ frequency: 'weekly', weekday, hour, minute }`——宿主可直接转发。传 `null` 关闭定时。 |
| `onOpenResource`         | `(uri: string) => void`                           | —        | 打开资源时触发，例如导入任务的目标路径。                                                                                                                                                    |
| `slots`                  | `TaskCenterSlots`                                 | —        | `toolbar` 与 `emptyState`。                                                                                                                                                                 |
| `labels`                 | `TaskCenterLabels`                                | —        | 可替换文案：页签与范围名称、占位说明 `description`、`empty`、`error`、`retry`、定时列及其状态文案。                                                                                         |
| `className`              | `string`                                          | —        | 容器附加类名。                                                                                                                                                                              |
| `style`                  | `CSSProperties`                                   | —        | 容器样式覆盖。                                                                                                                                                                              |

文案为纯文本，宿主可将自身的翻译结果映射到这些属性。props 里没有数据字段——数据由模块自己加载，任务状态归任务数据源，不在模块内复制维护。

「其他成员任务」是否出现取决于当前身份，由模块自行读取，没有权限开关；宿主已解析过身份也不需要重复传入。

占位组件当前只消费 `className`、`style`、`labels.title` 与 `labels.description`。
