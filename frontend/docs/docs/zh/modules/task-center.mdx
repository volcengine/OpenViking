# TaskCenter 任务中心

当前身份可见的任务、详情与执行记录。模块自己取数，宿主提供配置、受控选中、筛选条件、插槽与文案。

组件当前是占位实现：只展示模块名称与占位文案。下面的 props 已定型，接入方可以先完成容器与状态接入；组合视图与 `useTaskCenter` 随后补充。

## 模块负责什么

- 任务列表、其分页、加载与失败状态，以及选中任务的详情。
- 按宿主给定的状态与类型筛选条件发起请求。

## 宿主负责什么

- 通过 Provider 提供请求配置，模块可用 `requestOptions` 逐字段覆盖。
- 登录、账号作用域与权限。
- 筛选控件与工具栏，通过 `slots.toolbar` 注入；宿主决定有哪些筛选项，并把结果通过 `statuses` 与 `taskTypes` 传入。
- 详情区的附加内容，例如产物列表，通过 `slots.detailExtra` 注入。

## 属性

模块从子路径和根入口导出 `TaskCenterProps`，`TaskCenterStatus`、`TaskCenterLabels` 与 `TaskCenterSlots` 只从子路径导出。

| 属性                    | 类型                               | 默认值 | 说明                                                                                    |
| ----------------------- | ---------------------------------- | ------ | --------------------------------------------------------------------------------------- |
| `requestOptions`        | `OvRequestOptions`                 | —      | 请求配置覆盖，逐字段覆盖最近的 Provider。                                               |
| `selectedTaskId`        | `string`                           | —      | 受控的选中任务 id。传入时由宿主决定选中项，模块只上报选择意图。                         |
| `defaultSelectedTaskId` | `string`                           | —      | 非受控时的初始选中任务 id。省略时不选中任何任务。                                       |
| `onSelectedTaskChange`  | `(taskId: string \| null) => void` | —      | 选中任务变化后触发；清除选中时传入 `null`。                                             |
| `statuses`              | `readonly TaskCenterStatus[]`      | —      | 只保留这些状态的任务。省略时不按状态过滤。                                              |
| `taskTypes`             | `readonly string[]`                | —      | 只保留这些类型的任务，例如 `session_commit`。省略时不按类型过滤。                       |
| `slots`                 | `TaskCenterSlots`                  | —      | `toolbar`、`detailExtra` 与 `emptyState`。                                              |
| `labels`                | `TaskCenterLabels`                 | —      | 可替换文案：`title`、`empty`、`error`、`retry`、`noSelection`。未提供时沿用英文默认值。 |
| `className`             | `string`                           | —      | 容器附加类名。                                                                          |
| `style`                 | `CSSProperties`                    | —      | 容器样式覆盖。                                                                          |

文案为纯文本，宿主可将自身的翻译结果映射到这些属性。props 里没有数据字段——数据由模块自己加载，任务状态归任务数据源，不在模块内复制维护。

占位组件当前只消费 `className`、`style` 与 `labels.title`。
