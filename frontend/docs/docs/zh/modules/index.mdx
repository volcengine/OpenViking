# 业务模块

五个个人终端模块已提供占位组件，可先接入布局。每个组件展示模块名称与可替换的占位文案；业务 Hook、API 请求和模块内部交互随实际能力迁入后补充。

| 模块                               | 组件           | 目标能力     |
| ---------------------------------- | -------------- | ------------ |
| [`file-browser`](./file-browser)   | `FileBrowser`  | 文件浏览。   |
| [`console`](./console)             | `Console`      | 交互面板。   |
| [`agent-connect`](./agent-connect) | `AgentConnect` | Agent 接入。 |
| [`task-center`](./task-center)     | `TaskCenter`   | 任务中心。   |
| [`user-usage`](./user-usage)       | `UserUsage`    | 我的用量。   |

## 导入与样式

从 `@openviking/react/modules/<模块>` 导入组件及其 Props / Labels 类型。五个组件与对应类型也从根入口 `@openviking/react` 导出。

JavaScript 不加载 CSS。单模块使用 `@openviking/react/modules/<模块>/style.css`，全部模块使用 `@openviking/react/modules/style.css`，整库使用 `@openviking/react/style.css`，每个样式入口均可独立消费。没有 `@openviking/react/modules` 分类聚合 JavaScript 入口。

当前占位组件接受 `className`、`style` 和 `labels`，无需 Provider。业务 Hook、共享 Client 与 `OpenVikingProvider` 仍为规划，尚未导出。

## 宿主职责

页面布局、认证、账号作用域、路由和权限由宿主负责。产品引导、资源与 Skill 导入流程及同步配置留在宿主；管理后台不在这些模块的范围内。
