# 业务模块

FileBrowser 已通过 `useFileBrowser` 实现目录、搜索与预览联动；Console 提供原生命令面板及独立 `useConsole`，ScopeCascade 提供级联选择。对话服务由宿主接入。

props 里没有数据字段。模块通过 Hook 自己取数，宿主给配置与受控值，模块通过回调上报变化。

| 模块                             | 组件                     | 目标能力   |
| -------------------------------- | ------------------------ | ---------- |
| [`file-browser`](./file-browser) | `FileBrowser`            | 文件浏览。 |
| [`console`](./console)           | `Console` / `useConsole` | 交互面板。 |

## 导入与样式

从 `@openviking/react/modules/<模块>` 导入组件及其 Props / Labels / Slots 类型。两个组件的本体与主 Props 类型也从根入口 `@openviking/react` 导出；Labels、Slots 与枚举类型只从子路径导入。

JavaScript 不加载 CSS。单模块使用 `@openviking/react/modules/<模块>/style.css`，全部模块使用 `@openviking/react/modules/style.css`，整库使用 `@openviking/react/style.css`，每个样式入口均可独立消费。没有 `@openviking/react/modules` 分类聚合 JavaScript 入口。

模块请求继承 `@openviking/react/client` 提供的 `OpenVikingProvider`，`useFileBrowser` 和 `useConsole` 均可独立使用。FileBrowser 自动加载目录；Console 挂载本身不发请求，提交命令后才访问服务。

## 宿主职责

页面布局、认证、账号作用域、路由和权限由宿主负责。产品引导、资源与 Skill 导入流程及同步配置留在宿主；管理后台不在这些模块的范围内。

## 级联选择

[ScopeCascade 级联选择](./scope-cascade) 提供已实现的请求与级联 Hook 及默认视图。只需传三个宿主接口，各级独立订阅。
