# FileBrowser 文件浏览

目录导航、搜索与内容预览作为一个模块。模块自己取数，宿主提供配置、受控的当前资源、工具栏入口与文案。

组件已实现目录树、搜索与预览的联动：目录按需展开并分页，点击文件加载预览，搜索结果选中后同样打开预览。`useFileBrowser` 可单独使用，自行组装视图。

## 基础用法

示例用固定数据，不访问网络：

```tsx file="../../_demos/file-browser-basic.tsx" preview

```

## 范围

模块只覆盖文件树与文件预览两块。命令面板属于 `console`。

## 模块负责什么

- 目录、搜索、当前 URI 与预览加载在模块内协调：点击目录节点或搜索结果即移动选中并加载预览，切换资源时丢弃过期请求。点目录同时展开它并把它设为当前资源，右侧显示该目录的 L1 概览（为空时回落到 L0 摘要）。
- 保存、重命名或删除后刷新受影响的目录、搜索结果与预览。
- 搜索、目录与预览区域的布局，包括树与详情之间的可拖拽分隔条。树默认 352px，可在 200px 到「给详情留出可读宽度」的上限之间拖动，分隔条获得焦点后方向键同样能改宽。
- 工具栏里的搜索框与刷新按钮，以及行级状态，例如上传进度、冲突标记与保留策略设置。
- 预览页签。某个资源有哪些页签由资源本身决定，宿主不需要提供。
- 搜索视图。搜索是本模块内部的私有视图，不是公开的组件或模块：从工具栏或 ⌘K 打开，选中结果后移动目录树并加载预览。它不对外导出——离开目录树，搜索就没有去处。`console` 的 `@` 引用是基于同类接口的另一个视图，不是这一个。

## 宿主负责什么

- 通过 Provider 提供请求配置，模块可用 `requestOptions` 逐字段覆盖。
- 登录、账号作用域、路由与权限。
- 顶部入口条里的入口，例如连接 Agent、导入资源。用 `FileBrowserEntries` 在 `toolbarActions` 里组合，图标、文案与分隔线由它负责。需要菜单时把它包在气泡或下拉里。
- 接入弹窗、导入流程与引导。模块都不内置。

## 入口与工具栏

顶部是宿主入口条（主色浅底），其下是模块自己的搜索框与刷新按钮。宿主通过 `toolbarActions` 添加入口，用 `FileBrowserEntries` 保证外观一致：

```tsx
import { FileBrowserEntries } from '@openviking/react/components/file-browser-entries';
import '@openviking/react/components/file-browser-entries/style.css';
import { FileBrowser } from '@openviking/react/modules/file-browser';

<FileBrowser
  toolbarActions={
    <FileBrowserEntries
      onConnectAgent={connect}
      onImportResources={openImport}
      labels={{ connectAgent: '连接 Agent', importResources: '导入资源' }}
    />
  }
/>;
```

`FileBrowserEntries` 固定是两个入口，省略某个回调即隐藏对应入口；图标、文案与两者之间的分隔线都由它负责，宿主只决定显示哪几个与点击后做什么。只显示一个入口时不画分隔线。

`toolbarActions` 是节点，需要菜单的入口直接把 `FileBrowserEntries` 包起来，不需要再加字段：

```tsx
<Popover content={<ResourceMenu />} trigger="hover">
  <FileBrowserEntries onImportResources={openImport} />
</Popover>
```

## 目录树宽度

树与详情之间有一条可拖拽的分隔条，把指针放在上面左右拖就能改树宽；分隔条获得焦点后，左右方向键每次调整 16px。

- 默认 352px，与设计稿一致；最小 200px，再窄就只剩图标可辨。
- 上限是 520px 与「容器宽度减去详情区 320px、分隔条 24px」中的较小值。宿主把模块放进窄栏时，树会跟着收窄，不会把详情挤没。
- 拖动只改变当前实例的宽度，不写 `localStorage`：宽度属于布局，要不要记住是宿主的决定。

宽度由模块自己持有，并以 `--ov-file-browser-tree-width` 写在容器上——想改默认值或另做布局联动时读它即可，但覆盖它不会改变实际宽度，因为拖动的结果会立刻写回同一个变量。要固定宽度，请把模块包在定宽容器里，由容器的宽度上限约束。

分隔条的无障碍名称来自 `labels.resizeTree`，需要跟随界面语言时覆盖它。

## 失败态

读不到和读到空是两件事，模块分开呈现：

- 目录列表失败时，树里显示失败行与重试按钮，而不是「没有文件」。根目录失败也一样——把它画成空态会让 403 看起来像目录本来就没有内容。
- 预览失败时，右侧显示失败态：`labels.error` 作结论、服务端返回的原始消息作原因、`labels.retry` 作重试。有选中的资源却读不出来时不会回落到空态插画。
- 只有真正没选中资源时才显示空态。
- 搜索失败同样显示原因与重试，而不是「没有匹配结果」：两者在界面上完全不同，混成空态会让一次 403 看起来像搜索确实没有命中。

失败态的重试会重新取数目录、当前预览与进行中的搜索——外部改动之后，只刷树会让右侧继续显示旧正文。

## 属性

模块从子路径和根入口导出 `FileBrowserProps`；`FileBrowserLabels` 只从子路径导出。入口条 `FileBrowserEntries` 属于组件层，从 `@openviking/react/components/file-browser-entries` 导入。

| 属性                 | 类型                            | 默认值      | 说明                                                                                                                                                                                                                       |
| -------------------- | ------------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `requestOptions`     | `OvRequestOptions`              | —           | 请求配置覆盖，逐字段覆盖最近的 Provider。                                                                                                                                                                                  |
| `uri`                | `string`                        | —           | 受控的当前资源 URI。传入时由宿主决定当前资源，模块只上报切换意图。                                                                                                                                                         |
| `defaultUri`         | `string`                        | —           | 非受控时的初始资源 URI。省略时不选中任何资源。                                                                                                                                                                             |
| `toolbarActions`     | `ReactNode`                     | —           | 工具栏上方的宿主入口，用 `FileBrowserEntries` 组合。搜索框与刷新按钮由模块自己渲染。                                                                                                                                       |
| `onUriChange`        | `(uri: string \| null) => void` | —           | 当前资源变化后触发；清除选中时传入 `null`。                                                                                                                                                                                |
| `rootUri`            | `string`                        | `viking://` | 目录树的根，宿主据此把浏览范围收敛到某个子树。                                                                                                                                                                             |
| `defaultExpandedUri` | `string`                        | —           | 首次加载后自动展开到的路径，逐级展开并加载。省略时只展开根，其余折叠。                                                                                                                                                     |
| `locale`             | `'en-US' \| 'zh-CN'`            | —           | 透传给预览底座的文案语言。组件自身文案仍由 `labels` 控制。                                                                                                                                                                 |
| `labels`             | `FileBrowserLabels`             | —           | 可替换文案：`searchPlaceholder`、`searchEmpty`、`loading`、`refresh`、`empty`、`error`、`retry`、`previewMode`、`sourceMode`、`history`、`copyPath`、`viewSwitch`、`resizeTree`，以及透传给树与预览的 `tree` / `preview`。 |
| `className`          | `string`                        | —           | 容器附加类名。                                                                                                                                                                                                             |
| `style`              | `CSSProperties`                 | —           | 容器样式覆盖。                                                                                                                                                                                                             |

文案为纯文本，宿主可将自身的翻译结果映射到这些属性。props 里没有数据字段——数据由模块自己加载。

模块通过 `useFileBrowser` 自己取数，宿主无需提供目录或预览数据；`labels.tree` 与 `labels.preview` 分别透传给文件树与文件预览组件。
