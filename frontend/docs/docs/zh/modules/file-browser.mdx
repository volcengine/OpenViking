# FileBrowser 文件浏览

目录导航、搜索与内容预览作为一个模块。模块自己取数，宿主提供配置、受控的当前资源、工具栏入口与文案。

组件已实现目录树、搜索与预览的联动：目录按需展开并分页，点击文件加载预览，搜索结果选中后同样打开预览。`useFileBrowser` 可单独使用，自行组装视图。

## 基础用法

示例用固定数据，不访问网络：

```tsx file="../../_demos/file-browser-basic.tsx" preview

```

## 范围

模块只覆盖文件树与文件预览两块。命令面板属于 `console`。

## 模块负责什么

- 目录、搜索、当前 URI 与预览加载在模块内协调：点击目录节点或搜索结果即移动选中并加载预览，切换资源时丢弃过期请求。点目录同时展开它并把它设为当前资源，右侧显示该目录的 L1 概览（为空时回落到 L0 摘要）。
- 保存、重命名或删除后刷新受影响的目录、搜索结果与预览。
- 搜索、目录与预览区域的布局。
- 工具栏里的搜索框与刷新按钮，以及行级状态，例如上传进度、冲突标记与保留策略设置。
- 预览页签。某个资源有哪些页签由资源本身决定，宿主不需要提供。
- 搜索视图。搜索是本模块内部的私有视图，不是公开的组件或模块：从工具栏或 ⌘K 打开，选中结果后移动目录树并加载预览。它不对外导出——离开目录树，搜索就没有去处。`console` 的 `@` 引用是基于同类接口的另一个视图，不是这一个。

## 宿主负责什么

- 通过 Provider 提供请求配置，模块可用 `requestOptions` 逐字段覆盖。
- 登录、账号作用域、路由与权限。
- 顶部入口条里的按钮，例如连接 Agent、导入资源。用 `FileBrowserToolbarButton` 在 `toolbarActions` 里组合，外观与控制台一致。只靠点击不够时，入口可以包在气泡或下拉里。
- 接入弹窗、导入流程与引导。模块都不内置。

## 入口与工具栏

顶部是宿主入口条（主色浅底），其下是模块自己的搜索框与刷新按钮。宿主通过 `toolbarActions` 添加入口，用 `FileBrowserToolbarButton` 保证外观一致：

```tsx
import {
  FileBrowser,
  FileBrowserToolbarButton,
} from '@openviking/react/modules/file-browser';

<FileBrowser
  toolbarActions={
    <>
      <FileBrowserToolbarButton icon={<ConnectIcon />} onClick={connect}>
        连接 Agent
      </FileBrowserToolbarButton>
      <span className="ov-file-browser__entry-divider" aria-hidden="true" />
      <FileBrowserToolbarButton icon={<UploadIcon />} onClick={openImport}>
        导入资源
      </FileBrowserToolbarButton>
    </>
  }
/>;
```

入口之间的分隔线用 `ov-file-browser__entry-divider` 显式插入——它是一根竖线，不是自动推断的，所以宿主想在哪两个入口之间分隔就在哪里放。

`toolbarActions` 是节点，需要菜单的入口直接把自己的按钮包起来，不需要再加字段：

```tsx
<Popover content={<ResourceMenu />} trigger="hover">
  <FileBrowserToolbarButton icon={<UploadIcon />}>
    导入资源
  </FileBrowserToolbarButton>
</Popover>
```

## 属性

模块从子路径和根入口导出 `FileBrowserProps`，`FileBrowserToolbarButton`、`FileBrowserToolbarButtonProps` 与 `FileBrowserLabels` 只从子路径导出。

| 属性                 | 类型                            | 默认值      | 说明                                                                                                                                                                                                         |
| -------------------- | ------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `requestOptions`     | `OvRequestOptions`              | —           | 请求配置覆盖，逐字段覆盖最近的 Provider。                                                                                                                                                                    |
| `uri`                | `string`                        | —           | 受控的当前资源 URI。传入时由宿主决定当前资源，模块只上报切换意图。                                                                                                                                           |
| `defaultUri`         | `string`                        | —           | 非受控时的初始资源 URI。省略时不选中任何资源。                                                                                                                                                               |
| `toolbarActions`     | `ReactNode`                     | —           | 工具栏左侧的宿主入口，用 `FileBrowserToolbarButton` 组合。搜索、刷新与入口之间的分隔线由模块负责。                                                                                                           |
| `onUriChange`        | `(uri: string \| null) => void` | —           | 当前资源变化后触发；清除选中时传入 `null`。                                                                                                                                                                  |
| `rootUri`            | `string`                        | `viking://` | 目录树的根，宿主据此把浏览范围收敛到某个子树。                                                                                                                                                               |
| `defaultExpandedUri` | `string`                        | —           | 首次加载后自动展开到的路径，逐级展开并加载。省略时只展开根，其余折叠。                                                                                                                                       |
| `locale`             | `'en-US' \| 'zh-CN'`            | —           | 透传给预览底座的文案语言。组件自身文案仍由 `labels` 控制。                                                                                                                                                   |
| `labels`             | `FileBrowserLabels`             | —           | 可替换文案：`searchPlaceholder`、`searchEmpty`、`loading`、`refresh`、`empty`、`error`、`retry`、`previewMode`、`sourceMode`、`history`、`copyPath`、`viewSwitch`，以及透传给树与预览的 `tree` / `preview`。 |
| `className`          | `string`                        | —           | 容器附加类名。                                                                                                                                                                                               |
| `style`              | `CSSProperties`                 | —           | 容器样式覆盖。                                                                                                                                                                                               |

文案为纯文本，宿主可将自身的翻译结果映射到这些属性。props 里没有数据字段——数据由模块自己加载。

模块通过 `useFileBrowser` 自己取数，宿主无需提供目录或预览数据；`labels.tree` 与 `labels.preview` 分别透传给文件树与文件预览组件。
