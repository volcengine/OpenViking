    details: FileBrowser and Console read the OpenViking native API inside OpenVikingProvider, so you get a file browser and a command panel out of the box.
  - title: Import what you need
    details: Run npm install @openviking/react, then import the components and styles you use. Every business component and block has its own subpath, and React 18.2 and 19 are supported.
