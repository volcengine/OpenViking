# ScopeCascade

A three-level selector for library, space and user: when a parent changes, its descendants are cleared and reloaded, and `onChange` reports the complete identity once all three levels are selected.

## When to use

- You need to pick a library, a space and a user in turn, then load business data for the selected identity.
- Your data comes from your own APIs: the component fetches through three load functions and manages requests, cascading, cancellation and retries itself. It does not call the OpenViking native API, so it has no `requestOptions` and does not need `OpenVikingProvider`; for how the other blocks send requests, see the [blocks overview](../modules/).
- You want to manage each level's data yourself, customize the panel or fix a level: use [ScopeSwitcher](../components/scope-switcher) instead.

## Import

```tsx
import { ScopeCascade } from '@openviking/react/modules/scope-cascade';
import '@openviking/react/modules/scope-cascade/style.css';
```

## API

### ScopeCascade

| Property         | Description                                                                                                                                                                    | Type                                                                                                   | Default                                                                            |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------- |
| loadLibraries    | Loads the library list, called on mount; `signal` aborts when the request becomes stale                                                                                        | `(signal: AbortSignal) => Promise<readonly ScopeSwitcherOption[]>`                                     | Required                                                                           |
| loadSpaces       | Loads the spaces of a library, called after a library is selected                                                                                                              | `(libraryId: string, signal: AbortSignal) => Promise<readonly ScopeSwitcherOption[]>`                  | Required                                                                           |
| loadUsers        | Loads the users of a space, called after a space is selected                                                                                                                   | `(libraryId: string, spaceId: string, signal: AbortSignal) => Promise<readonly ScopeSwitcherOption[]>` | Required                                                                           |
| levelNames       | Names of the three levels: library, space, user. Shown on a trigger that has no selection, and used as the trigger's accessible name                                           | `readonly [string, string, string]`                                                                    | `en-US`: `['Library', 'Space', 'User']`; `zh-CN`: `['知识库', '数据空间', '用户']` |
| onChange         | Called when the selection changes: a `ScopeCascadeSelection` when all three levels are selected, `null` while the identity is incomplete; never repeated for the same identity | `(selection: ScopeCascadeSelection \| null) => void`                                                   | -                                                                                  |
| retryLabel       | Text of the retry button shown after a load failure                                                                                                                            | `string`                                                                                               | `en-US`: `'Retry'`; `zh-CN`: `'重试'`                                              |
| slots            | Replaces rendering-error content; see [error display slots](../guide/getting-started#custom-error-display)                                                                     | `{ errorFallback?: ReactNode \| ((reset: () => void) => ReactNode) }`                                  | -                                                                                  |
| labels           | Overrides interface text: `loading`, `searchPlaceholder`, `empty`, `noMatch` (no search results) and `error` (load failure)                                                    | `ScopeSwitcherLabels`                                                                                  | -                                                                                  |
| locale           | Interface language, see [Internationalization](../guide/i18n)                                                                                                                  | `'zh-CN' \| 'en-US'`                                                                                   | Inherited, otherwise `'en-US'`                                                     |
| className, style | Appearance and layout; other HTML attributes are passed to the root element                                                                                                    | HTML attributes                                                                                        | -                                                                                  |

### ScopeSwitcherOption

An option returned by the load functions.

| Property    | Description                                                                                                                                         | Type        | Default  |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- | -------- |
| id          | Unique identifier of the option; a parent's `id` is passed to the next level's loader, and the three `id`s form the identity returned by `onChange` | `string`    | Required |
| label       | Display text; search filters by it and highlights the matching part                                                                                 | `string`    | Required |
| icon        | Icon at the start of the option row; the level's default icon is used when omitted                                                                  | `ReactNode` | -        |
| description | Secondary text below the label                                                                                                                      | `string`    | -        |
| disabled    | Disables the option: it is dimmed, cannot be clicked and is never selected automatically                                                            | `boolean`   | `false`  |

### ScopeCascadeSelection

| Property  | Description                | Type     | Default  |
| --------- | -------------------------- | -------- | -------- |
| libraryId | Id of the selected library | `string` | Required |
| spaceId   | Id of the selected space   | `string` | Required |
| userId    | Id of the selected user    | `string` | Required |

## Notes

- Keep the load functions referentially stable, for example by defining them outside the component or wrapping them in `useCallback`. A new reference for any of them cancels in-flight requests, clears every selection and reloads from the library level.
- When the account changes, set `key={accountId}` on the component so the selection state resets with it.
- After mounting, libraries load first; each level selects its first enabled option and then loads the next level. A level stays disabled until its parent has a selection, and when a level has no options the levels below stay disabled and `onChange` receives `null`.
- When a parent changes, its descendants are cleared before they reload. A late response is discarded even if your load function ignores `signal`.
- When a level fails to load, only that level shows the error and a retry button, the levels below stay disabled, and retrying reloads just that level.
- Each level loads its complete list in one call; server-side search and pagination are not supported. With more than 10 options, a search box filters them locally by label.
- An option without `icon` gets the level's default icon: [LibraryIcon](../components/icons) (a round gradient swatch picked by `id`) for libraries, and `SpaceIcon` and `UserIcon` for spaces and users. An `icon` returned by your load function is used as is.
- Types are exported from `@openviking/react/modules/scope-cascade`: `ScopeCascadeProps`, `ScopeCascadeSelection` and `ScopeCascadeApi` (the three load functions together). `ScopeSwitcherOption` and `ScopeSwitcherLabels` come from `@openviking/react/components/scope-switcher`. The package root exports only the component and `ScopeCascadeProps`.
