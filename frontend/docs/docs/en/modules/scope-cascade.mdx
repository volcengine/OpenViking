# ScopeCascade

Optional `locale: 'zh-CN' | 'en-US'` overrides the nearest module or Provider; without either, copy defaults to `en-US`. Existing `labels` override individual fields. Hosts provide business content.

Pass three API adapters directly to `ScopeCascade`. Requests, cascading, cancellation, retries and per-level subscriptions are internal; hosts do not create a controller or call Hooks.

## Basic usage

```tsx file="../../_demos/scope-cascade-basic.tsx" preview

```

The adapters return `Promise<readonly ScopeSwitcherOption[]>`, with `{ id, label, icon?, description?, disabled? }` options. Adapters own authentication, addresses and response mapping. Keep function references stable: changing an adapter cancels requests and resets all selections. Use a component `key` to isolate accounts.

| Adapter         | Parameters                                                |
| --------------- | --------------------------------------------------------- |
| `loadLibraries` | `signal: AbortSignal`                                     |
| `loadSpaces`    | `libraryId: string, signal: AbortSignal`                  |
| `loadUsers`     | `libraryId: string, spaceId: string, signal: AbortSignal` |

Mounting loads libraries. Each level selects the first enabled option and continues to the next level. Parent changes clear descendants before notification; stale responses are ignored even when an adapter ignores its signal. Internal leaf subscriptions stay independent. Each level handles local search, loading, empty, error and retry states. The current version loads complete lists without server search or pagination.

## Selection changes

```tsx file="../../_demos/scope-cascade-selection.tsx" preview

```

`onChange(selection)` reports a complete `{ libraryId, spaceId, userId }` identity. It reports `null` while initialization, parent changes or adapter resets leave the identity incomplete. Refreshing the same identity does not repeat the callback. Load scoped business data when the value is non-null, without subscribing to internal state.

## Props

The three `load*` adapters are required. `onChange` is optional. `levelNames` names library, space and user in order; `labels` customizes loading, search, empty and error copy, and `retryLabel` names retry buttons. Standard HTML attributes such as `className` and `style` reach the layout container. Import `@openviking/react/modules/scope-cascade/style.css` for default styling.
