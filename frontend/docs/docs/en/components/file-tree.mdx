# FileTree

A flattened file tree. The host owns the tree state and passes the visible rows in order; the component renders them and reports intent.

This is a placeholder implementation: it renders every documented row type and honours the public props, so consumers can integrate against the API before the full view lands. Styling, iconography and interaction details will change.

## Basic usage

Expand a directory to reveal its children. Rows come from `rows`; selection and expansion are controlled by the consumer.

## How rows work

The tree never inspects parent/child relationships. The host flattens its own state into an ordered list:

- `entry` — a directory or file.
- `loading` — a children area that is still loading.
- `load-more` — a children page the host can fetch next.
- `error` — a children area that failed.
- `empty` — an expanded directory with no children.

Emit only the ones your data source needs. A host that returns all children at once never emits `load-more`.

## Slots and host content

- `slots.toolbar` — search, import sources, refresh. The component does not know what is inside.
- `renderDashboard` — the row-end indicator, for example a dashboard entry.
- `renderRowTooltip` — hover content; the component handles the delay and positioning.

## One-off effects

Highlighting is a page-level effect, not a tree prop. Three options are available and can be combined:

1. `data-file-tree-row-id` on every row element, exported as `FILE_TREE_ROW_ATTRIBUTE`.
2. `getRowAttributes(row)` for per-row classes and attributes.
3. The `ref` handle: `getRowElement(id)` and `scrollToRow(id, options)`.

```tsx
const treeRef = useRef<FileTreeHandle>(null);
treeRef.current?.scrollToRow('resources', { block: 'center' });
```

## Props

| Property                  | Type                                      | Default  | Description                                                   |
| ------------------------- | ----------------------------------------- | -------- | ------------------------------------------------------------- |
| `rows`                    | `readonly FileTreeRow[]`                  | Required | Visible rows in render order.                                 |
| `selectedId`              | `string \| null`                          | —        | Selected row id, owned by the host.                           |
| `isReady`                 | `boolean`                                 | `true`   | Whether the first load finished.                              |
| `loadingFallback`         | `ReactNode`                               | —        | Shown instead of rows while the first load runs.              |
| `errorFallback`           | `ReactNode`                               | —        | Shown when a whole-tree error row is present.                 |
| `emptyFallback`           | `ReactNode`                               | —        | Shown when `rows` is empty.                                   |
| `slots`                   | `FileTreeSlots`                           | —        | `toolbar` slot above the rows.                                |
| `labels`                  | `FileTreeLabels`                          | English  | Replaceable copy.                                             |
| `getRowAttributes`        | `(row) => HTMLAttributes<HTMLDivElement>` | —        | Extra attributes per row; `className` is merged.              |
| `renderDashboard`         | `(row) => ReactNode`                      | —        | Row-end indicator; `null` hides it.                           |
| `renderRowTooltip`        | `(row) => ReactNode`                      | —        | Hover content; `null` hides it.                               |
| `onSelect`                | `(row: FileTreeEntryRow) => void`         | —        | Selection intent; directories and files share this callback.  |
| `onToggleExpand`          | `(row: FileTreeEntryRow) => void`         | —        | Expand or collapse intent.                                    |
| `onLoadMore`              | `(row: FileTreeLoadMoreRow) => void`      | —        | Load the next page of children.                               |
| `onRetry`                 | `(row: FileTreeErrorRow) => void`         | —        | Retry a failed children load.                                 |
| `onOpenRetentionSettings` | `(uri: string) => void`                   | —        | Retention settings entry, offered when a row has `expiresAt`. |
| Other props               | `HTMLAttributes<HTMLDivElement>`          | —        | Standard div attributes.                                      |

## Accessibility

The tree uses `role="tree"` with `role="treeitem"` rows and reports `aria-level`, `aria-selected` and `aria-expanded`. Arrow keys move between rows, Right/Left expand and collapse, Enter and Space select. Status is carried by visible text, not colour alone.

## Implementation scope

The component renders what the host passes and reports intent. Directory loading, pagination, search, permissions and navigation belong to the host.
