# Icons

The icons built into the library: arrow, file-type, scope-level and dashboard icons as React components that render inline SVG, plus functions that pick a file-type icon from a file name.

## When to use

- You want icons that match the library's own UI, for example for the options of [ScopeSwitcher](./scope-switcher) or the rows of [FileTree](./file-tree).
- You want the icon for a file's type from its name: use `getFileTypeIcon`.

## Import

```tsx
import { PdfIcon, getFileTypeIcon } from '@openviking/react/icons';
```

Icons are bundled into the JavaScript as inline SVG: there is no separate asset request and no stylesheet to import.

## API

### Common icon props

The icon components in the list (except `LibraryIcon`) render an inline `svg` and accept `IconProps`.

| Property         | Description                                                                                                                         | Type                      | Default                                |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------- | -------------------------------------- |
| width            | Icon width                                                                                                                          | `number \| string`        | The icon's own size, see the icon list |
| height           | Icon height                                                                                                                         | `number \| string`        | The icon's own size, see the icon list |
| aria-label       | Accessible name; without it the SVG gets `aria-hidden` and counts as decoration, with it the icon stays in the accessibility tree   | `string`                  | -                                      |
| className, style | Class name and inline style for the SVG element; use `color` to recolor icons that follow the text color                            | `string`, `CSSProperties` | -                                      |
| Other props      | Standard SVG attributes, including `aria-*` and `role`; `children` is not accepted. An explicit `aria-hidden` overrides the default | SVG attributes            | -                                      |

### LibraryIcon

A round gradient swatch fixed at 14 × 14. It renders a `span`, accepts no SVG props and stays out of the accessibility tree.

| Property | Description                                                                                             | Type     | Default |
| -------- | ------------------------------------------------------------------------------------------------------- | -------- | ------- |
| name     | Picks one of the five gradients, always the same one for the same name; the first gradient when omitted | `string` | `''`    |

### VikingBotIcon

Icons for conversations, picked with `name`. Other props work like the common icon props.

| Property      | Description                                                                                                                     | Type                                                                                                                              | Default  |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | -------- |
| name          | Icon name: light bulb, book, video, report, history, new session, remove, tool, context folder and close context, in that order | `'bulb' \| 'book' \| 'video' \| 'report' \| 'history' \| 'newSession' \| 'remove' \| 'tool' \| 'contextFolder' \| 'contextClose'` | Required |
| width, height | Icon size                                                                                                                       | `number \| string`                                                                                                                | `16`     |

### File-type icon functions

| Function                 | Description                                                                                                                           | Type                                                  |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| `getFileTypeIcon`        | Returns the icon component for a file name, or the generic file icon when nothing matches                                             | `(name: string) => FileTypeIconComponent`             |
| `resolveFileTypeIconKey` | Returns the icon key for a file name, or `'default'` when nothing matches                                                             | `(name: string) => string`                            |
| `getFileTypeColor`       | Returns the brand color of an icon key; `scheme` defaults to `'light'`, and a key without a registered color returns `'currentColor'` | `(key: string, scheme?: 'light' \| 'dark') => string` |

`name` can be a file name or a path; only the last segment counts, and case is ignored. A full file name is matched first, then extensions from longest to shortest (`tar.gz` before `gz`), and the generic file icon is used when none matches.

The returned file-type icons use `currentColor`, except the PDF, PPT, Word, audio and video icons, which have fixed colors. Set `color` from `getFileTypeColor` to apply the brand color:

```tsx
import {
  getFileTypeColor,
  getFileTypeIcon,
  resolveFileTypeIconKey,
} from '@openviking/react/icons';

function FileTypeIcon({ name }: { name: string }) {
  const Icon = getFileTypeIcon(name);
  return (
    <Icon
      aria-hidden="true"
      width={16}
      height={16}
      style={{ color: getFileTypeColor(resolveFileTypeIconKey(name)) }}
    />
  );
}
```

## Theme variables

`LibraryIcon` has five gradients, shared by the light and dark themes. Override them one by one with `--ov-ui-color-library-swatch-1` to `--ov-ui-color-library-swatch-5`; without the library stylesheet, the component uses the same built-in gradients.

```css
:root {
  --ov-ui-color-library-swatch-1: linear-gradient(145deg, #e0f7fa, #80deea);
}
```

## Notes

- The icons in the list get `aria-hidden` by default and count as decoration. When an icon conveys information on its own, pass an `aria-label` in your app's language; omit it when the adjacent text already says what the icon means, so it is not announced twice.
- When you use a component returned by `getFileTypeIcon` as decoration, pass `aria-hidden` explicitly.
- Icons have no interactive behavior: when you put one inside a button, your app provides the button semantics, keyboard interaction and focus styles.
- The types `IconProps`, `IconComponent`, `FileTypeIconComponent` and `VikingBotIconName` are exported from `@openviking/react/icons` as well; the package root does not export icons.
