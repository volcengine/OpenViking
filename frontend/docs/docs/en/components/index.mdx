# Components

Reusable React UI modules for OpenViking applications. Each component includes
usage guidance, interactive examples, and API details. Components include both
basic controls and composed views: they receive prepared data and state through
props and report user intent through callbacks. Data fetching and business data
processing belong to the upper layer.

## Available components

### [Icons](./icons)

Five file-type icons with configurable image dimensions and accessible labels.

### [StatusBadge](./status-badge)

A scaffold example displaying a resource or operation state with a text label and color indicator.

### [FileTree](./file-tree)

A flattened file tree. The host supplies ordered rows; the component renders them and reports selection, expansion and pagination intent.

### [FilePreview](./file-preview)

A tabbed file preview. Each tab either hands a file source to the component or renders a host-owned node; the component owns the tab row, header row and view switching.

## Reserved modules

`tui`, `viking-bot`, `scope-switcher`, `agent-connect`, and `resource-import` publish their props types from their JS subpaths; component implementations and styles are still to be migrated. The same props serve every host; hosts differ in flow and data access but share the interaction and UI. See [Getting started](../guide/getting-started) for entry and stylesheet choices.
