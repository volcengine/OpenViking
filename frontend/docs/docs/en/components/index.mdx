# Components

Reusable views and file-type icons for OpenViking AI applications. Components receive prepared data and state through props and report user intent through callbacks. Applications own data fetching, authentication, and business workflows.

## Available modules

### [FileBrowserEntries](./file-browser-entries)

The entry row at the top of the file browsing area: connect an agent, import resources. Fixed to two entries; the host decides which appear and what a click does, while the icons, copy and divider belong to the component.

### [FileTree](./file-tree)

A flattened file tree with row rendering, selection, expansion, keyboard interaction, and pagination intent. The host supplies ordered rows and handles data loading. The current view is a placeholder; see the component page for its scope and limitations.

### [DirectoryTour](./directory-tour)

A six-step anchor walkthrough with async location, independent highlights, viewport collision handling, retry and skip. The host owns directory loading and completion state.

### [FilePreview](./file-preview)

A tabbed file-preview view with header actions, tab switching, and plain-text preview and editing foundations. The current view is a placeholder: the file body is not wired to FileViewer yet and falls back to plain text. Applications provide content and save behavior.

### [Tui](./tui)

Command records, results and input with completion, parameter hints and grouped command help, driven by bundled CLI metadata.

### [ScopeSwitcher](./scope-switcher)

A stateless header breadcrumb containing independent ScopeSelector views. Each host level owns its data, search and requests; only selected identities participate in cascading updates.

### [AgentConnect](./agent-connect)

A Figma connection view with mainstream agents and MCP, CLI, API and SDK developer methods, bilingual details and original icons. Hosts provide credentials and locale; selection can be local or controlled, with clipboard feedback.

### [VikingBot](./viking-bot)

The conversation view: message list, composer and pending-interaction area. Renders a working view against the normalized message model; the view is a placeholder pending design review.

### [Icons](./icons)

Five file-type icons with configurable image dimensions and accessible labels: audio, PDF, presentation, video, and word-processing files.

See [Getting started](../guide/getting-started) for public package entries, stylesheet choices, and application integration boundaries.

### [WikiDashboard](./wiki-dashboard)

Wiki generation, conflicts and resolution history with supplied loading states and retry callbacks.

### [ExperienceDashboard](./experience-dashboard)

Agent experience lists, effects and sources with supplied display data and state.

### [Authentication forms](./auth-forms)

Authentication views without requests, routing, storage or page layout. English labels can be replaced through props.
