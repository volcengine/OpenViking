# CommandConsole

A terminal-style view of command records and their results, with an input area that provides command suggestions and parameter help.

## When to use

- You want a command-line style input and result view, with your own commands and execution. The component sends no requests, does not use local storage and does not need `OpenVikingProvider`.
- You need one view for different kinds of command output, such as text, search results, resource previews, status and write results.
- When you use [Console](../modules/console), its command mode already includes CommandConsole, so you do not need to add it yourself.

## Import

```tsx
import { CommandConsole } from '@openviking/react/components/command-console';
import '@openviking/react/components/command-console/style.css';
```

## Examples

### Basic usage

Shows command records with several result types and an input area with completion. Type `/` to see suggestions, then submit `ov compile --compile-name demo-wiki`, `ov task list`, `ov session get session_demo` or `ov help` to get a write result, a table, a status card and command help.

```tsx file="../../_demos/command-console-basic.tsx" preview

```

The example uses fixed simulated data: submitting appends a pending record that is replaced by the result a moment later, and no request is sent. Clicking a resource link only shows an alert.

### Empty state and quick commands

Quick commands appear while there are no records. Clicking one only fills the input; press Enter to submit, and the first submission replaces the empty state with records.

```tsx file="../../_demos/command-console-empty.tsx" preview

```

Every quick command in the example fills a complete command except `compile`, which fills only `ov compile `, so you still need to add `--compile-name <name>`.

## API

### CommandConsole

| Property         | Description                                                                                                                                                      | Type                                         | Default                        |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- | ------------------------------ |
| records          | Command records to display, in submission order                                                                                                                  | `readonly CommandConsoleRecord[]`            | Required                       |
| value            | Text in the input area (controlled)                                                                                                                              | `string`                                     | Required                       |
| disabled         | Disables input and submission, and shows `labels.unavailableMessage` below the input area                                                                        | `boolean`                                    | `false`                        |
| emptyState       | Content shown when there are no records; replaces the built-in empty state, and `null` shows no empty state                                                      | `ReactNode`                                  | -                              |
| quickCommands    | Shortcuts in the built-in empty state; the empty state shows nothing when none of them resolves to a command                                                     | `readonly CommandConsoleQuickCommand[]`      | -                              |
| commands         | Command catalogue used for suggestions, parameter help and pending skeletons; without it you can still type and submit, but get no suggestions or parameter help | `readonly CommandConsoleCommandDefinition[]` | `[]`                           |
| commandGroups    | Group names and order in the suggestion list; undeclared groups follow in order of appearance                                                                    | `readonly CommandConsoleCommandGroup[]`      | `[]`                           |
| onValueChange    | Called when the input changes, including accepted suggestions and examples; the input is read-only when omitted                                                  | `(value: string) => void`                    | -                              |
| onSubmit         | Called on Enter with the trimmed command text; submission is disabled when omitted                                                                               | `(command: string) => void`                  | -                              |
| onOpenUri        | Called when a resource link is clicked, with the link target; links navigate natively through `href` when omitted                                                | `(uri: string) => void`                      | -                              |
| onCopy           | Called after a successful copy, with the copied text                                                                                                             | `(text: string) => void`                     | -                              |
| labels           | Overrides interface text, see [CommandConsoleLabels](#commandconsolelabels)                                                                                      | `CommandConsoleLabels`                       | -                              |
| locale           | Interface language, see [Internationalization](../guide/i18n)                                                                                                    | `'zh-CN' \| 'en-US'`                         | Inherited, otherwise `'en-US'` |
| className, style | Appearance and layout; other HTML attributes are passed to the root element                                                                                      | HTML attributes                              | -                              |

### CommandConsoleRecord

| Property    | Description                                                                                                                                      | Type                                               | Default  |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------- | -------- |
| id          | Unique identifier of the record                                                                                                                  | `string`                                           | Required |
| command     | Submitted command text, shown above the result; when it matches a command in `commands`, the command name is shown as that command's `inputText` | `string`                                           | Required |
| status      | State of this record; pending submissions show a skeleton, while background tasks can retain their submission result                             | `'pending' \| 'success' \| 'error' \| 'cancelled'` | Required |
| tasks       | Background task snapshots supplied by the host                                                                                                   | `readonly CommandConsoleTask[]`                    | -        |
| content     | Execution result; records with background tasks can show it while pending, otherwise pending records show a skeleton                             | `CommandConsoleRecordContent`                      | -        |
| createdAtMs | Submission time as a Unix timestamp in milliseconds, shown below the command                                                                     | `number`                                           | -        |
| createdAt   | Text shown when there is no valid `createdAtMs`, also used for server rendering; it is never parsed as a date                                    | `string`                                           | -        |

`CommandConsoleTask` uses the [ConsoleTaskSnapshot](../modules/console#consoletasksnapshot) fields.

### CommandConsoleRecordContent

The union of execution results, distinguished by `variant`.

| variant              | Description                                                          | Type                                   |
| -------------------- | -------------------------------------------------------------------- | -------------------------------------- |
| `'text'`             | Plain text or Markdown; also used for JSON and error messages        | `CommandConsoleTextContent`            |
| `'search-list'`      | A list of search results                                             | `CommandConsoleSearchListContent`      |
| `'resource-preview'` | A body preview of one resource                                       | `CommandConsoleResourcePreviewContent` |
| `'resource-tree'`    | A list of resource entries, shown as a table when they carry details | `CommandConsoleResourceTreeContent`    |
| `'status'`           | Key/value status rows                                                | `CommandConsoleStatusContent`          |
| `'write-result'`     | Result lines of a write command                                      | `CommandConsoleWriteResultContent`     |
| `'command-help'`     | Available commands listed in groups                                  | `CommandConsoleCommandHelpContent`     |

## Notes

- `onSubmit` only reports the command text and your app runs it: add a record with `status: 'pending'`, then update it to `'success'` or `'error'`. A pending record does not block further submissions; set `disabled` if you need that.
- Report a failure with `status: 'error'` and put the message in a `text` result. The component does not parse command output, so convert the response into a `CommandConsoleRecordContent` yourself.
- `'success'` only means the command itself succeeded; a task it started may still be running.
- Session creation, history panels and toolbars are yours to compose around the component, which has no slots for them. After you switch sessions or history, update `records` and `value`.
- Enter submits and Shift+Enter inserts a newline; the component has no send button.
- ↑ and ↓ recall commands from `records`, or move through the suggestions while the list is open. Tab stays in the input, and Shift+Tab moves focus out.
- As you type a command name, the rest is hinted in gray and Tab accepts it; the hint never enters `value` or the submitted text. Type `/`, or press Tab after the command prefix, to open the suggestion list, where ↑ and ↓ select, Tab or Enter fill in and Esc closes.
- Hovering or selecting a suggestion shows its usage, examples and parameter table beside the list. Once you accept a command, positional parameters are hinted in light text after the command name until you start typing arguments.
- Records follow new output only while the reader is near the bottom. Scrolling up keeps the reading position, and submitting a command resumes following.
- The root element is `height: 100%`: the record area scrolls and the input stays at the bottom, so give the parent a definite height.
- `viking://`, `http://` and `https://` addresses in the input, records and results become links, and clicking one never submits the command. `onOpenUri` receives the address.
- Links in descriptive text exclude trailing sentence punctuation, while links in commands, code blocks and resource values keep punctuation that belongs to file names. Structured `uri` fields accept only the three schemes above and show anything else as plain text.
- In Markdown text, `http(s)` links and addresses open in a new tab and do not call `onOpenUri`; `viking://` ones do.
- JSON and Markdown code blocks have a copy button, and a successful copy calls `onCopy`. If the browser refuses the clipboard write, no success feedback is shown and `onCopy` is not called.
- `createdAtMs` shows "Just now" under one minute, whole minutes under one hour, whole hours under 24 hours, then the local `YYYY-MM-DD HH:mm`; a future timestamp shows "Just now". Override the text with `labels.justNow`, `labels.formatMinutesAgo` and `labels.formatHoursAgo`.
- Server rendering and the hydration pass use `createdAt` and show no time without it; the client switches to `createdAtMs` afterwards. The time is recalculated when the component renders and does not refresh on a timer.
- Colors come from the `--ov-ui-color-*` theme variables, and dark mode follows the `.dark` class on `<html>`; see [Getting started](../guide/getting-started).
- Types are exported from `@openviking/react/components/command-console`; the package root exports only the component and `CommandConsoleProps`.
