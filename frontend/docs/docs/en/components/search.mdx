# Search

Search entry, retrieval mode switching and advanced filters. The host declares the modes and filters and owns requests, ranking and pagination; the component renders and reports intent.

This is a placeholder component: it renders a fixed-size empty shell and consumes no props, so hosts can integrate against the published package before the view is migrated. The props contract will be published from the same subpath.

## Basic usage

```tsx file="../../_demos/search-basic.tsx" preview

```

The placeholder is 960 × 640, matching the full-page view.

## Implementation scope

The component renders the view and reports intent. Data access, persistence, permissions and any network connection belong to the host.
