# WikiDashboard

Shows the conflicts in a Wiki directory or file: the directory view lists the files that have conflicts, and the file view lists each conflict with its details and resolution history.

## When to use

- You need a conflict overview while browsing files, with a way to jump to a file or a conflict.
- You want to decide the data source, row actions and page layout yourself. The component only renders: it sends no requests and does not need `OpenVikingProvider`.
- When you use [FileBrowser](../modules/file-browser), the dashboard is built in and needs no separate setup.

## Import

```tsx
import { WikiDashboard } from '@openviking/react/components/wiki-dashboard';
import '@openviking/react/components/wiki-dashboard/style.css';
```

## Examples

### Basic usage

Switch between the directory, file and no-conflict samples. Click a conflict title to expand its reason, times, fix plan and basis; the severity filter supports arrow keys, Home/End and Escape.

## API

### WikiDashboard

| Property         | Description                                                                                                      | Type                                                                                                                               | Default                        |
| ---------------- | ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ |
| kind             | View mode, known even while data is loading                                                                      | `'directory' \| 'file'`                                                                                                            | Required                       |
| data             | Display data matching `kind`; loading or error states are shown when omitted                                     | `WikiDirectoryData` (directory), `WikiFileData` (file)                                                                             | -                              |
| loading          | Shows the loading state when the list is empty                                                                   | `boolean`                                                                                                                          | `false`                        |
| error            | Shows the error state when the list is empty                                                                     | `Error \| null`                                                                                                                    | -                              |
| onRetry          | Called when Retry is clicked; the component sends no requests itself                                             | `() => void`                                                                                                                       | -                              |
| onOpenUri        | Directory view: called when a file is clicked, with its URI. File view: called when the path is clicked          | `(uri: string) => void` (directory), `() => void` (file)                                                                           | -                              |
| onOpenDashboard  | Directory view: called to open that file's dashboard; falls back to `onOpenUri` when omitted                     | `(uri: string) => void`                                                                                                            | -                              |
| defineActions    | Defines the action buttons of each row; the action area is hidden when omitted or when it returns an empty array | `(uri: string) => readonly WikiDashboardAction[]` (directory), `(conflict: WikiConflict) => readonly WikiDashboardAction[]` (file) | -                              |
| slots            | Replaces rendering-error content; see [error display slots](../guide/getting-started#custom-error-display)       | `{ errorFallback?: ReactNode \| ((reset: () => void) => ReactNode) }`                                                              | -                              |
| labels           | Overrides interface text                                                                                         | `Partial<WikiDashboardLabels>`                                                                                                     | -                              |
| locale           | Interface language, see [Internationalization](../guide/i18n)                                                    | `'zh-CN' \| 'en-US'`                                                                                                               | Inherited, otherwise `'en-US'` |
| className, style | Appearance and layout; other HTML attributes are passed to the root element                                      | HTML attributes                                                                                                                    | -                              |

| Property          | Description                                                                             | Type                | Default  |

| conflictFileCount | Number of conflicting files                                                             | `number`            | -        |

## Notes

- The component has no default actions. `defineActions` runs during rendering: derive the configuration from the current row only, without making requests or updating state. It may return different actions depending on the conflict state.
- There is no top-level `uri` prop. Capture the URIs you need for requests and navigation in the closures of `onOpenUri` and `defineActions`.
- To reset the filter and expanded details when the document changes, set `key={documentId}` on the component in the parent.
- Types are exported from `@openviking/react/components/wiki-dashboard`; the package root exports only the component and `WikiDashboardProps`.
