# Analytics

Receive interaction, outcome, and exposure events through `OpenVikingProvider.analytics`, and forward them to your analytics platform.

## Integration

Omitting `analytics` at the root disables collection: no analytics events, exposure observers, or operation timers are created. Supply `onEvent` to enable collection. Business components and blocks need no additional analytics props.

```tsx
import { OpenVikingProvider } from '@openviking/react/client';
import type { OpenVikingAnalyticsOptions } from '@openviking/react/client';

const analytics = {
  onEvent(event) {
    // Call your SDK here and add page, source, and user context.
    hostAnalytics.track(event.name, {
      ...event.params,
      instanceId: event.instanceId,
    });
  },
} satisfies OpenVikingAnalyticsOptions;

<OpenVikingProvider analytics={analytics}>{children}</OpenVikingProvider>;
```

The host supplies `hostAnalytics` and `children`. The library includes no analytics SDK and sends no requests to an analytics platform.

### Select events

Omit `events` to receive all built-in events, or pass `[]` to receive none. Event names are type checked. Checking `event.name` narrows `event.params` to that event's parameter type.

```tsx
const analytics = {
  events: [
    'openviking_file_preview_copy_path_click',
    'openviking_file_browser_search_success',
  ],
  onEvent(event) {
    if (event.name === 'openviking_file_browser_search_success') {
      console.log(event.params.result_count, event.params.duration_ms);
    }
  },
} satisfies OpenVikingAnalyticsOptions;
```

### Provider scope

A nested Provider inherits analytics when the prop is omitted. Pass `false` to disable its subtree, or an options object to replace the outer configuration. A collection point delivers only to its nearest effective configuration, without also notifying the outer receiver. Configuration changes do not reload business data or replay interactions that happened while collection was disabled.

`onEvent` may return `Promise<void>`. Delivery does not block business operations. Synchronous exceptions and rejected promises are isolated; the library does not retry or buffer events. Implement retries, sampling, or batching in your host adapter.

## Event semantics

- Names follow `openviking_<target>_<event>`. Copying a path, file content, connection instructions, and a code block each have distinct events.
- A business component's submit or click expresses user intent. The block or internal executor reports actual outcomes. When the host takes over execution, the library does not infer its business result.
- `console_command_accepted` means asynchronous tasks were accepted. `console_command_success` follows only after all associated tasks succeed. A task polling failure does not imply execution failure.
- `file_preview_download_start` means the browser download was initiated; it does not confirm that a file was saved locally.
- A `file_preview_save_success` event with `version_status: 'not-created'` means the content was saved but a version was not created. `'unknown'` means the save interface did not confirm version creation.
- Cancellation is distinct from failure. Unmounting or changing scope invalidates old requests without emitting stale success or failure events.

### Exposure

`*_show` and `directory_tour_start` fire when the target intersects the viewport with a positive width and height while the document is visible. Hidden elements, loading content placeholders, and background preview layers do not count. Each target reports once per display cycle. Rerenders, scrolling out and back in, or returning to the tab do not repeat an exposure. Reopening a dialog, advancing a tour step, or switching preview targets begins a new cycle.

Exposure uses `IntersectionObserver` and does not detect occlusion by other elements. Environments without this API skip automatic exposure. Server rendering emits no events. Re-enabling analytics does not replay previous interactions; a currently visible target that has never reported may emit its first exposure.

### Common fields and collected data

| Field        | Description                                                                       | Type                                       |
| ------------ | --------------------------------------------------------------------------------- | ------------------------------------------ |
| `name`       | Fixed event name that narrows `params`                                            | `OpenVikingAnalyticsEventName`             |
| `params`     | Parameters for that event, or `{}` for events without parameters                  | `OpenVikingAnalyticsEventMap[typeof name]` |
| `instanceId` | Collection-point instance identifier; not a user, account, or resource identifier | `string`                                   |

`operation_id` connects submission and outcome for one operation. `duration_ms` measures milliseconds from its start to the current stage. `step_index` starts at zero. `error_kind` is a fixed classification and never contains an error message.

Built-in events omit full URIs, paths, file names, queries, command text, message and file content, email addresses, passwords, and API keys. Add page, source, user identity, and platform-specific fields in your host's `onEvent` adapter.

## API

Import these types from `@openviking/react/client`.

### OpenVikingAnalyticsOptions

| Property  | Description                                                                   | Type                                                         | Default             |
| --------- | ----------------------------------------------------------------------------- | ------------------------------------------------------------ | ------------------- |
| `onEvent` | Receives selected events; receiver failures do not affect business operations | `(event: OpenVikingAnalyticsEvent) => void \| Promise<void>` | Required            |
| `events`  | Selects the built-in events to receive                                        | `readonly OpenVikingAnalyticsEventName[]`                    | All built-in events |

`OpenVikingProviderProps.analytics` accepts `OpenVikingAnalyticsOptions | false`; collection is disabled at the root by default. `OpenVikingAnalyticsEventMap` maps each name to its parameters. `OpenVikingAnalyticsEvent` is a union discriminated by `name`.
