# Monitoring event catalogue

Each event identifies one target and one outcome. See [frontend monitoring](./monitoring) for integration, switches, component attribution and tracing. Field groups describe `params`; derive public types with `OpenVikingMonitoringEventMap[EventName]['params']`.

| `client_request_fail`    | `ComponentName`  | `Owned region` | `RequestFault` | The attempt fails during configuration, transport, body consumption or existing business-envelope checks, including HTTP 200 error envelopes. Exclude aborts; do not newly reject legitimate non-JSON responses. |

## params field groups

`Ready` contains `durationMs` in milliseconds and `visibility`. `Fault` contains `errorKind`, its matching `code`, `observedAt`, `incidentId`, `faultRole`, `causeEventId`, `elapsedMs` and `traceSnapshot`. See [frontend monitoring](./monitoring) for shared fields.
