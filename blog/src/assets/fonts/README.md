# Blog typography

Shared OFL fonts live in `reading/`; see its README, source manifest, and licenses.
Vite bundles these local files with hashed URLs. Prose uses Source Sans 3 and
WenKai Screen, headings Source Serif 4 and WenKai Screen, code Maple Mono NF CN.
The former proprietary Chinese font files and their external CDN fallbacks have
been removed from the current source and builds. Historical Git commits are
unchanged.
