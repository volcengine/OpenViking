# Compile 输出校验与容量恢复

## 需求、证据和归属

用户要求将 PPT 流水线中发现的其他问题独立修复，与图片压缩改动分开提交；完整测试因磁盘空间不足停止。客户侧模型 429 配额问题明确排除。以下技术选择、实现与测试由 AI 完成，维护者评审未完成，不将其归为用户已经指定的方案。

已有证据来自标准解析入口后的 15 份各 101 页合成 PPT，使用真实火山 DeepSeek。所有材料完成解析，真实 Map 已处理 1,950 个来源片段。最终 Wiki 仍未完成全量验收；模型有效缓存曾在相同材料的修复验证中复用，因此这些记录不代表一次冷启动成功执行或性能基准。

## 修复边界与选择

1. **无有效提交耗尽后的重试。** required agent 没有校验通过的 emit、直接输出耗尽格式或语义修复时，原 ValueError 绕过已有作业重试。以 ModelCallError 表示模型执行失败，以 ModelOutputError 区分输出修复耗尽；复用原有四次作业预算，每次重新验证来源和范围。直接入口对 ModelOutputError 保持原来的流水线回退，不把 provider、认证或权限失败混为输出错误。来源 ID 错误详情变化不重置同类局部修复预算，Combine 提示明确列出遗漏 ID。
2. **拒绝空交付和丢失来源。** Wiki Markdown 必须有 frontmatter 后的正文；YAML 解析错误提供可修复反馈。有输入的普通文件响应必须产出文件，每份文件必须引用非空、唯一、本次赋值内的输入 ID。同步收紧 emit schema，并重新校验缓存。EntryResponse 的流水线请求与增量无变更语义保留，无输入模板不强制补造来源。
3. **准确定位规划错误。** 模型把已知契约字段放在 contract 外时，先反馈精确路径，再由原有模型修复完成；不自动搬字段或伪造配置，无关扩展字段继续兼容。
4. **识别真实容量失败。** 只对 Ark SDK、HTTP 400、InvalidParameter 与实际上下文超限消息的组合分类为 INPUT_TOO_LARGE，使既有 Reduce 聚合路径可达。其他参数错误不变，不硬编码模型的上下文上限。
5. **保持语义分组的直接确认。** 相关关系不传递，仍要求组内每对记录存在直接确认，避免错误桥接扩散成巨组。移除固定 50 条切组，真实上下文超限交给已有容量恢复。路由允许当前请求实际展示的记录，未知 ID 明确报错；自身链接去重忽略，历史文件仍限于该记录的授权召回。保留原始路由响应用于诊断。不会按来源目录或 scope 值假定新的业务相等关系，也不能保证模型每一条语义判断正确。
6. **复用并发和减少重复输入。** 真实溢出后独立 Combine 批次原来串行，复用 merge_concurrency 调度，实际调用仍受共享 provider 槽位约束，结果按输入顺序汇总，错误因果和取消保留。文件冲突合并保留全部候选正文，只将重复的中间记录正文换为完整输入 ID、原文范围、证据行句柄；read_evidence 可按原权限按需读取，不裁剪候选页或补造内容。

## 代价、兼容性与验证

- 不增加模型、依赖、配置项或宿主机执行权限。direct 模式的 allow_compile_exec 安全开关保持不变；本轮缺少该能力的配置问题不通过开放宿主机执行权绕过。
- 重试可能增加持续无效输出的模型开销；现有四次局部修复乘四次作业预算最多 16 次，持续错误必须失败。严格校验会让旧的无来源或空产出缓存失效并重新生成。
- 两两确认可能产生更多中间组，最终通过已有同路径文件合并整合。它是控制错误关联扩散的条件，不是最终内容质量证明。对已有 2,442 条路由决策的离线重放保留全部记录且无重复；不触发模型调用，也不等同于完成全量 Wiki。
- Combine 并行可能提高短时请求量，使用原有共享并发而不提高配额；实际收益取决于端点和工作集。惰性原文访问可增加工具往返，但避免重复大正文进入每次合并。
- 定向回归覆盖缺失/外部/重复来源 ID、空文件/空正文、缓存再校验、直接入口回退、规划路径修复、错误桥接不扩散、大于 50 条的直接确认组、可见与未知路由、真实 Ark 错误链、溢出聚合并行及取消、合并候选和原始来源保留。
- 仅运行本 PR 的定向本地回归和静态检查，不再启动完整用户规模测试、镜像下载或更大的压力测试。PR 应报告实际检查结果与剩余验收缺口。

既有 HTTP 生命周期回归在本轮曾间歇性断言失败。源代码确认 submit helper 忽略 execute() 的 False 返回值，但该返回值表示需要重新入队，不能直接断言生成完成。测试驱动器现按原协议模拟 QueueFS 的重新投递，使用短的总等待期限；不修改生产任务调度行为，不放宽结果断言。这不代表已经捕获每次历史失败的具体调度分支。
