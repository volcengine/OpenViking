Codex Compaction und OpenViking Responses State

Stand: 31. Juli 2026. Dieses Manual beschreibt einen implementierten Offline-Kandidaten. Es aktiviert keine Funktion.

HOLD: Der State-Modus, der Compaction-Threshold und der globale Hook sind nicht aktiviert. Der Capability-Probe kann einen kostenpflichtigen Provider-Request auslösen und darf nur nach ausdrücklicher Genehmigung ausgeführt werden. Der User hat den Live-Test vertagt. Der Legacy-VLM-H3-Source-Unlock ist nach dem finalen Security-Review verweigert.

1. Was der Kandidat bietet

  • Aufruferverwalteten, unveränderlichen Responses-State.
  • Sync- und natives Async-Streaming mit State-Commit erst nach response.completed.
  • store=false, vollständige Output-Items, Compaction und Tool-Ausgabe genau einmal.
  • Harte Limits, TTL, Chain-Bindings und einen expliziten Capability-Probe.
  • Einen gehärteten Hook-Kandidaten im Repository, noch nicht global installiert.

2. Default-Konfiguration

Der sichere Default bleibt deaktiviert:

vlm:
  provider: openai-codex
  responses_state_enabled: false
  responses_compact_threshold: null

Ein positiver Threshold ist nur mit aktiviertem State-Modus zulässig. Der Pilot verlangt exakt ein openai-codex-Credential. OAuth darf im State-Modus nur an https://chatgpt.com/backend-api/codex gesendet werden.

3. Aufruferverwalteter State

Nach einer später genehmigten Aktivierung hält der Aufrufer den State und reicht bei Folgeturns ausschließlich das neue Delta ein:

# Beispiel nach genehmigter Aktivierung; nicht in diesem Kandidaten ausführen.
turn1 = vlm.get_completion_with_state(prompt="Start")
state = turn1.state

turn2 = vlm.get_completion_with_state(
    prompt="Nur das neue Turn-Delta",
    state=state,
    expected_generation=state.generation,
)
state = turn2.state

Ein State darf nicht geloggt, serialisiert oder zwischen Principals, Credentials oder Origins übertragen werden. Fehler, Timeout, Cancellation und Teil-Streams lassen den vorherigen State unverändert.

4. Async-Nutzung

turn = await vlm.get_completion_with_state_async(
    prompt="Neues Delta",
    state=state,
    expected_generation=state.generation,
)

Der Async-Pfad verwendet natives Async-Streaming. Nach dem ersten Stream-Ereignis erfolgt kein automatischer Retry.

5. Tool-Calls

Tool-Ausgaben dürfen nur für eine offene Call-ID der aktuellen Chain-Generation eingespeist werden. Dieselbe ID wird genau einmal akzeptiert. Replay, fremde Chain, stale Generation und Größenüberschreitung schlagen explizit fehl.

6. Capability-Probe

Vor diesem Schritt sind eine ausdrückliche Live-/Kostenfreigabe, der exakte Endpoint und ein Request-Budget erforderlich. Es gibt keinen stillen Fallback. 
# POTENZIELL KOSTENPFLICHTIG — nur nach ausdrücklicher Genehmigung.
vlm.probe_responses_compaction_capability(
    probe_input=[{"role": "user", "content": "approved minimal probe"}],
)

7. Hook-Kandidat

Der Hook liegt unter tools/codex_compaction_hooks/codex_compaction_hook.py. Seine Offline-Tests belegen private Rechte, atomare Dateien, Eigentümer- und komponentenweise Symlink-Prüfungen, Directory-FD-Verankerung, eine erzwungene Deadline, begrenzte Retention, Parallelität und konstante prompt-sichere Ausgabe.

Dieses Manual enthält absichtlich keine Installationsanweisung. Eine globale Installation ist eine gesonderte Aktivierungsentscheidung und muss die verifizierten Backups respektieren.
