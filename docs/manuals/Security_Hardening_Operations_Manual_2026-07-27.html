Konfiguration

Lokale Entwicklung benötigt keine CORS-Wildcard. Für eine öffentliche Bindung müssen Betreiber eine konkrete HTTPS-Basisadresse und jede erlaubte Origin eintragen. Beispielwerte sind Platzhalter und dürfen nur durch echte Betreiberwerte ersetzt werden:

[server]
host = "0.0.0.0"
public_base_url = "https://viking.example.org"
cors_origins = ["https://studio.example.org"]
webdav_max_body_bytes = 16777216

Fail closed: cors_origins = ["*"], Credentials in URLs, Pfade/Queries in Origins und eine fehlende HTTPS-public_base_url sind für öffentliche Bindungen nicht zulässig. Keine Proxy-Header als Ersatz für die konfigurierte Basis verwenden.

Betriebsworkflow

  1. Vor dem Start die Betreiber-Origin(s), die HTTPS-Basis und das WebDAV-Limit prüfen.
  2. Eine nicht-sekrete Test-ov.conf für die Regression bereitstellen; keine Produktivschlüssel in Tests ablegen.
  3. Fokussierte Tests, dann Scanner und Baseline-Verifier ausführen.
  4. Nach Änderungen an Origins, Dependencies oder Proxies den passenden Teil erneut testen.
uv run pytest tests/server/test_api_webdav.py tests/server/test_public_url.py tests/session/memory/test_graph_view.py
cd web-studio && npm run test -- file-preview.security.test.tsx && npm run lint && npm run build
cd .. && cargo test

Dependency-Audit

Die Workflow-Datei .github/workflows/security-dependency-audit.yml exportiert die gelockten Python-Anforderungen, führt pip-audit, cargo audit sowie beide Production-npm-Audits aus und vergleicht die JSON-Befunde mit .github/security-audit-baseline.json. Eine neue, fehlende, verschobene oder abgelaufene Ausnahme führt zum Fehler.

python scripts/verify_security_audit_baseline.py --help
jq 'length' .github/security-audit-baseline.json

74 Baseline-Einträge laufen am 2026-08-27 ab. Sie dürfen nicht global ignoriert oder automatisch verlängert werden. Siehe docs/openitem/Security_Hardening_Open_Items_2026-07-27.md.

Grenzen, Incident- und Rollback-Regel

Diese Änderung belegt weder Deployment, CI noch Browser-E2E. Ein lokaler pip-audit-Subprozess endete mit SIGABRT; ohne gültige ov.conf ist die volle Suite offen. Bei einem neuen Advisory oder abgelaufener Baseline: anhalten, JSON-Befund und Paketpfad sichern, Kompatibilität prüfen und keine breite Ausnahme einführen.

Rollback erfolgt ausschließlich als Revert des dedizierten Härtungs-Commits nach Git-Review. Es gibt keine Daten- oder Schema-Migration. Dieses Manual fordert keinen Neustart eines Rechners oder Servers an.
