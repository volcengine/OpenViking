# Retained fonts

Maple Mono NF CN code subsets and the original Adobe Source Serif 4 WOFF2
remain from docs #5536. Their licenses and source hashes are included here.
Prose and Chinese heading fonts are documented in ../tosaki/README.md.
The docs build-reading-fonts.py generator uses sources.json to rebuild only
Maple subsets; no XiHei font program is modified by that generator.
