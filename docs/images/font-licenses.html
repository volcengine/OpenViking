Use the original IPA font / 恢复 IPA 原始字体

To replace the derived Chinese face with the original IPA font, download IPAexGothic from the official IPA font download page, install it on your device, then reload this site. The Chinese font CSS tries local “IPAexGothic” before downloading XiHei. Font access must be allowed by your browser. No other site settings need to change.

希望使用原始 IPA 字体时，可从上述官方页面下载并安装 IPAexGothic，再刷新本站。本站会优先使用本机的 IPAexGothic。它使用日文字形，部分汉字和标点外观会与中文字体不同。若移动设备不支持安装本地字体，可在支持本地字体的浏览器或桌面设备使用此方式。
