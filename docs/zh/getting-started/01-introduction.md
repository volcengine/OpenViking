# 功能概览

OpenViking 是面向 AI Agent 的上下文数据库，将资料、记忆、技能和规则组织成可浏览、可检索的文件。它为 Agent 提供上下文；Agent 读取这些内容后，再生成回答或执行任务。

第一次使用，先完成[快速开始](02-quickstart.md)，看到一份能够核对来源的回答。之后按下面的任务选择体验，不必按顺序读完全部文档。

## 从任务出发

| 你的任务 | OpenViking 提供什么 | 从哪里开始 |
| --- | --- | --- |
| 根据项目资料回答问题 | 导入资料、查找相关内容、读取原文 | [资料检索](08-resources.md) |
| 新会话继续使用已有背景 | 保存会话并提取记忆，在相关任务中召回 | [记忆使用](09-memory.md) |
| 复用一套工作方法 | 存储与检索 Skill，由 Agent 读取并应用 | [技能使用](10-skills.md) |
| 按规范检查任务与行动 | 编译强约束，按当前任务召回规则，供 Agent 核验 | [规则（Beta）](16-rules.md) |
| 把资料整理成可阅读的知识 | 按 Skill 编译为 Wiki 等产物 | [上下文编译](13-compile.md) |

<a id="三类上下文"></a>

## 上下文类型

| 类型 | 保存什么 | 用户怎样确认它有用 |
| --- | --- | --- |
| **资料（Resource）** | 文档、网页、代码等外部资料 | 回答中的关键结论能回到来源核对 |
| **记忆（Memory）** | 从会话提取的背景、偏好与经验 | 新会话不必重复交代，Agent 的新任务确实用到了背景 |
| **技能（Skill）** | 工作流程的指令与配套文件 | Agent 读取技能后，产物符合该流程的要求 |
| **规则（Rule，Beta）** | 特定条件下必须遵守的要求，包括义务、禁止项和例外 | Agent 根据任务证据核对适用规则，并据此调整行动或回答 |

这些内容通过 `viking://` URI 定位。知道位置时可以直接读取；不知道位置时先检索，再打开原文。目录摘要和概览的生成取决于处理方式与配置，可帮助 Agent 按需加载内容。

**规则：** 例如，“仓库声明开源时，必须提供可定位的许可证文本”。你可以将规范中的强约束主动编译为 Rule，再按具体任务召回。OpenViking 提供规则及其适用条件，Agent 结合当前证据核验是否满足要求。规则目前处于 Beta，概念与使用方式见[规则介绍](../concepts/17-rule-scenarios.md)。

## 选择使用入口

![CLI、已有 Agent 和 VikingBot 连接 OpenViking 上下文服务；网关为兼容客户端提供接入路径。](/quickstart/overview.zh.svg)

| 入口 | 适合怎样使用 |
| --- | --- |
| **CLI** | 在终端中浏览、导入、检索与读取；通过 `ov chat` 使用已启用的 VikingBot。见 [CLI 入门](05-cli-setup.md) |
| **已有 Agent** | 为日常工具加入上下文与记忆。各插件的自动捕获、提交和召回能力不同，安装后还需验证新会话行为 |
| **VikingBot** | 使用 OpenViking 内置 Agent 完成问答与工具任务；[快速开始](02-quickstart.md)使用这条路线 |
| **网关** | 将兼容客户端的模型请求接入上下文与记忆流程；可通过保存、提取和召回结果验证接入效果 |
| **SDK / HTTP** | 在自己的应用中控制导入、检索、会话和数据管理流程 |

OpenViking 负责管理和提供上下文，CLI、插件、网关和 Agent 的行为各有边界。深度接入时再查看[Agent 集成](../agent-integrations/01-overview.md)、[网关接入](12-gateway.md)或 [SDK 与 HTTP](../api/01-overview.md)。

## 体验技能与知识整理

**技能：** 选择一个有明确产物的工作流程，安装 Skill，确认 Agent 能发现并读取它，再提交一项任务并检查结果。OpenViking 负责存储和检索技能，Agent 负责激活技能、管理工具权限并执行任务。跟随[技能使用](10-skills.md)完成两组输入的体验。

**整理知识：** 准备来源资料，使用 Wiki Skill 执行编译，等待完成后打开一篇正文，核对来源和遗漏。使用 Skill 编译需要已配置的 Compile Runtime，编译结果可结合原始资料核对。可继续[上下文编译](13-compile.md)，生成并阅读一篇 Wiki。
