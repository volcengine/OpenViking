# Official Studio filesystem assets

Source: [OpenViking Console, filesystem preview](https://www.figma.com/design/ecpd1ZGHKRYibm1ODKEpM6/OpenViking-Console?node-id=8937-52805).

- `search.svg`: original search icon, 16 × 16.
- `refresh.svg`: original refresh icon, 14 × 14.
- `empty-preview.png`: original empty-document illustration from node `9141:203137`, displayed at up to 400 × 311. Its pixels are unchanged; source provenance is embedded as PNG metadata. The source contains Chinese copy, so English and dark mode retain the existing translated HTML empty-state label.

SVG root dimensions are retained. Temporary Figma asset URLs are not used at runtime. The existing Studio icon components continue to serve all unchanged controls; this project does not use Iconbox.
