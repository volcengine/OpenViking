# Pages Agent Guide

适用于本目录及其子目录，同时遵循 [UI Agent Guide](../../../../AGENTS.md)。目录用途与开发入口见 [README](./README.md)。

## 页面职责

- 以完整页面为单位组合 `components/`。页面负责获取数据、适配响应、处理业务状态，再将视图数据和事件回调传给组件；不把请求或业务编排下沉到组件及其内部 Hook。
- 通过消费应用明确提供的配置或服务接口接入数据源，不硬编码服务地址、凭证或账号。具体路由和宿主导航由消费应用接入。
- 加载、错误、分页、刷新、重试及流式连接等数据状态与异步清理由页面层负责。资源或账号切换、页面卸载时清理请求和订阅，避免过期结果覆盖当前页面。
- 依赖方向为 `pages → components`；通用展示与交互复用组件层，组件层不反向依赖页面层。页面私有的数据处理、Hook 和类型留在本页面内，跨实例共享行为通过明确的数据服务接入。

## 新增页面

- 每个页面独占一个 kebab-case 目录，入口文件与目录同名。仅有本目录约定时不添加占位实现、公开导出或文档导航。
- 有真实实现后同步维护公开接口、可运行示例及中英文文档。示例使用固定公开数据或独立的模拟服务，明确加载、失败、重试和作用域切换的行为。
- 验证与交付遵循 UI Agent Guide；本目录的 `AGENTS.md` 和 `README.md` 须由 Git 跟踪。
